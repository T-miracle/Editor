# 编辑器使用

本节介绍把 Nanobug 当作已安装产品来使用的方式。前提是你已经有这个编辑器；从源码
构建属于仓库 README 的开发者话题，不在这里。

本节的页面会随编辑器一起增补。每一页都从读者视角书写，只写编辑器当前真实的行为，
包括它的限制。

## 覆盖范围

- 快速开始：打开文件与打开项目文件夹的区别，以及编辑器分别会做什么。
- 编辑与快捷键：输入、选择、移动文本、折叠、软换行与保存。
- 文件树与搜索：文件如何列出、哪些会被隐藏、搜索的范围如何界定。
- 面板与布局：文件区、编辑区与停靠的插件面板。
- 设置与主题：哪些设置作用于你，哪些属于项目。
- 安装插件：权限确认、启用、更新与卸载。

## 插件用法不在这里

每个插件在自己的包内说明里记录各自的功能，编辑器会在插件管理界面中显示那份说明。
本站只讲宿主行为：包如何安装、权限提示意味着什么、更新或卸载时会发生什么。
[运行、调试与构建](/zh-cn/guide/run-debug-build/)说明配置、可移植目标、有序准备、独立会话和真实调试检查。
