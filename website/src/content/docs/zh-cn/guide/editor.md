# 编辑与快捷键

## 编辑区

编辑区显示行号、缩进参考线与折叠栏。折叠与软换行都是开关，因此你既可以不重排长行来阅读，
也可以让长行按窗口宽度换行。

文本在缓冲区中直接编辑。撤销与重做按会话与文档生效，未保存状态显示在标签上。

## 移动选区

选中一段文本后，在其上按住鼠标左键，选区会跟随指针；松开即把文本移动到新位置。拖到视口
边缘会自动滚动，按 `Esc` 取消移动并让文本留在原处。一次撤销即可恢复到原位置。

## 保存

默认按 `Ctrl+S` 把缓冲区写入磁盘。保存同时也是创建本地历史快照的时机；快照保存在用户数据
目录，不在你的项目里。

如果文件自读取后在磁盘上发生了变化，编辑器会告知你而不是静默覆盖，并保留你的未保存改动。
再次保存即可解决冲突。

## 快捷键

以下为默认绑定，可以在快捷键面板中修改。

| 按键 | 动作 |
| --- | --- |
| `Ctrl+K` | 打开快捷键面板 |
| `Ctrl+S` | 保存当前文档 |
| `Ctrl+Shift+R` | 从磁盘刷新文件树 |
| `Ctrl+Alt+T` | 在浅色与深色主题之间切换 |
| `F12` | 跳转到光标处符号的定义 |
| `F8` | 跳到当前文档报告的下一个问题 |
| `Shift+F8` | 跳到上一个问题 |
| `Esc` | 取消当前交互，例如进行中的拖动或已打开的弹窗 |

用鼠标中键点击符号同样会跳转到定义，并在没有定义时给出说明；点击没有定义的符号会短暂显示
该结果，而不是毫无反应。

插件面板获得焦点时并非所有快捷键都适用：编辑器自身的按键绑定在编辑区上，因此你在插件的
终端或表单里输入不会保存或跳转你的文档。

## 查询与修改绑定

按 `Ctrl+K`、点击标题栏的键盘按钮，或在应用菜单中选择“快捷键”。面板在当前窗口上方打开。
“面板快捷键”显示打开前焦点所在区域的操作，“全局快捷键”显示应用中可用的操作。
`Alt+Left` 与 `Alt+Right` 切换 tab，并保留搜索条件。

可以按描述搜索，也可以点击快捷键搜索按钮，再按下要查询的按键。录入按键不会执行对应操作。
绑定可以是一组组合键，也可以是依次按下的两组组合键；第二组须在两秒内输入。
录入时按 `Esc` 先结束录入；编辑绑定时会取消草稿且不保存。再按一次才关闭面板并恢复原焦点。
点击遮罩也可关闭。

点击绑定进行编辑，或使用行内控件新增另一组绑定、删除绑定、恢复默认。新增的字母、数字组合键
须包含 `Ctrl`、`Alt` 等超出单独 `Shift` 的修饰键。保存后立即作用于所有窗口，并跨重启和工作区保留；每个操作仍遵守自己的
焦点上下文。遇到冲突时，先查看受影响的操作，再明确替换冲突绑定；对方的其他绑定仍然保留。
离开未保存的编辑时，会询问继续编辑还是放弃。

停用、移除或不可用插件的命令会从列表消失，但已保存的绑定仍保留。命令恢复后，绑定可用时会
恢复生效；如果按键或序列已经与其他操作冲突，保留的绑定暂不生效，并在该行提供“处理冲突”。
受限工作区中的插件命令保持不可用。
