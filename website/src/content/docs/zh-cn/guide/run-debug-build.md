# 运行、调试与构建

顶栏在插件管理旁集中显示配置选择、构建、运行、调试、停止、定位和重新运行。禁用控件会解释配置缺失、能力不可用、工作区受限或当前生命周期状态。

## 选择配置

打开配置菜单新建或编辑配置；基本、构建、调试、环境四页共用一个草稿。保存只存储，不执行；取消丢弃修改。

程序模式填写可执行程序，参数每行一个；参数中的空格、引号和标点仍属于同一个参数。Shell 模式显式填写解释器、解释器参数和多行脚本文本；编辑器把脚本作为最后一个解释器参数，不猜测 Shell 或命令标志。缺少解释器或环境条目非法时，表单保留并说明原因。

环境页接受 NAME=value 行及工具路径覆盖，只影响本次程序／准备。工具路径保留本机，共享配置不授予信任或插件权限；原生字段支持中文组合输入、选择与多行输入。

## 发现与共享

发现目标向已启用提供者查询候选，不执行候选，也不自动保存。确认候选才创建配置，重复确认复用它；编辑的名称、参数、环境和有序准备步骤保留。提供者或目标消失时须显式修复，不运行另一个目标。

配置可只存本机，或存到项目共享配置文件。共享数据可移植，省略机器路径、权限、凭据和运行会话。其他工作区打开副本后建立本地身份，并在那里解析提供者绑定。外部非法／删除的共享数据会报告，不静默启动旧备用值。

## 构建与启动

构建按顺序执行构建步骤，不启动最终程序。运行先通过普通保存路径保存修改文档，再执行构建及运行前步骤，最终启动一次；磁盘冲突或保存失败阻止启动。准备失败显示失败步骤和输出，不启动程序。

提供者可为选中目标和配置产出确切构建产物，例如 debug 与 release 配置保持独立，构建不替换成无关可执行文件。本轮采用有效配置快照，后续修改不改变正在运行的一轮。

不同配置可并行运行；选择会话只改变控件作用对象。隐藏输出保留程序，定位恢复同一会话。停止请求正常清理，有界宽限后升级；强制停止立即作用于选中会话的所属进程树，停止中状态保留至观察到真实原生结束。重新运行先等待上一轮清理完成，再开始准备。

## 调试检查

调试要求兼容且已启用的提供者、可用配置与适当工作区权限。原生调试面板显示会话选择、已绑定／未绑定断点、源位置、调用栈和局部变量；提供者不支持的控件带原因禁用。

真实暂停打开提供者报告的源位置；选择另一帧后读取该帧局部变量。继续与单步使旧暂停检查失效，迟到结果不能覆盖新暂停或其他会话。调试面板获得焦点时，F5 继续、Shift+F5 停止、F6 暂停、F10 跨过、F11 进入、Shift+F11 跳出，Up/Down 选择帧。

隐藏面板保留调试。停止回收目标与适配器，强制停止只作用于该会话。停用、卸载、更新受影响插件或离开工作区／窗口前，编辑器列出受影响工作；取消保留插件和会话，确认退役会清理，不自动重跑用户命令。

插件作者可通过公开 SDK 实现[运行会话](/zh-cn/sdk/sessions/)、[调试会话](/zh-cn/sdk/debug/)及[目标发现与准备](/zh-cn/sdk/targets/)。
