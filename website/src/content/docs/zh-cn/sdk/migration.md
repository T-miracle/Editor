# 私有数据与迁移

可执行能力包可以声明：

```json
{
  "data_format": {"version": 2, "migration_hook": true},
  "api": {"base": "^1", "required": {"storage.private": "^1", "storage.migration": "^1"}},
  "permissions": ["storage"]
}
```

版本是插件自有的正整数，与包 semver 无关。零表示新的私有作用域；既有的无版本私有作用域
从版本一开始。宿主按工作区或应用作用域保存已提交的版本，因此休眠的工作区会在下次激活前
完成迁移。修改或删除已声明的格式不能静默绕过迁移；版本变化必须声明钩子。

作用域改变格式时，宿主发送 `Notification::MigrateData { from, to, snapshot }`。快照是插件
不透明数据，不是进程或连接镜像。该钩子内只允许读取包资源和操作私有副本文件；工作区、
编辑器、进程与跨插件服务访问一律拒绝。钩子打开的文件句柄在返回时失效。可返回转换后的
快照；省略则保留传入的快照。不得返回 UI 或其他提案。新实例在最终 `Prepare` 阶段收到转换
后的快照，随后是配置与激活；它在钩子之前绝不会把旧格式快照当作初始化状态。常规执行预算
照常适用。

准备阶段会编译并校验候选版本，同时保留旧实例。宿主捕获 `begin_installation` 任务并在
后台线程执行；既有 actor 继续处理命令、编辑器补全与文档事件。`prepare_installation` 是同一
路径的同步便捷形式。准备令牌可以在派发旧命令期间持有；`commit_installation` 在属主工作
线程的独占轮次中取得新副本与最终快照，因此最初的准备副本无法覆盖更新的写入。丢弃准备
令牌即丢弃其未发布的副本。令牌绑定管理器根目录、工作区与先前的包摘要。

迁移可能先在一次性预览上运行，以便依赖发现读取新格式；旧属主停止后会在最终副本上再次
运行。钩子必须转换传入的副本，不能假定只被调用一次。最终依赖选择必须与已准备的方案一致；
发生变化会使更新失败并恢复旧版本，让用户重新准备。切换期间不会发生下载与安装程序确认。

切换会在收集最终快照前封闭待处理的编辑器与服务请求，退役旧的语言服务租约，并停止旧属主。
即使包摘要未变，恢复也会创建新的实例身份。原生回调与面板事件保留其来源实例纪元，迟到事件
被丢弃。成功替换与恢复之后，宿主都会重新发布语言服务租约并重新同步已打开的内存文档。
未显式声明数据格式的普通协议 7 WASM 包在格式版本一上走同一条路径。

候选实例针对其隔离目录激活。激活成功后，宿主刷入包含先前注册表的日志，在保留备份的同时
交换数据作用域，原子写入新注册表，然后刷入已提交标记。只有在该标记之后才可以删除备份并
发布候选版本。启动时回滚缺少该标记的日志，并为已提交的日志完成清理。若无法完成恢复，
启动或激活会带保留的恢复位置失败：备份不被丢弃，也不会有任何来宾在数据不确定的情况下
恢复运行。日志覆盖私有文件、不透明快照、格式版本与包记录；用户文档、外部影响与原生进程
身份不在其中。

可执行的私有数据写入者对一个安装根目录只能有一个运行时属主，而仅元数据与声明式依赖管理器
保持独立。取得属主会在加锁后刷新注册表；事务读取者遇到正在提交的写入会拒绝，而不是激活
包与数据不匹配的组合。既有逻辑工作区在其属主管理器内保持隔离。副本只接受有界的常规文件：
总计 128 MiB、16384 个条目、深度 16，链接一律拒绝。恢复保证通过进程中断验证，并不宣称
每个文件系统或控制器都提供掉电持久性。
