# 插件系统对接

本节面向构建插件包的人。插件是声明式包，只有确实无法声明的那部分行为才需要附带
WebAssembly 组件。

契约是版本化并经协商的：清单声明需要哪些能力、哪些是可选的，编辑器在实例运行前检查
这些声明。必需能力无法提供时，插件会被带原因地拒绝，而不是以降级状态启动。

## 契约覆盖的内容

- 包清单以及它携带的能力声明。
- 访客组件与编辑器之间的类型化请求与通知。
- 插件为其面板发布的原生界面树，含画布这一特殊通道。
- 带明确版本与提供者选择的跨插件服务。
- 原生进程（含交互式进程）及其各自的权限。
- 语言包：grammar 与查询资源，以及语言服务。
- 私有存储、配置、数据格式迁移与故障恢复。
- 通过编辑器自带的 Cargo 入口独立构建，以及 SDK 导出。

## 这些文档如何交付

契约文档同时也是编辑器交给插件项目的 SDK 的一部分：编辑器内嵌这些内容，按内容摘要
缓存，并在你构建插件时提供给 `cargo`。本节页面就是同一份文本，在此发布以便阅读。

## 从哪里开始

如果你从未为本编辑器写过插件，先从包清单与能力声明开始，再按插件的实际需要进入界面
或服务章节。每一章都会说明它适用的版本。
