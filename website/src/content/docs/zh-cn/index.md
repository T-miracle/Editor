# Me Editor 文档

Me Editor 是用 Rust 与 GPUI 编写的原生桌面代码编辑器。它不是网页应用：窗口、编辑区
与插件面板全部原生绘制。

本站面向两类读者，请按你手头的事选择入口。

- **[编辑器使用](/zh-cn/guide/)**——安装编辑器、打开项目、编辑与跳转代码，
  并配置编辑器的本机行为。
- **[插件系统对接](/zh-cn/sdk/)**——构建插件包：声明能力、协商版本、
  绘制原生界面、运行服务与进程，并完成打包。

## 编辑器当前具备的能力

- 原生可调布局：文件区与代码编辑区。
- 递归文件树，并遵循 `.gitignore`。
- 深浅色主题，以及按文件类型显示的图标。
- 打开 UTF-8 文件并按扩展名启用高亮。
- 语法高亮与诊断来自随插件分发的 WebAssembly grammar，因此新增语言靠安装插件包完成，
  不需要修改编辑器本身。
- 按 `F12` 或点击鼠标中键跳转定义；插件或语言服务报告的问题可用 `F8` 与 `Shift+F8` 跳转。
- 行号、缩进参考线、代码折叠与软换行切换。
- 选中文本后按住鼠标左键拖动即可移动，松开后可用一次撤销恢复到原位置。
- 按 `Ctrl+S` 保存，并在项目目录之外写入本地历史快照。
- 运行时插件系统：从本机安装包、确认权限、热更新，并把插件面板停靠在编辑区旁。

## 其余内容在哪里

源码构建方式、工作区结构与测试命令面向编辑器本身的开发者，留在仓库 README，不放在本站。
插件包自己的用法由各插件的包内说明记录，编辑器会在插件管理界面中显示它。
