## What to build

用户完成插件快捷键自定义后，可以禁用、卸载和重新启用或安装插件：不可用命令不再显示或响应，但绑定配置保留；插件返回后仍存在的命令恢复配置，若与当前有效绑定冲突，则在原生界面提示用户处理，不静默抢占。

本单交付插件生命周期中的绑定保留、撤销、恢复与冲突反馈，并承担整批最后一次短组合验收。复用 02 的用户配置与分发规则，不另造插件快捷键体系；必要的生命周期整理先保持原有启停和权限行为，再接入绑定恢复。

## Acceptance criteria

- [x] 通过现有公开管理器禁用或卸载插件后，相关命令从查询列表撤销，快捷键不再执行旧实例，但用户绑定配置仍保留。
- [x] 重新启用或安装同一插件时，只为仍然存在的操作恢复自定义绑定，不把已移除命令的配置错误应用到其他操作。
- [x] 插件离线期间其他命令获得相同绑定，插件恢复后必须提示冲突并沿用显式处理规则；不得按安装/启用顺序覆盖当前有效绑定。
- [x] 恢复冲突同时覆盖单步重复与连续前缀冲突，正确保留不重叠作用域可复用的绑定；配置保留不等于冲突绑定已经生效。
- [x] 禁用或卸载时撤销旧命令目标和等待中的连续按键状态，不允许迟到的第二步调用已失效实例；重新激活使用有效贡献与权限。
- [x] 受限工作区中，查询、修改或恢复绑定不会自动启动被禁止的插件和工具，也不改变工作区信任或插件权限。
- [x] 安装此前未知的独立测试插件包即可进入同一查询、改绑、停用和恢复路径；不修改宿主名称白名单，不引入插件专属测试 API。
- [x] 使用同一隔离用户配置和公开包管理应用流程完成 T20–T21，以及 T22 中新增生命周期提示的中英文、深浅主题和焦点验收。
- [x] 对新增或修改的公开契约、包和 SDK 补齐对应文档与消费者；实际 WASM 场景按要求构建后显式运行 ignored 测试，不能将跳过报告为通过。
- [x] 完成一次短组合验收：不同面板查询 → 基础编辑和插件改绑 → 两步执行与冲突 → 插件禁用/恢复 → 重启后再次执行并核对焦点；引用 01、02 的详测记录，仅对本单实际影响的路径追加回归。
- [x] 核对规格 T01–T22 均有真实证据，明确各记录对应的工作树/版本、命令与结果；未执行项不得标通过，不将旧版本记录冒充本次完整重跑。
