# 01：快捷键面板查询与按键搜索

稳定标识：`ui-keyboard-shortcuts-panel-01`

状态：实现与验收完成；交付后核对 GitHub #81 的关闭状态。证据见[阶段验证记录](../../verification/keyboard-shortcuts.md)。

## Parent

- [#77 — 快捷键面板与用户绑定规格](https://github.com/T-miracle/Editor/issues/77)

## What to build

用户从任一有效面板通过 Ctrl+K 或应用菜单打开 C 方案的快捷键弹层，看到原面板与应用全局的真实操作，使用文字或按键搜索，再关闭并返回原位置。宿主、基础编辑操作和插件贡献使用一致的描述与作用域入口，有绑定和未绑定的操作都可发现。

这是一条可独立演示的查询路径，不交付用户绑定修改。两步按键的表示、录入和搜索在本单完成，实际修改、保存和连续命令执行由下一单完成。必要预重构先整理现有操作描述与上下文入口，保持现有命令效果和插件边界，再接入面板。

## Acceptance criteria

- [x] 通过 Ctrl+K 和应用菜单打开主窗口内模态弹层；遮罩阻止背景交互，无标题栏、无关闭按钮。
- [x] 采用 C 方案的紧凑结构，默认约 760 × 560 逻辑像素，小窗口自适应；固定双 tab、搜索区和底部提示，只有列表滚动，搜索结果变化不改变弹层尺寸。
- [x] 打开前捕获原焦点面板并固定查询上下文；有面板快捷键时默认选该 tab，否则选全局；每次重新打开清空搜索并聚焦搜索框，关闭后恢复原焦点。
- [x] 宿主命令、基础编辑操作和当前有效插件命令均来自真实操作描述，左侧描述、右侧键帽；未绑定的可管理操作标记“未绑定”，不靠硬编码演示行冒充实际目录。
- [x] 面板与全局分类根据真实作用域，不按插件名称或命令标题猜测；必要契约扩展保持对全部插件公开和可复用，不扩大权限或建立白名单。
- [x] 描述搜索实时筛选当前 tab；Alt+← / Alt+→ 切换 tab 并保留搜索条件；右下角固定显示文字和按键图标提示。
- [x] 键盘按钮开启和退出按键搜索；录入只改变查询条件，不触发保存、粘贴、插件命令或背景文字输入。
- [x] 支持一步与两步按键显示，第一步立即筛选单步及连续前缀匹配，2 秒内第二步缩小为完整序列匹配；修饰键精确匹配，无第二步形成单步查询。
- [x] 录入时 Alt+方向键作为查询内容；Esc 退出录入但不关闭弹层，普通浏览时 Esc 或点击遮罩关闭。
- [x] 基于已确认的 GPUI 应用测试入口完成规格 T01–T09 的本单部分及 T22 的查询相关场景，覆盖中英文、深浅主题、IME、长列表、小窗口与缩放；配置改绑和行内编辑部分留给 02。
- [x] 双步查询使用有效操作描述与可控时间夹具验证，不为此新增生产环境演示命令或插件专用测试 API。
- [x] 保留既有宿主、基础编辑和插件默认命令执行行为；未开放的编辑能力不以可点击但无效的控件伪装完成。
- [x] 完成本单针对性测试、仓库规定的阶段检查和必要原生交互验收，记录实际结果；后续引用同一夹具与证据，不另建重复查询测试体系。
