# 02：用户绑定修改与连续快捷键执行

稳定标识：`ui-keyboard-shortcuts-panel-02`

状态：`ready-for-agent`，用户已批准拆分并授权执行；阻塞项完成后进入实施前沿。

## Parent

- [#77 — 快捷键面板与用户绑定规格](https://github.com/T-miracle/Editor/issues/77)

## What to build

用户在已经可用的面板中，为宿主、基础编辑及有效插件操作行内增删改绑定，明确处理冲突后保存，随后在真实应用中执行新的单步或两步快捷键。设置即时生效、重启保留且跨工作区共用，仍遵守命令原作用域。

将绑定编辑、冲突判定、持久化和实际事件分发合为一个闭环，避免出现列表已修改而旧快捷键仍执行的半成品。沿用 01 的操作目录、录入、时钟和 UI；必要预重构先整合生效配置与分发职责，在保持既有行为的前提下迁移重复的原始绑定路径。

## Acceptance criteria

- [ ] 点击右侧绑定进入 C 方案行内录入，显示保存/取消；未绑定操作可添加；每个操作允许多个绑定，各组可独立增删改，并可恢复该操作默认绑定。
- [ ] 宿主、基础编辑操作和有效插件命令均支持实际改绑，不遗漏底层输入控件；更改或删除旧绑定后，旧路径不会继续触发同一命令，也不会重复派发。
- [ ] 保持编辑命令经现有文档会话执行，复制、粘贴、撤销等改变的是绑定，不引入第二份文本或 Undo/Redo 状态。
- [ ] 录入期间不执行对应业务操作，也不改变已保存绑定；保存校验通过后立即应用并持久保存，取消或录入态 Esc 丢弃草稿。
- [ ] 配置属于用户，在所有工作区和重启后共用；面板命令仍仅在原作用域触发，不因“全局保存”而变成跨面板命令。
- [ ] Ctrl+K 的打开绑定自身可修改、删除和恢复默认；应用菜单始终保留可用入口。
- [ ] 支持单步及最多两步连续快捷键；复用 01 的录入与 2 秒等待，不支持三步；实际执行第一步后提示下一步，超时取消，不匹配的第二步按正常方式处理，匹配时仅执行一次。
- [ ] 新绑定的每一步均校验文字键修饰限制：字母/数字必须包含 Ctrl、Alt 等超出单独 Shift 的修饰键；功能键、方向键等按规格允许单独使用。
- [ ] 冲突按真实可同时触发的上下文判定，覆盖完全相同绑定和短绑定占用连续前缀；不重叠面板允许复用，全局与面板重叠不能漏报。
- [ ] 存在冲突时显示操作并禁止直接保存；取消保留原配置，显式替换只解除发生冲突的绑定，不删除同一操作的其他绑定；恢复默认同样检查冲突。
- [ ] 录入态 Alt+← / Alt+→ 作为绑定输入，不切换 tab；Esc 取消本次录入后返回普通状态，再按一次才能关闭。
- [ ] 有未保存修改时，点击遮罩、切换 tab 或开始编辑其他项均先询问放弃或继续；继续编辑保留草稿，选择放弃后再完成目标动作。
- [ ] 通过应用级真实按键、可见文档效果及保存重载验证 T10–T19，补齐 T01 的自定义入口、T05 的行内布局、T09 的绑定录入及 T22 的编辑/冲突提示部分；共用前单夹具，不重复建设相同查询测试。
- [ ] 静态有效插件通过公开管理器进入同一改绑和冲突流程，不以测试专用宿主 API 替代真实插件调用；停用、卸载和恢复持久配置由 03 验收。
- [ ] 完成本单针对性测试、仓库规定的阶段检查和受影响原生交互验收；如修改公开契约或 SDK，同步验证消费者与分发，记录对应版本及未验证限制。
