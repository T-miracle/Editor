# 01：外部粘贴与可靠文件转移

稳定标识：`explorer-file-transfer-01`。状态：已批准并发布，待实施。

## Parent

[资源管理器文件转移规格 #76](https://github.com/T-miracle/Editor/issues/76)。设计依据，不作为必须关闭的执行阻塞项。

## What to build

用户从系统文件管理器复制或剪切一个或多个文件、目录后，通过资源目录树右键菜单或粘贴快捷键完成导入。遇到同名内容时自行选择处理方式，长操作可查看进度和取消，移动成功后继续编辑原有标签页。

本票连通系统剪贴板、目录树目标、磁盘执行、冲突 UI、文档状态及结果提示。先用已有粘贴场景完成局部预重构，再扩展行为；不单独拆只有内部接口而无用户结果的基础票。

## Acceptance criteria

- [ ] Windows 文件剪贴板支持多项文件和目录，正确区分复制/剪切；复制保留来源，成功移动改变来源位置。
- [ ] 右键菜单与目录树焦点下的粘贴快捷键可用，不截获编辑区文本粘贴和中文 IME。
- [ ] 目录行写入目录自身、文件行写入父目录、空白处写入项目根目录；后续拖放复用相同目标语义。
- [ ] 同名冲突提供跳过、保留两份、替换，可应用于本批后续冲突；保留两份不覆盖原有内容。
- [ ] 同名目录经选择合并，保留目标独有文件，内部同名文件继续处理冲突。
- [ ] 普通替换禁止覆盖未保存目标内容，可跳过或保留两份；移动未保存源文件及其父目录后更新标签路径，保留文本、光标和文本 Undo/Redo。
- [ ] 复制和移动在后台执行，长操作显示进度与取消按钮，编辑器仍可使用。
- [ ] 失败或取消保留已完成项、清理当前未完成结果；失败停止后续项并区分成功、失败和未执行内容。清理不得删除目标原有内容或尚未成功转移的来源。
- [ ] 通用错误消息显示路径、原因和批次结果，保留到手动关闭；普通定位提示时长不变。
- [ ] 导入时跳过符号链接及 Windows 目录联接，不跟随目标递归复制，结束后汇总跳过项。
- [ ] 从本票起按实际完成结果保存操作记录与必要的项目外覆盖备份，供工单 03 直接消费。部分失败或取消只记录已完成部分，记录和备份遵循会话生命周期，不另建文本撤销栈。
- [ ] 遵守既有路径边界，拒绝自身、后代等无效目标；资源树、标签页和后台完成事件反映实际成功结果。
- [ ] 复用资源树 GPUI 主入口验证磁盘、标签及消息，并完成 Windows 系统复制/剪切后粘贴的真实验收。
- [ ] 尽量复用 macOS/Linux 能力，记录文件剪贴板、剪切意图适配的支持范围与未验收部分，不把 Windows 结果代替其他平台运行结果。
- [ ] 集中覆盖本票公共规则与明暗主题，形成后续可复用夹具；通过相关模块测试及仓库规定的阶段检查。

## Testing decisions

本票拥有复制/移动、目标解析、冲突合并、文档同步、未保存内容保护、进度取消、部分失败及链接跳过的主要行为矩阵。复用实际 EditorApp、临时工作区和现有菜单/键盘测试，不为每种输入创建重复策略用例。

完成记录与覆盖备份随本票实际操作生成，并验证生命周期；恢复入口及强制撤销的完整行为属于工单 03，避免到撤销票才重写复制与覆盖路径。
