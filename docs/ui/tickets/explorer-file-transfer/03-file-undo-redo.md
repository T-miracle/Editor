# 03：文件操作撤销、重做与冲突恢复

稳定标识：`explorer-file-transfer-03`。状态：已批准并发布，待实施。

## Parent

[资源管理器文件转移规格 #76](https://github.com/T-miracle/Editor/issues/76)。设计依据，不作为必须关闭的执行阻塞项。

## What to build

用户通过目录树右键菜单及 Ctrl+Z、Ctrl+Shift+Z 撤销和重做已经完成的复制、移动、替换与目录合并。恢复遇到后续变化时逐项确认，强制撤销需要丢弃未保存内容时再次明确确认。

复用公共转移流程的完成记录和项目外备份，恢复真实磁盘结果并同步标签页。记录限于当前会话，退出后清理。

## Acceptance criteria

- [ ] 右键菜单提供撤销、重做及具体操作提示；目录树有焦点时 Ctrl+Z 撤销文件操作、Ctrl+Shift+Z 重做，编辑区有焦点时处理文本编辑。
- [ ] 消费工单 01 的实际完成记录，不区分粘贴或拖放来源，不建立重复的备份体系或撤销规则。
- [ ] 撤销复制移除复制结果，撤销移动恢复路径，撤销替换恢复旧内容；目录合并区分新增、替换和原有未变内容。
- [ ] 部分失败或取消只撤销实际完成部分，不删除原有目标内容，不操作从未成功转移的项目。
- [ ] 撤销和重做改变路径后同步标签页与文档状态，继续使用原有 EditorState，不复制可变文本或文本撤销栈。
- [ ] 撤销前检查后续修改和路径占用等冲突，逐项提示，仅按用户选择执行强制撤销。
- [ ] 强制撤销涉及未保存内容时再次明确提示丢失；拒绝或取消时保留内容，再次确认后才允许丢弃并撤销。
- [ ] 强制撤销授权不放宽普通复制、移动及替换的未保存内容保护。
- [ ] 重做前重新检查目标和冲突，不盲目重放旧结果；取消和失败展示可核对的实际结果及通用错误提示。
- [ ] 记录和备份位于项目外、仅在当前会话有效，退出后清理，不承诺跨重启撤销。
- [ ] 用真实粘贴生成记录，从菜单和快捷键恢复并检查磁盘、标签、焦点和确认结果；覆盖强制撤销二次确认的接受与拒绝。
- [ ] 验证明暗主题和中英文菜单、确认与错误提示；通过相关测试及仓库规定的阶段检查。

## Blocked by

- 工单 01：外部粘贴与可靠文件转移。依赖其实际完成记录、覆盖备份及公共执行流程。

## Testing decisions

本票拥有撤销/重做、恢复冲突、未保存内容二次确认、快捷键焦点及会话清理矩阵。通过粘贴即可完成核心验收，工单 02 不构成技术阻塞。

02、03 均完成后集中执行一次 Windows“外部导入 → 树内移动 → 撤销 → 重做”跨入口验收。正向转移的全部组合不在本票重复人工验收，除非公共实现变化或新失败需要回归。
