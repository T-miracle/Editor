# Me Editor 开发计划

状态：已确认

以 `需求整理.md` 为准。每阶段完成时运行：

```powershell
cargo fmt --check
cargo test --workspace --exclude editor-app
cargo check --workspace
```

## 0. 稳定现有基线

锁定 Rust、GPUI Kit、Tree-sitter 与 Windows 工具链版本；为打开、编辑、保存、历史快照和 `.gitignore` 文件树补齐回归测试。

## 1. 动态 WASM grammar 验证

在 `plugin-schema` 定义清单、宿主版本、Tree-sitter ABI、grammar、查询和权限。在 `editor-core` 建立“文档 revision → 后台增量解析 → 高亮范围”流程，并通过 GPUI Kit 公开接缝绘制。用本地 Rust 与 TypeScript 插件验证；关闭插件后必须移除对应高亮。

## 2. 插件安装与项目启用

实现本地目录与公开 GitHub commit 安装、hash 锁定、显式更新、依赖解析和循环检测；保存项目推荐项与本机实际启用项；完成七个首发语言插件。

## 3. 信任、设置和工具链

实现受限工作区、设置作用域、文件排除和 Node/Rust/Git 路径解析；工具缺失时仅禁用关联能力并显示诊断。

## 4. LSP 与格式化

实现标准输入输出 JSON-RPC、取消、超时、退出恢复与 revision 校验；接入 `rust-analyzer`、TypeScript 语言工具、Volar，并支持诊断、补全、悬浮、语义 token 和格式化。

## 5. 搜索与本地历史

实现 `.gitignore` 感知的搜索、正则、替换预览和原子写入；历史升级为 SQLite 元数据、压缩增量、检查点、恢复及 30 天/1 GB 清理。

## 6. Git

实现状态、diff、历史、暂存、提交、分支、clone、fetch、pull、push。写操作按仓库串行；破坏性动作预览后确认；认证委托外部 Git。

## 7. Windows 交付

完成中英文、主题、布局恢复、命令面板、快捷键冲突提示、中文 IME 与异常场景验收，并建立安装包、许可和发布检查表。

## 依赖顺序

```text
plugin-schema
  → documents + dynamic syntax
  → plugins + workspace trust + settings
  → toolchains + language-host
  → search + local-history + git
  → editor-app 收尾与发布
```
