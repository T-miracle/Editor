# E02 — 迁入能力协议文档并确定英文权威版

**Status:** ready-for-agent — 本地制品，未发布 GitHub。稳定标识：`docs-site-02`

**规格：** [编辑器文档站点规格](../specs/docs-site.md)。覆盖用户故事：10、11、13、15。

## What to build

把插件能力协议的 9 篇文档从源码旁迁入站点的英文树，成为唯一手写源；同时产出英文权威版：正文本就是英文的 4 篇按站点结构就位，正文为中文的 5 篇产出英文权威版（中文原文暂存，由 E03 转为译文）。源码旁只保留指向站点的指针。

## Acceptance criteria

- [ ] 9 篇内容完整迁入，原 `README.md` 按站点结构拆为 SDK 概览与独立构建两页；其余 8 篇各成一页。
- [ ] 每个主题的表述与迁移前逐条一致：协议版本、能力标识、字节数与条目上限、错误码、权限名称、超时与预算数值均不得改写；翻译造成的语义偏移视为缺陷。
- [ ] 迁移后源码旁目录只保留指针文件，指针说明"文档已移至站点、SDK 导出内容取自站点源"，不再保留第二份正文。
- [ ] 站点内的相互引用（概览指向各专题）在站点结构下可解析；原文档之间指向源码目录的相对链接已按站点路径修正。
- [ ] 中文原文在 E03 完成前不进入中文树，避免出现半迁移的双语状态。
- [ ] 站点构建通过，新增页面出现在"插件系统对接"栏目的侧栏中。

## Blocked by

- E01 — 建立双语文档站点骨架与链接测试

## Verification

逐篇对照迁移前后内容，确认无段落丢失、无表述改写；运行站点构建与链接测试。记录对照方式与实际结果，不以"页面存在"替代逐条核对。

## Implementation guardrails

- 迁移是内容搬迁，不是重写：不得借迁移调整协议内容、补充未确认能力或删减限制描述。
- 不在本单建立中文译文；语言职责分离，避免同一页被两次编写。
- 不修改协议实现代码与 WIT；本单只动文档与站点内容。
- 保留工作区已有改动。
