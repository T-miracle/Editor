# E09 — 完成整站双语与链接终验并交付

**Status:** ready-for-agent — 本地制品，未发布 GitHub。稳定标识：`docs-site-09`

**规格：** [编辑器文档站点规格](../specs/docs-site.md)。覆盖用户故事：全部（最终集成复核）。

## What to build

在全部内容与机制就位后执行整站终验：两个语言树的页面集合一致、每页可读且切换正确、站内链接与锚点无断、搜索覆盖两条线、部署产物与真实站点一致；并补齐站点协作约定，使双语同步规则对后续 AI 与维护者可见可执行。

## Acceptance criteria

- [ ] 交付状态可核验：站点真实 URL 可访问，中英两版"使用指南"与"插件系统对接"两条线页面齐全，无空页与占位页。
- [ ] 双语终验：页面路径集合一致；切换入口互指；逐页抽查中英两版内容语义一致，精确数值与标识符无偏差。
- [ ] 链接终验：站内链接与锚点全部可解析；语言切换、侧栏、页内目录与外链均按预期工作。
- [ ] 搜索终验：以中英关键词各检索一次，命中对应页面。
- [ ] SDK 终验：执行一次真实导出，确认导出的协议文档与站点英文树内容一致；SDK 验证脚本通过。
- [ ] 站点内容不包含任何指向 `docs/` 内部资料、源码路径或工单的链接；公开面只含使用说明与对接文档。
- [ ] 站点协作约定文件补齐并明确：英文为权威正本、双语必须同提交、站点目录移动会导致宿主构建失败、根路径与站点地址需同步修改。
- [ ] 证据完整：记录实际执行的命令与结果、未验证项与平台限制；不以构建通过替代真实页面核对。

## Verification

按仓库约定的阶段检查执行：站点构建与测试（含故意制造故障后的还原确认）、Rust 侧格式与非 UI workspace 测试与编译检查、SDK 分发验证脚本；再对真实站点 URL 逐项核对。记录失败归因、环境缺失与未验证内容。

## Implementation guardrails

- 本单是集成与终验，不接收前序未完成的内容，也不把前序测试推迟到此。
- 终验发现的缺陷回到对应工单范围修复，不在本单夹带范围外改动。
- 只有证据满足后才标记完成；平台未实测项按实际说明，不宣称全平台通过。
- 不修改既有父议题或其他批次的状态。
