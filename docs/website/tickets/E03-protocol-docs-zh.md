# E03 — 补齐能力协议的中文译文

**Status:** ready-for-agent — 本地制品，未发布 GitHub。稳定标识：`docs-site-03`

**规格：** [编辑器文档站点规格](../specs/docs-site.md)。覆盖用户故事：7、8、9、19。

## What to build

为 E02 建立的英文权威页补齐中文译文，使中文树与英文树的页面集合完全一致：正文原为英文的 4 篇需要新译，正文原为中文的 5 篇需要把迁移前原文整理为站点结构下的译文。完成后"插件系统对接"栏目在中英两侧都可完整阅读。

## Acceptance criteria

- [ ] 中文树与英文树的页面路径集合完全一致，无缺页、无多余页；`tests/doc-sources` 通过。
- [ ] 每页的中英切换入口互指对应页面；从任一页切换后停留在同一主题。
- [ ] 译文与英文权威版语义一致：协议版本、能力标识、数值上限、错误码、权限名称、超时与预算不得出现偏差；译文不得比英文原文更强或更弱的断言。
- [ ] 原中文正文的全部信息在新译文中均有落点，无因重组而丢失的段落。
- [ ] 术语全文一致：同一能力、同一概念在中文侧使用同一译名；首次出现处保留英文标识符，便于对照代码与清单。
- [ ] 中文页面不出现指向 `docs/` 内部资料或源码目录的链接。

## Blocked by

- E02 — 迁入能力协议文档并确定英文权威版

## Verification

逐页对照中英两版，按"数值与标识符逐条核对、术语逐页抽查"的方式确认；运行站点构建、链接测试与页面集合测试。记录实际对照范围与发现的问题。

## Implementation guardrails

- 英文是权威正本：译文与英文冲突时改译文，不改英文；确需改英文表述时回到 E02 的范围另行处理。
- 不新增英文侧没有的内容，也不因翻译困难删减英文侧的限制说明。
- 本单与 E02 必须分别提交，不得把英文改写混入译文提交。
