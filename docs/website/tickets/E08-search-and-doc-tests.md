# E08 — 接入站内搜索与文档源测试

**Status:** ready-for-agent — 本地制品，未发布 GitHub。稳定标识：`docs-site-08`

**规格：** [编辑器文档站点规格](../specs/docs-site.md)。覆盖用户故事：14、19、20。

## What to build

为站点接入构建期生成的静态搜索索引，使读者能站内检索中英两个语料；同时把文档源测试补全为完整门禁：双语页面对应、必填页面元数据、站内链接与锚点。搜索索引在部署产物中可用。

## Acceptance criteria

- [ ] 搜索命中插件 SDK 关键词（如协议版本标识、能力名称、错误码）与使用指南关键词；中英两棵树均可被检索。
- [ ] 搜索在部署产物中可用，不依赖运行时服务；索引随构建生成，页面新增后无需手工登记。
- [ ] `tests/doc-sources` 覆盖：两个语言树的页面路径集合一致、每页含指向对侧页面的切换入口、必填元数据存在；缺页、多页与元数据缺失均失败。
- [ ] `tests/links` 覆盖站内链接与锚点，能定位到具体页面与具体链接；外部链接检查不因网络波动产生假失败。
- [ ] 两类测试与构建命令入口单一，实施时执行的命令与文档记录一致。
- [ ] 故意制造的缺页与断链均被拦住，验证后还原，不改测试断言迁就实现。

## Blocked by

- E01 — 建立双语文档站点骨架与链接测试
- E07 — 用 GitHub Actions 部署到项目站并核验真实链接

## Verification

运行站点测试与构建，在预览中检索中英关键词确认命中；制造一次缺页、一次断链、一次元数据缺失，确认三类都被拦住；还原后确认全部通过。记录实际检索词、命中结果与制造故障的验证过程。

## Implementation guardrails

- 测试只断言外部可观察结果：页面存在、链接可解析、索引可检索；不断言索引内部结构或页面 DOM 细节。
- 不为自定义 Markdown 插件单独写单元测试；其行为由真实页面构建与链接测试覆盖。
- 搜索方案限定为静态索引，不引入需要服务端或第三方账号的检索服务。
- 保留工作区已有改动。
