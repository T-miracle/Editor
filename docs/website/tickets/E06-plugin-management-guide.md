# E06 — 撰写插件安装与管理说明

**Status:** ready-for-agent — 本地制品，未发布 GitHub。稳定标识：`docs-site-06`

**规格：** [编辑器文档站点规格](../specs/docs-site.md)。覆盖用户故事：16、17、18、7、9。

## What to build

写出面向使用者的插件宿主行为说明：从本机安装、权限确认、启用范围、启停、更新、卸载，到受限工作区的限制与失败后的状态。只讲宿主流程，不复述各插件自己的用法。中英双语平行交付，英文为权威正本。

## Acceptance criteria

- [ ] 覆盖安装入口与包来源、首次安装的权限确认、更新时新增权限的再次确认，以及正常调用不反复弹窗的行为。
- [ ] 覆盖全局启用与项目启用的区别、作用范围语义，以及禁用或关闭工作区后的资源撤销结果（读者可观察层面）。
- [ ] 覆盖更新与卸载：准备失败时保留旧实例、激活失败时恢复旧版本、成功切换后旧资源撤销；说明快照只恢复逻辑状态，不承诺回滚外部系统副作用。
- [ ] 覆盖受限工作区的限制：不得启动插件或语言工具、不采用项目工具路径。
- [ ] 明确说明各插件自己的用法在哪里查看：插件包说明由管理界面读取显示；本页不复制其内容。
- [ ] 中英两版页面路径一一对应，切换入口互指；页面集合测试通过。
- [ ] 页面不出现指向 `docs/` 工单、验收记录或源码路径的链接。

## Blocked by

## Verification

按页面在真实编辑器中走一遍：安装一个真实插件包、确认权限弹窗、切换启用范围、禁用后观察资源撤销、卸载后确认状态；受限工作区下确认插件未启动。运行站点构建、链接测试与页面集合测试。记录实际操作与结果。

## Implementation guardrails

- 只描述已实现的宿主行为；未实现的在线市场、评分、其他版本等入口不写入，也不描述为"即将支持"。
- 不写插件开发者视角的接口细节；接口内容属于"插件系统对接"栏目。
- 表述权限与安全边界时不得弱化：不暗示可以不确认权限、跳过信任检查或对受限工作区例外。
- 中英两版在同一提交内完成。
