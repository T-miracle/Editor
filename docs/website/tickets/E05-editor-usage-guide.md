# E05 — 撰写编辑器使用指南

**Status:** ready-for-agent — 本地制品，未发布 GitHub。稳定标识：`docs-site-05`

**规格：** [编辑器文档站点规格](../specs/docs-site.md)。覆盖用户故事：1、2、3、4、5、6、7、9。

## What to build

在站点的"使用指南"栏目写出面向使用者的编辑器说明：从启动与打开文件，到编辑、快捷键、文件树与搜索、面板布局、设置与主题，以及受限工作区的行为。中英双语平行交付，英文为权威正本。

## Acceptance criteria

- [ ] 覆盖面完整：快速开始、编辑与快捷键、文件树与搜索、面板与布局、设置与主题；每页有明确读者目标，不写成功能罗列。
- [ ] 快捷键与交互描述逐项对照当前实现核实，包括保存、定义跳转、诊断跳转、折叠、软换行、选区拖动与取消；不照抄既有描述。
- [ ] 受限工作区的行为说明与实际一致：允许编辑，但插件与语言工具不启动、不采用项目工具路径。
- [ ] 设置与主题的作用范围说明与实际一致：项目设置不覆盖用户语言、主题与信任状态。
- [ ] 插件相关操作在本栏目只指向"插件安装与管理"页，不复述插件包自己的用法。
- [ ] 易漂移内容（快捷键、命令名、限制项）优选用源码片段引入而非手抄；引入失败时构建必须报错，不得静默输出空内容。
- [ ] 中英两版页面路径一一对应，切换入口互指；页面集合测试通过。
- [ ] 页面不出现指向 `docs/` 内部资料、源码路径或工单的链接。

## Blocked by

## Verification

在真实窗口中按页面逐项操作核对（打开文件、保存、跳转、折叠、软换行、受限工作区提示），确认说明与可见行为一致；运行站点构建、链接测试与页面集合测试。记录核对了哪些操作、发现哪些不符。

## Implementation guardrails

- 只写使用者视角：不写架构、模块划分、构建与测试命令；源码构建与打包留在仓库根 README。
- 不承诺未实现能力：未确认的功能、未上线的入口不写进指南。
- 截图或示意图仅在能表达文字说不清的界面结构时使用，并以本地资源提交。
- 中英两版在同一提交内完成。
