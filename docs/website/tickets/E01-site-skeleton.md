# E01 — 建立双语文档站点骨架与链接测试

**Status:** ready-for-agent — 本地制品，未发布 GitHub。稳定标识：`docs-site-01`

**规格：** [编辑器文档站点规格](../specs/docs-site.md)。覆盖用户故事：9、19、20、24。

## What to build

在仓库内建立读者文档工作面的骨架：一个可构建、可本地预览的双语站点，包含英文与中文两棵树、对应的首页、语言切换入口、按"使用指南 / 插件系统对接"两条线组织的侧栏，以及"页面集合一致 + 站内链接可解析"的测试。本单只交付骨架与机制，正文内容由后续工单填入。

## Acceptance criteria

- [ ] 站点工作面独立于 `docs/`，内容全部手写在该目录内；`docs/` 不参与构建、不出现在站点任何链接中。
- [ ] 英文与中文两棵树的页面路径一一对应，每页提供指向对侧同一页面的切换入口（互跳对应页，不退回首页）。
- [ ] 侧栏与顶部导航按"使用指南 / 插件系统对接"两条线组织，与目录结构一致；两条线各自有可见的栏目首页。
- [ ] 站点配置写明目标站点地址与带仓库名前缀的资源根路径，并相邻注明仓库改名时两处需同步修改。
- [ ] 站点可构建、可本地预览，中英两版页面直接访问均正常；构建命令、预览命令与测试命令各自只有一个人口。
- [ ] `tests/doc-sources` 在两类故障下失败：缺页与多页；`tests/links` 能定位到具体页面与具体链接。
- [ ] 仓库忽略规则覆盖依赖目录与构建产物，并注明构建产物为可再生产物故不入库。

## Prerequisites

- Node 工具链（node 与 npm）可用。**当前环境未安装**，本单第一步是核对；未满足前不开始编码，也不擅自安装。
- 包管理器与锁文件策略在实施时确定，并保持可复现安装。

## Blocked by

无 — 可以立即开始（受上方前置条件约束）。

## Verification

在本机运行站点构建与预览，逐页打开中英两版；运行站点测试并故意制造一次缺页与一次断链，确认两类测试都能失败并给出可定位信息。记录实际命令、结果与未满足的前置条件。

## Implementation guardrails

- 骨架不预置空占位正文页面：只建立栏目首页与机制，避免上线空页被读者看到。
- 不引入数学公式渲染、交互式组件演示、版本目录或在线服务依赖。
- 自定义 Markdown 插件本单只接入最小必要能力，不建立通用插件框架。
- 新增配置与脚本必须带注释；保留工作区已有改动，不顺手重构无关文件。
