# 主题插件格式

主题插件用 plugin.toml 声明一个 JSON 文件。主题文件只能设置宿主公开的组件槽位，不执行代码，也不使用 CSS 选择器。

~~~toml
[plugin]
id = "example.calm-theme"
name = "Calm Theme"
version = "1.0.0"
host_version = ">=0.1.0"

[theme]
file = "theme.json"
~~~

主题文件的 schema_version 当前为 1。一个文件可以同时定义浅色和深色主题：

~~~json
{
  "schema_version": 1,
  "themes": [
    {
      "id": "calm-dark",
      "name": "Calm Dark",
      "mode": "dark",
      "window": {
        "background_appearance": "opaque"
      },
      "colors": {
        "background": "#1e1f22",
        "surface": "#2b2d30",
        "hover": "#393b40",
        "border": "#43454a",
        "foreground": "#dfe1e5",
        "muted_foreground": "#9da0a8",
        "selection": "#2e436e",
        "accent": "#3574f0",
        "accent_hover": "#4682fa",
        "accent_active": "#2f65ca"
      },
      "typography": {
        "ui": { "family": "Segoe UI", "size_px": 14 },
        "mono": { "family": "Cascadia Mono", "size_px": 14 }
      },
      "plugins": {
        "terminal": {
          "typography": {
            "content": { "family": "Cascadia Mono", "size_px": 15 },
            "tab": { "family": "Segoe UI", "size_px": 14, "bold": true }
          },
          "ansi": { "red": "#ff7673", "yellow": "#d7ba7d" },
          "ui": { "tab_bar": { "background": "#2b2d30" } }
        }
      },
      "components": {
        "explorer-row": {
          "hover": { "background": "#393b40" },
          "selected": {
            "background": "#2e436e",
            "border": "#3574f0"
          }
        },
        "editor-tab": {
          "base": {
            "background": "#2b2d30",
            "foreground": "#9da0a8",
            "border": "#43454a"
          },
          "selected": {
            "background": "#1e1f22",
            "foreground": "#dfe1e5"
          }
        }
      }
    }
  ]
}
~~~

宿主的 `colors` 和 `components` 颜色支持 `#RRGGBB` 与 `#RRGGBBAA`；最后两位 `AA` 是透明度，`00` 为完全透明，`80` 约为 50% 不透明，`FF` 为完全不透明。背景颜色中的透明度只作用于背景，不会降低文字或子元素的透明度。`components` 可省略；每个组件可提供 `base`、`hover`、`selected` 和 `active` 状态，每个状态可设置 `background`、`foreground`、`border`、`radius_px`、`font_size_px`、`padding_x_px` 和 `padding_y_px`。尺寸使用像素，范围为 0 至 128。可选字段的 `null` 与省略表示沿用主题全局色或控件默认值。

## 窗口背景与毛玻璃

`window.background_appearance` 控制原生窗口背景，切换主题或更新主题包时同步应用到已打开的主窗口及原生对话框；新窗口也继承当前配置。旧主题省略 `window` 时默认为 `opaque`。

| 值 | 效果 |
| --- | --- |
| `opaque` | 不透明窗口；元素的半透明背景与窗口内部背景混合 |
| `transparent` | 透过透明区域显示窗口后方的桌面或其他窗口 |
| `blurred` | 透过透明区域显示模糊后的桌面或其他窗口；具体效果依赖系统支持 |

毛玻璃作用于整个原生窗口后方，不会模糊窗口内部的代码、菜单或文字。启用 `blurred` 后，还需将相应背景改为带透明度的颜色。不透明父背景会遮住毛玻璃；需要透出桌面的区域，其下方各层都应透明或半透明。例如，可把 `colors.background` 和 `components.app-shell.base.background` 设置为 `#ffffff00`，让 `components.explorer-tree.base.background` 使用 `#ffffffCC`，并相应调整文件树行背景；其他区域仍可保留不透明背景。窗口根节点不再额外重复填充背景，避免同一个透明度叠加两次。

内置 [default.json](../crates/editor-app/assets/themes/default.json) 是完整参考样式表：两套主题都显式列出窗口配置、17 个组件的全部四种状态及所有样式字段、全局字体和已声明的插件字体角色。未覆盖的可选字段使用 `null` 表示继承。默认仍为 `opaque` 与不透明配色，编辑其中的字段即可开启透明度或毛玻璃。

每套主题可通过顶层 `typography.ui` 和 `typography.mono` 设置全局 UI 与等宽字体；`family` 为字体名，`size_px` 为 8 至 64 的像素字号，`bold` 为是否加粗。`plugins` 对象按插件 ID 配置专属样式；其中 `typography` 按插件自定义的文字角色配置同样的字体属性，其余字段为颜色树，叶节点仍使用 `#RRGGBB`，与插件运行时的 RGB 数值颜色契约保持一致。宿主把路径展开为插件运行时键，例如 `plugins["terminal"].ansi.red` 对应 `terminal.ansi.red`。旧版平铺的 `plugin_colors` 仍可读取；新主题请使用 `plugins`，同名键以 `plugins` 中的值为准。

运行时插件从 `Environment` 读取全局颜色、字体及自己的角色样式。宿主在切换内置主题或已安装主题包时发送 `Event::Theme(Environment)`；插件应据此重绘界面。当前主题声明的属性优先于插件私有配置，未声明的插件文字属性继承全局 `typography.ui` 或 `typography.mono`。终端插件的颜色和字体角色见[终端插件说明](../plugins/terminal/README.md)。

当前组件 ID：

| ID | 用途 |
| --- | --- |
| app-shell | 主窗口内容区 |
| window-title-bar | 窗口标题栏 |
| project-badge | 标题栏项目标记 |
| explorer-tree | 文件树背景和文字 |
| explorer-row | 文件树行及交互状态 |
| explorer-menu | 资源管理器右键菜单及悬停状态 |
| editor-tabs | 编辑器标签栏 |
| editor-tab | 编辑器标签及选中状态 |
| editor-tab-close | 标签关闭按钮 |
| editor-tab-drag-preview | 编辑器标签拖动预览 |
| editor | 编辑区 |
| scrollbar | GPUI 滚动条滑块及悬停/拖动状态 |
| panel-toggle | 面板切换按钮的选中状态 |
| dock-title-bar | Dock 标题栏 |
| dock-tab | Dock 标签及选中状态 |
| dock-drag-preview | Dock 标签拖动预览 |
| status-bar | 底部状态栏 |

组件 ID 与属性名是宿主主题契约的一部分；宿主新增可定制样式时扩展该契约，未知 ID 或属性会在读取时被拒绝。
