# 主题插件格式

主题插件用 plugin.toml 声明一个 JSON 文件。主题文件只能设置宿主公开的组件槽位，不执行代码，也不使用 CSS 选择器。

~~~toml
[plugin]
id = "example.calm-theme"
name = "Calm Theme"
version = "1.0.0"
host_version = ">=0.1.0"

[theme]
file = "theme.json"
~~~

主题文件的 schema_version 当前为 1。一个文件可以同时定义浅色和深色主题：

~~~json
{
  "schema_version": 1,
  "themes": [
    {
      "id": "calm-dark",
      "name": "Calm Dark",
      "mode": "dark",
      "colors": {
        "background": "#1e1f22",
        "surface": "#2b2d30",
        "hover": "#393b40",
        "border": "#43454a",
        "foreground": "#dfe1e5",
        "muted_foreground": "#9da0a8",
        "selection": "#2e436e",
        "accent": "#3574f0",
        "accent_hover": "#4682fa",
        "accent_active": "#2f65ca"
      },
      "components": {
        "explorer-row": {
          "hover": { "background": "#393b40" },
          "selected": {
            "background": "#2e436e",
            "border": "#3574f0"
          }
        },
        "editor-tab": {
          "base": {
            "background": "#2b2d30",
            "foreground": "#9da0a8",
            "border": "#43454a"
          },
          "selected": {
            "background": "#1e1f22",
            "foreground": "#dfe1e5"
          }
        }
      }
    }
  ]
}
~~~

所有颜色使用 #RRGGBB。components 可省略；每个组件可提供 base、hover、selected 和 active 状态，每个状态可设置 background、foreground、border、radius_px、font_size_px、padding_x_px 和 padding_y_px。尺寸使用像素，范围为 0 至 128。未提供的值沿用主题全局色或 GPUI Kit 默认值。

当前组件 ID：

| ID | 用途 |
| --- | --- |
| app-shell | 主窗口内容区 |
| window-title-bar | 窗口标题栏 |
| project-badge | 标题栏项目标记 |
| explorer-tree | 文件树背景和文字 |
| explorer-row | 文件树行及交互状态 |
| editor-tabs | 编辑器标签栏 |
| editor-tab | 编辑器标签及选中状态 |
| editor-tab-close | 标签关闭按钮 |
| editor-tab-drag-preview | 编辑器标签拖动预览 |
| editor | 编辑区 |
| scrollbar | GPUI 滚动条滑块及悬停/拖动状态 |
| output-panel | 输出面板 |
| panel-toggle | 面板切换按钮的选中状态 |
| dock-title-bar | Dock 标题栏 |
| dock-tab | Dock 标签及选中状态 |
| dock-drag-preview | Dock 标签拖动预览 |
| status-bar | 底部状态栏 |

组件 ID 与属性名是宿主主题契约的一部分；宿主新增可定制样式时扩展该契约，未知 ID 或属性会在读取时被拒绝。
