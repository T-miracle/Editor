# 维护者文档入口

本目录保存 AI 与维护者使用的项目基线、设计、工单与验收。面向使用者的文档正文在 [website](../website/README.md) 维护。

- [需求基线](需求整理.md)、[开发计划](开发计划.md)：历史项目依据。
- [协作与领域约定](agents/domain.md)、[议题跟踪器](agents/issue-tracker.md)：协作规则与 GitHub 授权。
- [插件文档](plugins/README.md)、[插件平台规格](specs/plugin-api-platform.md)：插件设计、实施与验收。
- [原生 UI 文档](ui/README.md)：宿主 UI 的规格、工单与验收。
- [文档站点设计](website/specs/static-docs-site.md)：站点维护约定。

新主题按 `主题/specs/`、`主题/tickets/`、`主题/verification/` 归档；仅在实际验收和交付后记录完成。历史基线保留当前主分支已有路径，不为单个 UI 功能迁移其他主题。
