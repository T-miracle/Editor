# Me Editor：已确认需求基线

状态：已确认（历史基线）

插件平台的后续已确认范围以 [通用插件 API 方案](../plugins/specs/plugin-api-platform.md) 为准；终端、公开能力、授权私有依赖准备与热更新替代本文件中相冲突的初期限制。原始阶段记录保留以便追溯。

## 技术与平台

- 使用 Rust 和 GPUI Kit 构建原生桌面代码编辑器；不使用 WebView 或前端 UI 技术。
- Windows 优先交付；macOS/Linux 暂仅保持可编译。
- 不 fork GPUI Kit；`EditorState` 是唯一内存文本、IME、选择、布局和会话 Undo/Redo 真相来源。
- 所有高亮由语言插件携带的 Tree-sitter WASM grammar 与查询规则提供，宿主运行时加载。
- 外部 LSP 仅走标准输入输出 JSON-RPC。

## UI、工作区与文档

- 首版默认简体中文，并通过 i18n 资源保留英文翻译。提供深浅主题，默认跟随系统。
- 固定可调三栏：文件区、编辑区、问题/Git/搜索区；首版不做自由停靠、多窗口或编辑组。
- 单根工作区；受信任工作区自动恢复文档与布局。
- 未信任工作区可编辑，但不启用插件、不启动语言工具、不采用项目工具路径。
- 文件树和搜索遵循 `.gitignore`；项目可用 `files.exclude` 追加规则。
- 首版完整支持 UTF-8/UTF-8 BOM；其他编码提示转换。
- 默认显式保存；异步语言结果、格式化与替换必须携带 revision，过期结果一律丢弃。

## 插件与工具链

- 首发独立语言插件：HTML、CSS、JavaScript、TypeScript、Vue、React、Rust；允许自动解析依赖。
- 插件只含清单、WASM grammar、查询、文件匹配和外部工具启动模板；不允许原生代码或 JavaScript 运行逻辑。
- 支持本地插件与公开 GitHub 链接；安装锁定 commit/hash，只显式更新；不支持市场、自动更新和私有仓库。
- 安装时展示权限；项目启用不重复提示。
- Node、Rust、Git、LSP 和格式化器均外置，不自动下载或安装。
- 工具路径：项目本地 → 项目本机覆盖 → 用户全局 → PATH/注册表/常见目录；缺失时只部分降级。

## 搜索、历史与 Git

- 支持文本、大小写、全词、正则搜索和替换预览；变化文件不得被盲目覆盖。
- 本地历史独立于 Git、不写入项目目录；保留 30 天或 1 GB，以先达到者为准。
- Git 支持状态、diff、历史、暂存、提交、分支、clone、fetch、pull、push；认证复用外部 Git、Credential Manager 与 SSH Agent。
- 批量替换及破坏性 Git 操作必须预览并明确确认。

## 设置作用域

| 设置 | 允许的位置 |
| --- | --- |
| 语言、主题、字体、历史上限 | 仅用户 |
| `files.exclude`、格式化策略、语言偏好 | 可共享项目 |
| 信任、实际启用插件、工具路径覆盖、恢复布局 | 仅本机工作区 |

项目设置不得覆盖用户语言、主题或信任状态。

## 首版不做

内嵌终端、任务执行、调试、在线插件市场、私有 GitHub 插件、内建工具链/凭据管理、非 UTF-8 无损编辑、多窗口和自由停靠。
