## What to build

终端在新协议下支持交互输入、会话与布局管理、主题和私有设置，并可热更新及卸载，不使用专属宿主接口。

广域迁移中的终端批次。复用已完成的类型化编辑器操作、进程能力、设置、组合 UI 和热事务，保留现有终端核心。

## Acceptance criteria

- [ ] 进程、剪贴板、文档/编辑器操作、存储和界面全部通过新版公开契约，不保留旧字符串命令。
- [ ] 申请明确的任意命令与所需数据权限，输入输出、空格、粘贴、IME 和交互式程序行为保持正确。
- [ ] 会话栏与画布组合通过通用布局实现，拖动尺寸、滚动、字体和主题热生效。
- [ ] 最小化、隐藏、禁用与卸载回收布局空间和资源，不留下空白区域或进程。
- [ ] 私有配置与已有逻辑快照按迁移约定保留，热更新失败恢复；不把恢复解释为继续执行已结束进程。
- [ ] 同步提升插件版本并生成包和 README，宿主不引入终端命令、VT 状态或 Shell 专属分支。

## Implementation guardrails

- 使用已确认的现有包管理器与编辑器集成测试边界，不新增插件专属测试入口。
- 只改变本工单范围，保留工作区已有改动；新增代码同时补充意图和不变量注释。
- 复用既有模块；必要的预重构先保持行为不变并通过相关回归，再加入新行为。
- 测试使用隔离目录与夹具，不操作用户真实插件安装数据；不提交 Git、不发布中间版本。
- 流程与契约细化若改变已确认产品行为，应先评审；不能以实现方便引入插件专属分支。
