**Parent:** [设计基线 #1](https://github.com/T-miracle/Editor/issues/1)

## What to build

示例插件的原生交互与 SVG 插件的未保存内容预览使用新版 UI 和文档能力，安装即生效，禁用后正确撤销。

广域迁移中的两个小型 UI 插件批次。使用相同公开能力验证标准组件与画布，不与终端迁移互相阻塞。

## Acceptance criteria

- [ ] 示例插件迁移面板、命令、输入及存储操作；无需权限的功能不扩大授权。
- [ ] SVG 预览订阅当前内存文档，正确处理未保存修改、文档切换和旧 revision。
- [ ] 矢量绘制、透明背景、缩放和尺寸变化通过通用画布能力，宿主不识别 SVG 插件 ID。
- [ ] 两类插件的主题、焦点、界面关闭和资源撤销保持正常，不留下预览空白区。
- [ ] 同步版本、SDK 使用、打包和 README，独立安装包通过公开能力协商。
- [ ] 移除本批旧协议调用，不改变与此次 API 迁移无关的业务行为。

## Implementation guardrails

- 使用已确认的现有包管理器与编辑器集成测试边界，不新增插件专属测试入口。
- 只改变本工单范围，保留工作区已有改动；新增代码同时补充意图和不变量注释。
- 复用既有模块；必要的预重构先保持行为不变并通过相关回归，再加入新行为。
- 测试使用隔离目录与夹具，不操作用户真实插件安装数据；不提交 Git、不发布中间版本。
- 流程与契约细化若改变已确认产品行为，应先评审；不能以实现方便引入插件专属分支。
