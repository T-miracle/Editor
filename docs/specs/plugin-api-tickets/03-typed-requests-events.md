## What to build

示例插件读取选区、保存文档、隐藏自身面板，并订阅文档变化；耗时请求有明确进度，可取消或超时，停用后不再收到事件。

用实际编辑器操作验证公共调用模型。统一错误、关联 ID、截止时间和订阅句柄，SDK 隐藏传输细节。

## Acceptance criteria

- [x] 读取选区、活动目录、保存及自身面板显隐使用类型化参数和结果，不新增拼接命令字符串。
- [x] 区分受理、进度和最终结果；即时操作可以直接完成，失败原因可在示例界面观察。
- [x] 请求关联由 SDK 处理；耗时任务支持截止时间与取消，并明确停止等待、尽力终止和未执行的区别。
- [x] 文档订阅可释放，文档事件包含有效版本语义；迟到或已取消的结果不覆盖当前状态。
- [x] 事件队列有上限，可合并事件保留最新语义；不可丢失数据流有背压或明确失败，不静默丢弃。
- [x] 停用实例后未完成请求结清，订阅解除，隐藏面板后空间回收且不能隐藏其他插件的面板。
