## 交付契约

- 依赖 artifact 可声明通用 `installer`：包内程序、参数数组、私有目标、用途及 service/project_sdk 分类。
- `dependencies.install` 独立于下载解包、固定服务及任意进程权限；静态方案和 WASM 钩子方案执行相同权限检查。
- 已授予安装权限也不能直接运行。宿主显示具体路径与参数，等待本次请求的一次性确认。无交互处理器的安装 API 失败关闭。
- 大型 SDK 在来源读取前要求用户主动勾选准备；下载校验后，再确认具体执行。拒绝前没有 HTTP 请求。
- 原生程序拥有实际 OS 权限，私有目录不代表系统沙箱；取消不承诺撤销外部副作用。
- 安装在临时私有目录内进行，安装定义参与缓存身份；保留旧下载型缓存身份。只有成功且入口存在/未逃逸才发布完成标记。
- Windows 原生执行保留 job，等待所有子进程退出和管道读者结束，再清理或发布目录。旧版本在准备失败时保留。
- SDK 对外文档见 [DEPENDENCIES.md](../../crates/plugin-protocol/DEPENDENCIES.md)。不引入插件或语言专属宿主入口。
