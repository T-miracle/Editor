# 通用 LSP 能力验证（GitHub #8）

日期：2026-10-02。比较基线：`891651fcede1e7a971869bf61746ff21af93137d`。

## 交付

- 独立 `language.lsp` 1.0、声明式 `language_servers`、可选 WASM 配置钩子。
- 固定服务方案与动态 program/argv 权限分离；动态启动另需声明并授权 `process.exec`。
- 用户显式程序路径优先且不静默回退；项目根限制在工作区内；配置节名称和初始化 JSON 不含宿主特定语言业务。
- LSP 独立选择，安装后对已打开、未保存文档启用诊断及导航；使用本机 stdio JSON-RPC。
- 共享进程所有权、工作区撤销、服务实例退休、文档生命周期租约和单调版本共同拒绝旧请求。
- 配置重新计算最终计划，仅替换实际有变化的服务；无关服务保持相同租约与进程。
- 有界 JSON-RPC 输入/输出、写入等待截止时间、请求超时取消、显式就绪通知匹配。
- 独立 SDK 示例升级为 0.6.0，公开契约 [LSP.md](../../crates/plugin-protocol/LSP.md) 随 SDK 导出。

旧发行语言的适配器与专属初始化逻辑保留至工单 16/#17 迁移；新能力不进入该路径。

## 验证

包检查先 RED 后 GREEN，使用独立 SDK 构建的 WASM、真实 stdio 夹具和现有 GPUI 发布边界。
全部安装、配置、日志及项目使用临时目录；夹具由 `cargo build -p plugin-runtime --example lsp_fixture` 构建。

- 未知语言在安装前打开并输入未保存文本；安装后实际返回诊断和定义位置，磁盘文本不变。
- 服务端记录插件生成的初始化数据、配置节响应和动态 argv；未经 `process.exec` 授权拒绝动态启动。
- 独立识别/高亮/LSP 包、竞争提供者保留现有选择、项目选择切换、卸载后唯一候选接替。
- 显式坏路径直接报错；同包另一个有效计划保持同一租约；非法 hook UI 输出不改变旧面板。
- 项目根逃逸拒绝；卸载后旧租约不能再启动进程。
- 进行中的请求因退休终止，等待连接锁的旧启动也被拒绝；重选同计划使用新适配器。
- 真实服务不响应请求时，30 秒后宿主发送 `$/cancelRequest`，线上的原操作只出现一次，没有重放。
- 关闭重开后旧版本诊断拒绝；倒置新同步与旧关闭的执行顺序，旧关闭不能撤销新文档，旧诊断请求不重启有效服务。
- 未换行的超长 LSP 头在 8 KiB 边界拒绝；原生进程能力 5 项完整回归通过。
- `cargo fmt --check`、`cargo check --workspace`、非 UI 工作区 39 项通过。
- 编辑器 162 项通过。既有全局语言注册表要求使用 `--test-threads=1`；默认并行跑曾暴露测试间注册表干扰，串行全量验证通过。
