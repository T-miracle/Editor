# 01：文档快照、事件与只读资源比较

稳定标识：`plugin-api-community-foundation-01-documents`

状态：实施与验收完成，最终双轴剩余发现均为 0；发布处理中。实际推送与 #93 关闭读回见[验收入口](../../verification/plugin-api-community-foundation/README.md)。

## What to build

用户通过独立插件读取当前未保存文档，打开历史内容或生成文本，并与当前文件进行差异比较。编辑、保存、切换、关闭和重新打开文档后，插件收到可验证的事件；旧结果不能指向新文档。虚拟内容只读且不必创建临时文件。

用“历史内容比较”和“生成文本预览”两类实际 SDK 插件贯通资源身份、文档快照/事件、原生 Tab 与差异呈现。夹具可以使用固定历史文本，不要求实现完整 Git Provider。

## Acceptance criteria

- [x] T01：枚举/打开文档、范围读取和快照取自当前 DocumentSession/EditorState，包含 dirty、语言、编码、EOL 和 revision；不得维护第二份可变文本。
- [x] T02：打开/关闭/内容变化/保存前后/活动文件/选区/视口事件、订阅取消和溢出补读可观察；关闭重开的文档身份与旧引用区分。
- [x] T03：目标和 revision 校验、读取权限及坐标转换正确，覆盖 CRLF、中文及非 BMP 字符；资源标识不是访问授权。
- [x] T04：本地和只读虚拟资源使用统一身份与显式能力，两个插件能够打开、刷新、导航和比较内容；Tab 不成为独立工具页面，虚拟文档拒绝编辑和保存。
- [x] T05：插件禁用/退役、关闭文档及失败重载后，订阅和虚拟提供者资源正确清理，界面不继续接受失效结果。
- [x] 完成公共 C01–C06：正式 SDK、错误/释放与有界事件契约、注释、站点说明、实际包、权限/清理、原生交互及规定交付检查。

## 实施边界与预重构

先整理既有文档身份/版本与快照读取的重复映射，保留当前消费者行为并验证，再加入通用资源与只读提供者。复用现有文档请求和订阅入口，不另造插件专用文档会话。

以现有清单命令和原生入口演示，不依赖 02 尚未完成的新命令调用协议。当前协议模型允许的资源扩展与当前消费者同步迁移，不重新启用历史协议分支。若确有无法保持可编译的广域迁移，记录具体影响后调整实施方案，不默默扩展工单。

不实现工作区写入、可写虚拟文件系统或跨文件事务。冻结可供后单复用的资源/事件基础和稳定性规则，但不预先发布没有消费者的远程接口。

## 测试安排

主责 T01–T05。复用既有文档请求、作用域隔离、纯语言快照及原生文本测试先例；新增两个实际插件的读取/比较闭环，覆盖过期、权限、关闭和有界事件失败行为。

此单一次完成资源身份与文档事件的详测，后单调用同一套测试，不复制坐标、身份与溢出矩阵。资源身份变动必须重跑既有编辑/语言消费者的针对性回归。虚拟文档的键盘、焦点、滚动、主题和只读可见结果做 Windows 原生验收。
