# 05：通用树与编辑器装饰

稳定标识：`plugin-api-community-foundation-05-presentation`

状态：已批准，待实施；发布标签 `ready-for-agent`。实际设计议题及依赖编号见发布记录。

## What to build

用户可以展开并分页浏览插件提供的树、选择节点和执行节点菜单。在编辑器内看到书签图标、覆盖率范围和悬浮说明；输入或 Undo 后标记保持正确位置。

Todo 树与数据库对象树复用同一树接口，书签与覆盖率复用同一装饰接口。宿主管理原生滚动、焦点、键盘与绘制，插件提供领域数据，不复制大纲专用实现给每类插件。

## Acceptance criteria

- [ ] T21：两个独立领域树支持展开时加载、分页、刷新、选择、节点菜单、取消及迟到结果拒绝；节点身份和请求版本明确。
- [ ] T22：原生虚拟化、键盘导航、焦点、错误重试可用，长列表不阻塞 UI；折叠或退役后不继续应用旧子节点结果。
- [ ] T23：两个独立消费者提供行号旁图标、范围标记和悬浮说明，编辑与普通 Undo 后位置跟踪正确，不改变文件内容。
- [ ] T24：深浅主题、缩放、滚动、基础无障碍及相关中英文正确；关闭文档、禁用或替换提供者后树与装饰资源撤销。
- [ ] 既有大纲、插件布局和两组底栏职责不退化；不引入 WebView 或将插件业务菜单搬回宿主。
- [ ] 新接口具备实例所有权、限额、取消、错误和正式 SDK/文档，并完成公共 C01–C06。

## Blocked by

- 01：文档快照、事件与只读资源比较——提供文档目标、读取与变化事件。
- 02：插件命令、宿主交互与选择授权——提供节点命令、菜单贡献及交互基础。

## 实施边界与预重构

先核对现有原生树/大纲行为接缝和主题契约，提取有实际复用价值的数据呈现部分并保持原行为，再接任意领域数据。位置跟踪依托原生编辑状态与文档变更，不维护第二份 Rope。

本单无需等待 03：Todo 验证使用已打开文档快照及事件，数据库树使用受控异步数据；不为树接口验收额外建设数据库连接或工作区索引。编辑跟踪先用普通文本编辑/Undo 验证，批量修改后的组合由 07 补充。

不实现复杂行间按钮、嵌入式编辑面板、完整文件树徽标系统或数据库产品功能。

## 测试安排

主责 T21–T24。共用真实包和原生 UI 夹具，但树与装饰分别有两个消费者；不靠同一消费者改插件 ID 冒充领域通用性。

复用 T02–T03 的文档事件/坐标断言和 T06–T07 的命令/菜单断言；新增自己的节点分页、迟到结果、位置跟踪及撤销测试。主题/焦点/缩放只详测本单新增控件和装饰，不重跑未变化的快选/通知全部矩阵。
