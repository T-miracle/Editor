# 06：云服务查询、密钥与后台刷新

稳定标识：`plugin-api-community-foundation-06-cloud`

状态：已批准，待实施；发布标签 `ready-for-agent`。实际设计议题及依赖编号见发布记录。

## What to build

用户在云翻译或代码托管查询插件中输入 Token/API Key，宿主安全保存。插件通过通用 HTTP 获得流式结果，显示进度并允许取消，通过私有缓存和可释放定时器刷新。禁用插件后请求、流和计时器停止，其他插件无法读取其密钥或私有数据。

两个独立插件共用正式网络、密钥和私有状态能力，不通过原生辅助进程、图片下载或依赖安装接口绕行。首发不实现浏览器登录或 AI 功能。

## Acceptance criteria

- [ ] T25：正式 SDK 支持方法、头、请求体和流式响应；两类插件完成分块显示、成功、错误及取消闭环。
- [ ] T26：代理/TLS、目标权限、重定向、大小/时间限额及回压得到验证；读取密钥不代表可向任意目标发送。
- [ ] T27：系统安全设施提供按插件隔离的密钥读取/更新/删除及撤销；Token 不进入普通设置、日志和普通快照，权限与网络独立。
- [ ] T28：私有数据和密钥不可跨插件读取；公开服务调用检查调用方权限，不转交 Token、不借用提供者的权限。
- [ ] T29：私有目录枚举/查询/改名/删除、缓存和临时数据生命周期及配额完善；timer/debounce 支持刷新，私有数据不落工作区。
- [ ] T30：取消、禁用、信任撤销、退役及失败更新释放本单资源；旧版本与受管数据按既定恢复规则保留，密钥不因快照而泄漏。
- [ ] 离线、拒绝权限、系统密钥设施不可用等情况返回清晰原因，不能静默退化为明文存储。
- [ ] 完成公共 C01–C06，包括真正经过宿主 HTTP 和系统密钥实现的 Windows 验收。

## Blocked by

- 02：插件命令、宿主交互与选择授权——提供 Token 输入、命令结果、通知及取消交互。

## 实施边界与预重构

先梳理既有实例资源撤销、私有根与网络下载边界，保持原用途行为，再增加可协商的一般 HTTP、密钥、私有管理与计时能力。使用同一既有资源所有权机制，不复制另一套插件权限系统。

无需等待工作区写入：本单仅管理私有数据；复用既有文件读写和隔离根。此阶段仍可按当前实例启用机制运行并立即正确清理资源，声明后台用途；按命令/视图等需求延迟激活由 07 统一接通，不把本单的禁用清理延期。

服务 schema 与事件流只补本单真实消费者所需类型、错误、分页或分块语义；不预造完整账号平台、WebSocket 家族或任务调度系统。

## 测试安排

主责 T25–T30。共用受控 HTTP/代理端点产生流、超时、错误及重定向，但插件必须通过正式网络入口。用实际系统密钥设施的独立测试命名空间验证写入/读取/删除，测试后清理；不使用真实用户密钥。

Token 输入和通知只做本单连接测试，完整 UI 行为引用 T08–T10。服务权限复用既有公开服务测试先例，新增跨插件密钥访问拒绝和授权不传播用例。流和定时器循环启停验证资源回落，不能以 UI 隐藏代替取消成功。
