# 02：插件命令、宿主交互与选择授权

稳定标识：`plugin-api-community-foundation-02-interaction`

状态：已批准，待实施；发布标签 `ready-for-agent`。实际设计议题及依赖编号见发布记录。

## What to build

用户从上下文菜单或命令入口运行插件，完成快选、输入、文件/目录/保存位置选择，并通过有来源的通知和可取消进度获知结果。插件可以调用正式命令并取得类型化结果，取消与失败不会被当作成功。

以“选择文件并显示基本信息”和“分步骤选择并运行可取消检查”两个插件演示。工作区外目标通过用户选择获得受限授权；本单先贯通选择与授权读取，写入和跨文件操作由 03 完成。

## Acceptance criteria

- [ ] T06：命令注册/发现/调用、参数校验、返回值、错误及取消完整；跨插件调用不得绕过调用方权限和实例作用域。
- [ ] T07：编辑器、文件树、Tab 与选区等宿主位置支持菜单分组/排序、上下文条件、可见及启用状态，实例禁用后移除；不混合两组底栏按钮职责。
- [ ] T08：快选、输入、打开文件/目录及保存选择具备确认、取消、关闭和异步结果；不要求插件自建整套面板。
- [ ] T09：用户选择外部目标后取得限定对象、操作和实例的授权，不能伪造、借用或转授句柄；限定读取从正式 API 完成，退役和取消后无残留授权。
- [ ] T10：通知/确认/消息来源/进度与取消调用进入现有宿主 UI；焦点恢复、键盘、IME、中英文、深浅主题及基础无障碍正确。
- [ ] 实例消失、调用超时、关闭窗口和迟到回复得到明确终态；未授权插件不能借菜单或文件选择取得任意访问。
- [ ] 完成公共 C01–C06，发布可被文件、树和云插件复用的正式交互接口，而非仅在测试或某插件中可调用。

## Blocked by

None (can start immediately after approval).

## 实施边界与预重构

先整理现有命令事件与宿主消息/本地控件的通用调用边界，保持当前交互不变并验证，再增加有结果的调用和贡献注册。复用现有原生控件及资源归属，不复制上游 UI 或消息系统。

独立于 01：菜单上下文使用现有活动编辑器信息，文件选择返回受权资源句柄，所选文件读取复用已有读取路径；不以新文档枚举或虚拟资源作为本单前提。保存位置选择只授予有限意图/句柄，不在本单暗中增加任意磁盘写入。

## 测试安排

主责 T06–T10。真实插件调用经过公开 Manager 和宿主原生入口；可控延迟用来验证取消/超时，不增加测试专用命令 API。通知复用既有宿主消息测试先例，但必须新增实际插件来源证据。

文件选择授权的归属、取消和限定读取详测归本单；03 负责实际文件操作的路径攻击与写入矩阵。后续插件只检查自己的请求能进入本单接口，不重做每种对话框的完整输入/焦点矩阵；改动公共控件时例外。
