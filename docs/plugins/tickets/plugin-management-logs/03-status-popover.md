# 03 — 底栏持续提醒与摘要直达日志

**Status:** completed — 已实现并通过行为验收，2026-10-04。
GitHub：[#25](https://github.com/T-miracle/Editor/issues/25)；父方案：[#22](https://github.com/T-miracle/Editor/issues/22)。
规格：[插件管理与运行日志改造](../../specs/plugin-management-logs.md)。

## What to build

插件发生异常后底栏持续提醒；用户点击看到 A 方案按插件分组的最新异常摘要，并可直达该插件完整日志。两个入口共享已读记录，同时区分底栏本轮提醒是否已查看。

## Acceptance criteria

- [x] 底栏图标优先级为错误、警告、loading，警告与错误颜色正确，查看前持续显示。
- [x] 查看后确认本次底栏提醒；仍加载时恢复 loading，否则隐藏，新异常再次提醒。
- [x] A 方案按插件分组，名称、摘要、原因、时间和来源层次清晰；每插件仅展示最新一条警告或错误摘要。
- [x] 原有正常加载状态仍可查看，点击摘要打开插件管理并定位对应日志 Tab。
- [x] 只有实际展示摘要标为已读，旧未展示记录保持未读但不重新唤起本次已确认底栏提醒。
- [x] 完整日志页同步清除对应插件底栏提醒，其他插件与并发新异常保留。
- [x] 最新摘要为警告但更早存在未读错误时，严重程度仍正确；不将“已看过”表示为“已修复”。

实现与实际验收见[底栏提醒与摘要验证](../../verification/plugin-status-popover-verification.md)。
