## What to build

安装宿主从未认识的语言资源包后，已打开文件立即获得识别与高亮；另一个包可以替换其能力，卸载后按候选数量接替或降级。

移除固定语言枚举对新注册路径的限制，贯穿声明、贡献目录、解析器注册、文档更新和选择界面。语言服务本身留给工单 07。

## Acceptance criteria

- [x] 语言来自已安装且有效的声明，一个包可贡献多个语言；不必附带无业务用途的 WASM 组件。
- [x] 语言识别与高亮提供者分别注册，按全局和项目设置选择，不按安装顺序覆盖已有有效选择。
- [x] 安装、启停和卸载影响已打开文档，无需重新打开或重启；旧贡献异步结果不得重新注册。
- [x] 选中提供者移除后，一个候选自动接替，多个候选提示选择，无候选明确降级。
- [x] 高亮只使用插件 WASM grammar；不得以宿主内建 grammar 作为新语言接入的替代。
- [x] 保留图标及现有资源贡献行为；新增路径不含固定语言集合，现有语言包暂未迁移不阻止此独立路径演示。
