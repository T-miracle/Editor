## What to build

用户在底部左侧通过窗口按钮控制窗口显隐，在短竖线右侧通过插件工具控制当前文件或活动插件窗口的功能。多个插件可一起提供适用工具。插件自己的按钮切换中心显示模式，并通过公开私有存储让同工作区同类文件一起切换、重启后恢复。

## Acceptance criteria

- [x] 左侧窗口按钮组只控制窗口显隐，插件窗口贡献和系统文件树入口均可使用；仅提供中心布局的插件不自动产生窗口按钮。
- [x] 右侧插件工具按钮组与窗口组用短竖线分隔；插件声明功能、图标、中英文提示、适用条件和选中／禁用状态，并处理业务事件。
- [x] 同一个插件可分别贡献两类按钮；多个适用插件可同时贡献工具，辅助插件仍不能改变所选提供者的整体布局。
- [x] 工具组跟随当前文件或活动插件窗口；点击底栏取得焦点后仍作用于原功能目标，目标失效或状态过期时拒绝事件。
- [x] 两组分别使用各自的“更多”溢出菜单，底栏保持单行与分隔关系；溢出项保留原状态、目标、键盘和事件行为。
- [x] 独立插件通过工具按钮改变自身布局，使用公开私有存储保存显示偏好，不要求宿主增加插件专属模式、同步或工具栏显隐字段。
- [x] 同工作区同类文件一起切换显示模式，不同工作区独立，重启恢复；每个文档的文本、选择、光标、滚动与 Undo／Redo 仍互相独立。
- [x] 多实例在同一偏好范围内保持一致；偏好只是待应用意图，实际窗口、布局、文档与权限仍由宿主校验。
- [x] 包内图标和默认领域配色可经通用接口供宿主绘制，主题覆盖、深浅主题和缩放有效，资源缺失／跨包引用按公开契约拒绝。
- [x] 贡献停用、移除或目标切换后撤销按钮、订阅和事件；原生控件继续采用项目本地外观与既有行为基座，内置和第三方接口相同。
