# 04 — 现有插件与用户数据迁移

**Status:** in_progress — 前置 #64 已验收并关闭，在独立分支连续迁移真实插件与旧显示偏好。

议题：[工单 #65](https://github.com/T-miracle/Editor/issues/65)。

稳定标识：`plugin-ui-decoupling/04-plugin-migration`

## Parent

[总方案 #61](https://github.com/T-miracle/Editor/issues/61)。用户故事主责：18、37、39、48。验收主责：U08、U10、U12；U19、U20 在本单完成真实迁移包回归，最终复核由 05 承担。

## What to build

用户继续使用 Markdown、Image 和终端功能，但它们的布局、工具按钮、图标、内容默认配色和显示偏好来自插件自身。Image 已在 01 由原 SVG 插件升级，本单完成它的通用布局、工具和历史偏好迁移，不重复改名或扩展图片格式。现有用户设置迁移后继续生效，安装这些插件不再需要宿主专属业务。示例及语言插件中受影响的资源和消费者一起完成适配。

将迁移作为一个粗批次连续处理，不为每个图标、开关或插件再创建工单；范围限于已经成熟的公开能力及受影响功能，不顺带重写各插件领域实现。

## Acceptance criteria

- [ ] Markdown 的编辑／分栏／预览布局、同步滚动与顶部格式工具栏显隐由插件提供和处理，功能按钮位于右侧工具组；保留现有格式、链接、任务框、图片和语法高亮行为。
- [ ] Image 的布局、图标及交互改用同一公开路径，保留 SVG 源码编辑与未保存预览、其他格式只读、默认原尺寸／超区等比缩小及手动缩放、透明背景、主题与尺寸响应。源码模式按钮仅在有文本编辑能力的 SVG 上适用，不给其他图片创建编辑面板。
- [ ] 终端窗口显隐入口位于左组，新建终端和菜单等功能位于右组，图标和 ANSI 默认调色板由插件提供；Shell、PTY、输入和尺寸变化保持原有职责与行为。
- [ ] Markdown 内容默认配色、文件／面板／工具图标及其他受影响资源放入对应插件，用户主题可通用覆盖；宿主保留原生控件统一外观而不提供插件专属默认值。
- [ ] 旧预览模式、同步滚动及工具栏显隐偏好有限迁移到插件私有数据，包含原 SVG 到 Image 的显示设置；按工作区／类型恢复并一起切换，SVG 的源码布局偏好不错误应用到其他图片类型。冲突、重复迁移与不适用数据有可测试规则，不清空其他设置。
- [ ] 示例和已有语言插件的受影响图标、资源及公开消费者完成迁移，不删能力、不改无关领域行为、不扩大权限。
- [ ] 移除对应宿主专属模式按钮、业务处理、图标兜底与活跃偏好字段；需要保留的有限数据导入只用于迁移，不成为旧协议运行分支。
- [ ] 修改并交付的插件包提升清单版本，协议与能力声明、资源、SDK 消费者及独立构建产物一致；内置与第三方采用同一公开接口。
- [ ] 真实包迁移后保留未保存文本、Undo／Redo、焦点与中文 IME；Markdown 持续输入、首次打开、编辑区高度及同步滚动有实际回归证据，已知卡顿不因迁移自动标为解决。

## Verification

按插件完成对应独立构建和真实包针对性验收，作为同一批次连续推进。使用历史设置样本验证迁移、重复执行、重启、不同工作区与非相关数据保留；通过原生界面验证实际模式、同步、格式工具栏、Image 与终端工具，而非只检索宿主符号。回归 Image 的编辑／只读区别及尺寸适配，避免底栏和偏好迁移覆盖 01 的默认规则。

构建受影响包后显式执行相关 ignored 用例，回归输入、IME、焦点、主题、尺寸及资源清理。阶段内复用不受后续改动影响的有效结果；交付时执行一次仓库基础检查，并验证实际独立 SDK 消费者。统一故障组合、全部契约和跨插件最终验收由 05 收口。
