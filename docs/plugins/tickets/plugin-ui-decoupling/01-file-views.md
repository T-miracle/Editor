用户于 2026-10-05 补充：将现有 SVG 插件扩展为名为 `Image` 的通用图片插件，SVG 保留编辑能力，其他图片格式暂时只提供预览；默认按图片自身尺寸显示，超过预览区域时等比缩小到完整可见。本补充扩展了 #61 原先只以 PNG 夹具验证非文本显示的交付范围；图片修改、编码转换和导出仍不进入本单。

## What to build

在现有 SVG 插件上升级交付 `Image`，用户打开 SVG 时继续编辑源码并查看未保存内容的预览；打开其他支持的图片时只显示预览，不创建文本编辑会话。首期复用现有格式能力，覆盖 SVG、PNG、JPEG（jpg／jpeg）、GIF 和 WebP，发行包明确声明匹配范围。

图片默认以自身宽高显示，较小图片不放大；超过当前可绘制区域时保持宽高比缩小，保证整张图片可见。打开、切换图片和自动适配状态下调整预览区域，都根据当前图片尺寸与区域重新计算。查看器失败时文件仍保持打开，显示准确原因并可重试；切换回普通文本文件仍可正常编辑、保存和关闭。

把插件升级、文件身份、受控图片访问、中心显示与生命周期沿同一条产品路径打通，交付可直接演示的实际 `Image` 包。可组合编辑布局由 02 扩展，底栏及偏好能力由 03 建立，`Image` 的模式、按钮和历史显示偏好在 04 与其他插件一起迁移，不重复进行插件改名或格式扩展。

## Acceptance criteria

- [x] 在现有 SVG 插件基础上升级，用户可见名称统一为 `Image`；正式交付实际包并声明支持格式，不以一个仅用于测试的新查看器代替。更新包版本及独立构建产物，保留已有安装、启用和私有数据；如调整包标识，采用有限、可测试的通用迁移，不在宿主写专属运行分支。
- [x] 文件 Tab 只表示已打开文件；SVG、PNG、JPEG、GIF、WebP 与文本文件共用原有文件 Tab 栏，不创建独立插件 Tab。
- [x] SVG 保留原生源码编辑、未保存内容预览、Undo／Redo、磁盘重载及解析错误恢复；不把“可编辑”扩大为新的可视化矢量编辑器。
- [x] 其他支持的图片格式只读预览，通过受控文件上下文和资源读取，不调用文本解码／编辑路径、不依赖伪造的文本 revision，不显示文本编辑入口，关闭不触发文本保存操作。
- [x] 默认尺寸采用图片固有宽高；SVG 按自身画布尺寸确定，其他格式按解码后尺寸确定。废除原 SVG 默认最长边固定 240px 的规则，较小图片不自动放大。
- [x] 图片宽度或高度超过实际预览内容区域时等比缩小，完整可见，无拉伸、默认裁切或宽高比变化；尺寸刚好合适时保持原尺寸。自动缩放比例为 min(1, 可用宽度 ÷ 图片宽度, 可用高度 ÷ 图片高度)。
- [x] 自动适配状态下切换图片、调整预览区域或修改 SVG 内在尺寸后重新计算；区域扩大后最多恢复原尺寸。既有 SVG 手动缩放交互保留，默认适配规则不等于禁止用户主动放大。
- [x] `Image` 从实际包经公开 Manager 安装后显示对应图片，宿主不按 `Image`／SVG 插件 ID 或具体图片扩展名执行专属绘制、缩放和编辑分支；适用格式和展示策略由插件提供。
- [x] 文本会话成为可选资源；普通 UTF-8／UTF-8 BOM 文件的编辑、未保存提示、保存、关闭与语言接入保持正常，唯一文本状态不变。
- [x] 查看器不可用、停用、图片损坏或超过解码资源预算时保留文件 Tab，说明准确原因并提供重试；没有文本能力的文件不出现强制普通编辑回退。SVG 仍可使用其原文本能力恢复编辑；仅超出预览区域的图片应缩小显示，不误报为解码资源超限。
- [x] 文件关闭、切换或同路径重开后，旧显示结果和文件资源不能作用于新目标；基本资源清理在本单完成。
- [x] 新能力拒绝未协商版本、受限工作区、未授权读取、越界路径及错误资源归属，权限不能由插件配置授予。
- [x] 本单公开文件显示契约、必要能力协商、SDK、`Image` 包与独立验证夹具同步更新；通用解码和原生绘制仍由宿主提供，已有能力的消费者保持可验证，不增加旧协议运行分支。

## Verification

通过实际 `Image` 包进入现有 Package／Manager 和原生宿主，验证 SVG 编辑与未保存预览、其他声明格式只读、文本切换、无查看器／失效／重试、关闭重开和资源拒绝。另保留不同身份的最小文件显示夹具，证明宿主不依赖正式插件名称。断言可见结果与公开行为，不断言内部 EditorState 数量或私有映射。

尺寸验收覆盖：小图原尺寸、刚好容纳、仅宽度超出、仅高度超出、两个方向均超出、横图／竖图、区域缩小再扩大、切换不同尺寸图片及 SVG 修改尺寸。均检查宽高比与完整显示，自动适配不超过原尺寸；手动缩放作为独立交互回归。损坏、超预算和不支持格式显示明确原因，不用缩放绕过资源限制。首期复用现有静态解码，不新增动画播放、图片修改或导出功能。

必要预重构先保持现有文本行为完成并回归，再增加非文本打开能力。协议、运行时及应用测试按本单影响范围执行；实际 WASM 显式运行相关 ignored 用例。交付时执行仓库基础检查，SDK 变更追加分发验证，不重复运行与本单无关的全部插件场景。
