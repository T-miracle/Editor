## What to build

实际迁移插件和不同身份的独立插件使用同一套最终公开契约，在文件切换、权限变化、失效、更新与持续输入期间保持正确的内容、按钮和恢复行为。清理本批迁移临时内部结构，交付没有插件专属宿主业务、包与 SDK 一致且有完整行为证据的集成版本。

本单是广域迁移的最终收缩／集成例外；不把 01–04 的功能测试留到此时才首次执行，也不另起新的功能或性能项目。

## Acceptance criteria

- [ ] U01–U20 及 Image 补充 I01–I03 均有对应实现、有效测试或必要原生验收证据；最终组合受后续改动影响的场景重跑，未受影响的既有证据明确引用其版本与适用范围。
- [ ] 不同身份的独立插件通过公开 SDK 构建、安装、替换并展示内容／工具，无需修改宿主；代码检索辅助核对专属分支和私有资源依赖已经移除。
- [ ] 文本提供者崩溃、停用或失去权限后复用普通编辑状态；非文本文件保留 Tab 与准确原因、选择／重试入口，恢复菜单只对文本能力生效。
- [ ] 更新准备失败保留旧实例，激活失败恢复旧实例及受管私有数据，成功切换撤销旧资源；不重放旧操作，不承诺回滚外部副作用。
- [ ] 文件切换／关闭重开、revision 变化、提供者更换及实例更新后，旧布局、工具事件、资源和异步结果不能影响当前目标。
- [ ] 受限工作区、未授权文件、符号链接越界、跨工作区／实例资源与不兼容能力明确拒绝；两组按钮、中心内容和订阅均有清理证据。
- [ ] 连续输入期间原生文本及时显示、光标稳定，插件更新不阻塞输入；保留已有树与丢弃旧结果的组合正确。已知性能问题按实际表现记录，未满足响应性要求不得记为通过。
- [ ] 深浅主题、中英文、键盘、中文 IME、焦点交接、滚动、缩放及可见编辑区高度在最终实际包组合中通过相关原生验收。
- [ ] 最终 SDK、能力协商、包版本、公开文档、示例及分发一致；不增加历史协议运行兼容分支，有限数据迁移继续保留。
- [ ] 清理本批迁移遗留的临时内部结构和重复业务，Markdown、Image（含原 SVG 能力）、终端、示例与受影响语言功能完整；Image 的声明格式、只读边界与尺寸行为符合补充要求。最终证据、实际限制和工单状态一致，不关闭或修改父议题。
