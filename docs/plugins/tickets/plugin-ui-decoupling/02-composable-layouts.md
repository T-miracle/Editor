## What to build

两个不同身份的兼容插件都可为同一文件安排中心布局，用户明确选择并按工作区／文件类型记忆。选中的插件能把原生编辑器与自身内容并排、上下组合或只显示插件内容。切换布局和提供者不会丢失原文档，插件失效时用户能恢复适合该文件的界面。

## Acceptance criteria

- [x] 从真实插件包提供并应用中心布局，原生编辑面板是引用现有文本会话的可组合组件，可省略；宿主不把固定三种模式作为全部插件的必备接口。
- [x] 并排、上下及仅插件内容的布局可通过原生交互使用，原生组件尺寸、输入与事件正确，不重新建立第二份文本或撤销栈。
- [x] 布局切换、提供者切换和恢复后保留未保存文本、选择、光标及 Undo／Redo；非文本布局不因引入编辑组件而被迫创建文本会话。
- [x] 用户从兼容候选明确选择，按工作区＋文件类型恢复；不同工作区独立，新安装提供者不覆盖有效选择，不按安装顺序或插件 ID 决定业务优先级。
- [x] 只有选中提供者能改变中心整体布局；其他插件仍可启用，其迟到布局或不匹配目标无法接管当前文件。
- [x] 文本提供者失效时回到普通编辑；宿主菜单仅对具有文本编辑能力的当前文件提供“恢复普通编辑界面”，并复用原文本状态。
- [x] PNG 无查看器时继续保留 Tab 与原因，可选择另一个兼容提供者或重试；自动故障回退不静默改写用户选择。
- [x] 隐藏编辑面板正确移交焦点和中文 IME，隐藏目标不截获输入；重现时复用有效组件，更新不造成光标跳动。
- [x] 文件身份、revision、选择和实例变化后拒绝迟到结果；拒绝非当前提供者、跨文件编辑引用及失效事件目标。
- [x] 本单布局、编辑引用和选择的公开契约与 SDK 同步完成，使用通用贡献与能力校验，不增加专属宿主测试入口。
