# 01：内置 Alacritty 终端与原生交互

稳定标识：`builtin-terminal-run-debug/t01`

**Status:** completed — 已实现并通过阶段门禁与双轴审查，交付记录见 [验收记录](../../verification/builtin-terminal-01-2026-10-09.md)。GitHub [#88](https://github.com/T-miracle/Nanobug/issues/88) 在正式提交推送核对后关闭。

规格标识：`builtin-terminal-run-debug`；主责验收 N01、N02、N22–N25。

## What to build

在不安装终端插件的隔离编辑器中，用户能够打开一个原生终端，连接真实 Shell，输入命令、复制粘贴、选择与滚动、管理侧边 Tab，并正常关闭和保存内置会话状态。终端使用上游 Alacritty，外观和交互继续沿用项目控件与用户主题。

先在本单内部完成必要的预重构：整理现有 PTY/进程资源和可复用绘制边界，保持原有消费者可验证，再把原生终端从打开入口一路接到真实进程和 UI。不另建一套平台进程实现，不把纯代码搬迁当作功能完成。

## Acceptance criteria

- [x] N01：无终端包时可打开并实际使用 Shell，终端核心为锁定的上游 `alacritty_terminal`；新终端不经 WASM Guest 或插件 UI 序列化运行，也没有重复入口。
- [x] N02：用户打开空终端面板自动创建一个 Shell Tab；关闭最后一个 Tab 隐藏面板，再次打开可用。为后续任务入口保留直接打开指定会话的行为，不强制每次创建附加 Shell。
- [x] 终端模块独立拥有终端状态、输入和恢复逻辑，应用只组装；复用已有受控 PTY 与本地控件，首次可运行就执行信任、归属及退出清理保护。
- [x] N22：真实键盘与中文 IME 输入正确，选择限制、Ctrl+C/V、右键菜单的复制可用条件、粘贴及清空缓冲区保留；任务停止不占用既有复制快捷键。
- [x] N23：保留 Shell 工具名默认命名、名称编辑及 Enter/失焦保存、拖动排序、左右侧栏、可调宽度和选中样式；滚动条在需要时显示并于停止滚动 1 秒后隐藏。
- [x] N24：中英文、深浅主题、自定义终端配色覆盖、图标、内边距和默认竖线光标生效；焦点、缩放和受限窗口尺寸不裁剪必要控件。
- [x] N25：实际 Shell、代表性全屏 TUI、长行、中文及宽字符通过输入与显示回归，连续调整宽高不人为生成重复命令行或额外空白。
- [x] 内置终端自身的设置与逻辑快照能够保存和重开，容量限制有效，不声称恢复旧进程内存；旧插件数据格式导入由 04 负责，不能提前覆盖真实旧数据。
- [x] 普通 Shell Tab 关闭释放资源，隐藏面板不结束 Shell；错误可见，关闭窗口和切换工作区保留原有信任及生命周期约束。
- [x] 为运行消费者建立可复用的会话/资源边界，不按终端插件 ID 设计长期调用分支；本单不提前删除尚未迁移消费者需要的旧入口。
- [x] 完成相关自动化与 Windows 原生交互验收及本单仓库基础门禁；注释、内部模块说明和当前受影响文档同步，不宣称旧用户迁移或整批发行完成。

## Testing Decisions

以编辑器打开终端的实际入口贯通真实 Shell，成组覆盖交互、Tab、主题和尺寸。复用现有 GPUI 窗口、SideTabs、滚动条及 PTY 测试夹具；已有终端回归用例按可见行为迁移，避免把旧解析器内部布局照抄为新断言。

本单建立可被后续使用的隔离窗口与进程夹具，不新增测试专用宿主 API。核心重排、选择及输入编码的必要低层用例与原生验收互补；不会为每个快捷键重复构建和启动整套插件。执行本批目录规定的阶段门禁与证据记录，旧数据导入全矩阵留给 04。
