# 02：运行与构建统一会话及 Tab 生命周期

稳定标识：`builtin-terminal-run-debug/t02`

**Status:** planned — 已批准并发布为 [#89](https://github.com/T-miracle/Nanobug/issues/89)，等待 01 完成。

规格标识：`builtin-terminal-run-debug`；主责验收 N04–N11、N16、N17、N26。

## What to build

用户从现有配置入口进行准备、构建和运行，或执行插件开发、构建、打包任务时，所有输出进入内置终端面板，并能交互输入、定位、停止、确认关闭和再次运行。同一次准备和正式运行使用同一个任务 Tab，独立配置并行且不占用普通 Shell。

将通用执行服务与 Shell 配置能力接到原生终端，合法插件也可经公开契约使用它。建立后续调试复用的统一任务身份和生命周期，本单不实现调试协议或调试输入握手。

## Acceptance criteria

- [ ] N04：配置经既有校验、保存、顺序准备及构建进入目标执行，同一任务 Tab 保留步骤标识、准备输出和正式输出；失败或取消阻止后续步骤和目标启动。
- [ ] N05：独立构建与现有插件开发、构建、打包任务都使用统一面板，其独立输出块退役；保留各任务状态、错误、停止和完成结果。
- [ ] 内置 Shell 配置模板、可用解释器发现、表单和执行可用，不要求安装终端包；其他语言的模板和构建规则仍由插件拥有。旧配置引用导入由 04 承接。
- [ ] N06：不同配置可同时运行并分别输入、定位和停止；普通 Shell 不被复用或混入输出。任务入口打开空面板不额外创建 Shell。
- [ ] N07：重复运行活动配置仅定位；显式重新运行等待原进程真正退出，再按正常准入与准备流程启动一次。
- [ ] N08：已结束任务对应 Tab 未关闭则复用，新一轮执行受理后清除旧输出；已关闭则新建。校验拒绝不清除原输出，旧执行事件不写入新轮次或重建已关闭 Tab。
- [ ] N09：关闭活动任务 Tab 提示停止并关闭；取消保持原状态，确认按受控停止流程清理后关闭。停止失败保留可见错误和控制入口。
- [ ] N10：准备中、启动中关闭以及确认期间自然退出正确收敛，不重复启动、不重复停止、不留下不可见的活动进程；保留宽限停止及强制清理能力。
- [ ] N11：已经结束的任务直接关闭；隐藏整个面板不停止任务，重新定位准确恢复对应 Tab。关闭 Tab 与隐藏面板不再共用含混语义。
- [ ] N16：受限工作区、权限不足、来源退休及伪造跨会话句柄被拒绝；内置能力不借用其他插件权限或提供者私有进程。
- [ ] N17：不同身份的真实消费者经通用公开能力执行、输入、查询、订阅、定位和停止；不依赖已安装终端包，不增加插件身份白名单或私有测试 API。
- [ ] N26：关闭窗口或切换工作区可取消；确认后回收对应任务、进程树及订阅，保存输出不会导致重启重放已结束任务。
- [ ] 配置、执行、Tab 身份分离，提供稳定的任务交互和清理边界供 03 复用；当前终端、构建和运行形成完整可演示路径，不借迁移顺手重做配置表单或调试功能。
- [ ] 更新受影响的公开 SDK、实际消费者、能力声明及文档；完成普通运行、构建、权限和生命周期测试以及本单阶段门禁。

## Testing Decisions

沿同一原生运行入口成批执行两组主要场景：准备/构建/运行成功失败组合，以及并行输入/关闭/复用/重新运行组合。覆盖原生 stdio 插件开发任务进入终端的适配，不能仅测一种 PTY 程序。

复用 01 的真实终端夹具，增加一个不同身份的公开消费者验证通用能力；暂停、超时、越权与晚到事件使用已有服务/进程测试边界注入，核对可见状态和实际存活，不从输出文本猜测退出。普通 Shell 的主题与 IME 清单若未受影响，引用 01 的有效证据并做必要组合检查，不全套重复。真实包、SDK 及阶段门禁按本批公共规则执行。
