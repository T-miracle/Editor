## What to build

用户安装独立 XML 插件并授权依赖准备后，打开 XML、SVG、XSD、XSL、XSLT 文件即可使用高亮、基础/Schema 补全、诊断、悬浮说明和定义跳转。无 Schema、离线或服务准备失败时按方案明确降级；与 Image 同时使用时保留 SVG 源码与预览，两个插件互不依赖。

本工单交付一个可以独立安装、演示和验收的语言插件，包含包声明、实际 grammar/query、服务和 Schema 配置、必要的通用宿主接入、用户设置、打包及端到端验证。格式化、标签编辑、大纲和折叠留给后续工单，不把缺失的后续能力标为完成。

## Acceptance criteria

- [ ] 五种首版格式和用户自定义扩展名关联可用；已打开文档在安装/启用后获得能力，无宿主固定语言白名单。
- [ ] 高亮来自实际 Tree-sitter WASM grammar 与查询；核对锁定版本、ABI、来源、许可证和包内资源，不使用宿主内建 XML grammar。
- [ ] 无 Schema 提供闭合标签、文档已有元素/属性等基础补全和语法诊断，不显示“缺少 Schema”告警。
- [ ] XSD/DTD 支持合法子元素、属性、枚举补全与约束校验；SVG 提供常用元素/属性提示。支持 DTD 作为规则来源不扩展成独立 DTD 编辑器。
- [ ] 标签不匹配、重复属性及命名空间错误可观察；有定义时悬浮说明和跳转准确，无定义时不伪造目标。
- [ ] 默认只使用插件随附、本地和缓存 Schema；远程获取可选、默认关闭，开启后按需缓存。显式配置失败显示配置/加载问题，失败不影响基础编辑。
- [ ] 安装授权后在私有版本目录准备语言服务及必要运行时，支持本机服务配置；准备/启动失败保留高亮并明确状态，不修改全局环境或安装项目工具链。
- [ ] XML 和 Image 分别独立安装、启停；同时启用时消费同一未保存 SVG 文档，不建立插件间依赖、调用或 ID 特判。
- [ ] 旧文档、旧 revision、旧实例和被取消的结果不得应用；关闭、卸载、服务退出清理资源；受限工作区不启动插件或语言工具。
- [ ] 经正式独立构建与安装入口验证实际插件包；补全真实输入、中英文、主题及相关原生交互通过，新增代码有必要注释。
- [ ] 锁定实际可用的 XML grammar、语言服务分发和 SVG 提示来源，记录平台限制，不以候选服务的功能列表替代本机验收。
