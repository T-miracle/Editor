## What to build

用户在宿主内置大纲窗口查看 XML 元素树，点击定义跳转到编辑区，并让大纲跟随当前文件和光标。大纲与资源管理器可同时显示，按停靠方向分割，通过 DockArea 拖动和调整比例，并在重开本机工作区后恢复。编辑区同时提供准确的 XML 结构折叠。

在一个可演示切片内交付插件结构数据与图标、通用契约、宿主树形面板、定位/光标联动、折叠、DockArea 接入和持久化。大纲与折叠可复用语言结构数据，但不是同一节点集合；不依赖格式化或标签重命名才能工作。

## Acceptance criteria

- [x] 大纲由宿主内置，插件只通过公开契约提供结构和图标；没有插件私有 XML 大纲面板或固定类型白名单。
- [x] 节点包含名称、类型、插件图标、层级、覆盖与定义定位范围，响应绑定文档、revision 和实例；非法/过期数据不应用。
- [x] 树项依次为折叠按钮、定义类型图标、定义名称；叶节点不显示折叠按钮，图标缺失或失败使用默认“定义”图标。
- [x] XML 以元素为节点，用 id/name 辅助区分；属性、文本、注释不单独列入大纲，点击跳转到开始标签名并聚焦编辑区。
- [x] 切换当前编辑文档时同步切换树；面板获得焦点不丢目标；关闭、无提供者或失效不残留旧树，无提供者显示“此文件暂无大纲”。
- [x] 光标移动高亮最内层元素；自动展开/滚动作为可关闭的跟随选项，不打断关闭跟随后用户的手动浏览。
- [x] 元素和注释等结构可准确折叠，编辑后刷新；折叠、跳转与光标归属范围分别处理，不能只打开原生 folding 开关便视为完成。
- [x] 大纲默认与资源管理器同级且可同时显示，不是互斥切换；左右停靠上下排列，顶底停靠左右排列。
- [x] 首次布局或新增面板等比例分割；通过真实 DockArea 交互拖动及手动调整后，普通文件/大纲更新不重置比例。
- [x] 位置与分割比例按本机工作区保存恢复；复用现有 DockArea 基础，不维护第二套布局真相，不扩大为多窗口或编辑组。
- [x] 不同 ID 的测试语言提供者通过同一结构契约渲染和导航，资源归属、实例清理、受限工作区边界有效。
- [x] 本地 UI 采用既有行为和主题契约，树、图标、焦点、键盘、滚动、缩放及中英文在原生窗口中验收；新增代码有必要注释。
- [x] 相关 XML 包版本、能力声明、公开 SDK 文档和实际包同步更新并验证；不重复承诺全项目所有语言已迁移大纲。
