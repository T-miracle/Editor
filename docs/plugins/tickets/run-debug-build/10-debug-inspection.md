# 10 — 单步、变量、调用栈与多会话调试

状态：ready-for-agent — 已确认并发布，待实施。

GitHub：[本工单 #58](https://github.com/T-miracle/Editor/issues/58)；父设计：[总方案 #48](https://github.com/T-miracle/Editor/issues/48)。

## What to build

在统一调试面板步入、步过和步出，检查栈帧与变量，并在多个独立调试会话之间切换。

本工单属于运行、调试与构建总方案。每个切片在既有公开能力边界内完成模型、接口、提供者、原生 UI 与可观察行为验收；不以只有类型或空界面代替交付。

## Acceptance criteria

- [ ] 面板顶部提供单步能力，真实 Rust 目标能步入、步过、步出；按钮按暂停状态和提供者能力启用。
- [ ] 统一变量与调用栈视图展示所选会话的暂停数据，切换栈帧定位源码并读取对应作用域，不把运行输出当作调试数据。
- [ ] 继续、单步、重新启动或会话切换后旧暂停引用失效，迟到栈帧或变量结果不覆盖新视图；公共契约明确请求关联与释放。
- [ ] 两份独立配置可同时调试，暂停一个不暂停其他；操作只作用于选中调试会话。
- [ ] 命中断点自动定位但不抢其他应用焦点；正在检查另一暂停会话时只提示，避免视图反复跳转。
- [ ] 真实 Rust 调试验证调用栈、局部变量与步进行为，受控公开提供者夹具验证乱序／迟到结果及能力缺失。
- [ ] 补充键盘、滚动、缩放、中英文与深浅主题验收，不新增自由停靠或高级调试范围。
