# 02 — 正常停止、重新运行与离开确认

状态：ready-for-agent — 已确认并发布，待实施。

GitHub：[本工单 #50](https://github.com/T-miracle/Editor/issues/50)；父设计：[总方案 #48](https://github.com/T-miracle/Editor/issues/48)。

稳定标识：`run-debug-build/02-stop-and-leave`

## What to build

用户可以正常停止或立即终止程序，明确重新运行；关闭窗口或切换项目时确认并清理会话。

本工单属于运行、调试与构建总方案。每个切片在既有公开能力边界内完成模型、接口、提供者、原生 UI 与可观察行为验收；不以只有类型或空界面代替交付。

## Acceptance criteria

- [ ] 停止先发出受支持的正常退出请求，显示停止中；超时升级为强制终止受管进程树，提供立即终止入口。
- [ ] 定稿并记录默认等待时长及不支持正常退出时的行为；不能把访谈中的示例值冒充已确认常量。
- [ ] 停止与查询等待取消语义分离；停止后迟到的启动结果仍可被追踪和清理，不回滚已发生的外部副作用。
- [ ] 重新运行明确先停止旧执行，再经校验和自动保存启动新执行；无新旧进程重叠。
- [ ] 有活动会话时关闭窗口或切换项目展示确认，取消保留上下文，确认清理后离开，不提供后台脱离。
- [ ] 测试会正常退出、忽略退出请求、产生子进程及启动中被停止的程序，核对实际进程与可见状态。
