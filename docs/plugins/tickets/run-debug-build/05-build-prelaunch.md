## What to build

在构建标签配置独立构建操作和启动前步骤；构建按钮只构建，运行先顺序准备，失败或停止后不再启动。

本工单属于运行、调试与构建总方案。每个切片在既有公开能力边界内完成模型、接口、提供者、原生 UI 与可观察行为验收；不以只有类型或空界面代替交付。

## Acceptance criteria

- [ ] 构建标签支持步骤增加、删除、排序，使用程序或显式 Shell 定义有限操作；本切片不引入跨配置依赖。
- [ ] 构建操作与启动前步骤分别存储；后者可引用构建当前配置，更新构建定义后引用同步生效且不复制命令。
- [ ] 点击构建只执行构建操作，不执行启动专属步骤或程序；无构建操作则按钮禁用并说明原因。
- [ ] 运行在已确认的自动保存成功后顺序执行准备，步骤以成功完成作为继续条件，失败、取消及停止均阻断后续。
- [ ] 当前步骤、逐步输出和最终结果归属同一会话；独立构建也可从菜单选择并停止。
- [ ] 构建和启动期间同配置去重；停止请求与步骤完成竞态不能放行迟到步骤，不用后台服务就绪或日志猜测代替完成。
- [ ] 在实现前记录单独构建的保存策略；若要扩大到此前未确认的产品行为，先明确差异，不静默套用运行规则。
- [ ] 验收至少两步成功、一处失败、构建复用、准备中停止、单独构建不产生启动副作用。
