# 01 — 手动配置运行真实程序

状态：ready-for-agent — 已确认并发布，待实施。

GitHub：[本工单 #49](https://github.com/T-miracle/Editor/issues/49)；父设计：[总方案 #48](https://github.com/T-miracle/Editor/issues/48)。

稳定标识：`run-debug-build/01-manual-run`

## What to build

在 B1 弹窗保存一份本机程序配置，从顶栏运行，通过真实终端执行提供者查看输出、退出结果并停止。

本工单属于运行、调试与构建总方案。每个切片在既有公开能力边界内完成模型、接口、提供者、原生 UI 与可观察行为验收；不以只有类型或空界面代替交付。

## Acceptance criteria

- [ ] B1 顶部配置选择、发现／新建位置及四标签结构可见；本切片尚未支持的构建与调试明确禁用，不伪装可用。
- [ ] 手动配置名称、可执行程序、参数数组和工作目录，保存到本机后可重新打开编辑；定稿最小版本化配置格式，保存不启动程序。
- [ ] 顶栏位于插件图标左侧并用短竖线分隔；可选择配置、启动、查看实际输出与退出结果。
- [ ] 通过公开执行契约返回执行身份并观察最终状态；不得把 interactive.execute 的 started 当作完成，不依赖终端插件 ID。
- [ ] 运行前自动保存工作区修改；验证或保存失败不启动进程；同配置重复或并发请求只定位已有会话。
- [ ] 至少具备显式终止与拥有资源回收；实例撤销、请求超时和旧事件不能制造孤儿进程或误改新会话；正常退出升级策略由 02 补全。
- [ ] 真实插件包经公开管理器进入宿主验证；覆盖受限工作区拒绝、权限不足、字面参数与启动失败，并验证深浅主题、中英文和键盘操作。
