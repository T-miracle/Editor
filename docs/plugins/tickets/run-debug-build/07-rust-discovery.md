# 07 — Rust 目标发现、保存与修复

状态：ready-for-agent — 已确认并发布，待实施。

GitHub：[本工单 #55](https://github.com/T-miracle/Editor/issues/55)；父设计：[总方案 #48](https://github.com/T-miracle/Editor/issues/48)。

稳定标识：`run-debug-build/07-rust-discovery`

## What to build

Rust 插件发现可运行目标，用户确认后得到可编辑配置与构建操作，运行真实构建产物；目标失效时引导修复。

本工单属于运行、调试与构建总方案。每个切片在既有公开能力边界内完成模型、接口、提供者、原生 UI 与可观察行为验收；不以只有类型或空界面代替交付。

## Acceptance criteria

- [ ] 通过通用公开贡献与发现接口返回带稳定身份、来源、类型和字段的候选；宿主不解析 Rust 专属业务。
- [ ] B1 发现入口展示候选，确认后保存并可修改；发现不运行目标，不静默把所有候选加入菜单。
- [ ] Rust 插件解析目标、构建模式和产物，关联构建操作后可普通运行真实程序；工具缺失给出修复提示，不自动安装编译器。
- [ ] 目标改名或删除后标记配置失效；重发现不覆盖用户修改、不重复保存，确认更新后才能改变执行目标。
- [ ] 贡献撤销不删除用户保存配置，迟到发现结果校验工作区与提供者实例；共享类型与字段具有清晰版本语义。
- [ ] 以不同 ID、不同配置类型的独立发现提供者验证通用表单和注册入口，不为夹具新增宿主特判。
- [ ] 验收真实 Rust 项目发现、保存、构建运行、用户修改保留及目标失效修复。
