# 08 — 按配置选择执行提供者与插件调用

## What to build

用户可为配置选择默认或指定的兼容执行提供者；独立插件通过同一公开会话 API 启动、订阅、定位和停止程序。

本工单属于运行、调试与构建总方案。每个切片在既有公开能力边界内完成模型、接口、提供者、原生 UI 与可观察行为验收；不以只有类型或空界面代替交付。

## Acceptance criteria

- [ ] 配置界面支持跟随默认与显式兼容执行提供者选择；缺失或不兼容提示修复，不静默替换。
- [ ] 活动会话绑定启动时提供者实例；新增插件不覆盖有效选择，切换默认只影响后续启动。
- [ ] 独立消费者插件通过版本化会话操作创建可见会话，查询、订阅输出与状态、定位展示并停止；与顶栏入口共享去重和归属规则。
- [ ] 同一消费者分别使用真实终端与不同 ID 的兼容提供者，展示、输入及清理语义一致，宿主不修改业务代码。
- [ ] 正常终止和强制终止能力完整贯通；返回请求接受不等于进程创建、调试就绪或执行结束。
- [ ] 声明版本、结构、错误、权限、取消和资源释放契约；验证授权交集、跨实例拒绝、过期引用与有界订阅。
- [ ] 更改接口的插件包同步版本、SDK 与消费者，沿公开 SDK 独立构建，无仓库内部依赖或 SDK 副本。
