# 03 — 统一下拉管理并行会话与输出

状态：ready-for-agent — 已确认并发布，待实施。

GitHub：[本工单 #51](https://github.com/T-miracle/Editor/issues/51)；父设计：[总方案 #48](https://github.com/T-miracle/Editor/issues/48)。

稳定标识：`run-debug-build/03-parallel-output`

## What to build

从同一个下拉管理多份独立配置的活动会话，分别查看输出与停止；关闭输出页签不结束程序。

本工单属于运行、调试与构建总方案。每个切片在既有公开能力边界内完成模型、接口、提供者、原生 UI 与可观察行为验收；不以只有类型或空界面代替交付。

## Acceptance criteria

- [ ] 统一下拉分组显示活动会话、保存配置及配置管理入口；收起后显示当前名称与状态。
- [ ] 不同配置可同时运行；选择未运行配置禁用停止，选择活动配置定位对应会话；同配置重复启动不产生第二实例。
- [ ] 每实例独立输出页签，输出及错误归属正确，交互输入仅发给对应执行，不共享可变输出缓冲。
- [ ] 关闭或隐藏会话输出仅撤销展示，实际程序继续运行；从下拉恢复同一输出与交互入口。
- [ ] 停止、重新运行和窗口离开准确作用于选中或列出的会话；一个会话失败不停止其他配置。
- [ ] 展示句柄与执行句柄分离沿公开契约实现；订阅有界、迟到事件按会话身份过滤；原有普通终端关闭行为不被无关改写。
- [ ] 原生验收同时运行两个实际程序、交错输出与输入、隐藏后重开并单独停止，覆盖窄窗口、键盘选择和缩放。
