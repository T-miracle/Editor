# 06 — 共享配置与本机覆盖

状态：ready-for-agent — 已确认并发布，待实施。

GitHub：[本工单 #54](https://github.com/T-miracle/Editor/issues/54)；父设计：[总方案 #48](https://github.com/T-miracle/Editor/issues/48)。

稳定标识：`run-debug-build/06-shared-config`

## What to build

用户把本机配置主动共享到项目，另一工作区可读取并编辑后运行，同时保留个人路径、环境与授权隔离。

本工单属于运行、调试与构建总方案。每个切片在既有公开能力边界内完成模型、接口、提供者、原生 UI 与可观察行为验收；不以只有类型或空界面代替交付。

## Acceptance criteria

- [ ] 底部保存位置默认为仅本机，选择项目共享后写入已定稿的版本化配置格式；取消不产生共享文件。
- [ ] 名称、目标、参数、脚本、构建与启动前步骤可往返；可移植值与本机覆盖分开，个人路径、敏感值和实际授权不被导出。
- [ ] 直接编辑共享文件与表单遵循同一验证契约；格式或变量错误明确显示并阻止启动，不回退到另一条命令。
- [ ] 两个隔离工作区加载同一配置时解析到各自项目；共享声明不能替用户指定已授权提供者、工具信任或权限。
- [ ] 同一配置稳定身份保持；活动会话继续使用启动快照，保存或文件变化只作用于后续执行。
- [ ] 以真实共享读写、重新打开、手工修改和再运行验证；如变更已落地本机格式，保留有限可测试迁移，不清空配置。
