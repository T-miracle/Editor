## What to build

用户在同一配置弹窗中切换程序模式与显式 Shell 模式，设置环境与本机工具路径，运行并查看真实结果。

本工单属于运行、调试与构建总方案。每个切片在既有公开能力边界内完成模型、接口、提供者、原生 UI 与可观察行为验收；不以只有类型或空界面代替交付。

## Acceptance criteria

- [ ] 程序模式始终使用可执行路径与参数数组；带空格、引号、中文及 Shell 元字符的参数可逐项编辑并原样传递。
- [ ] Shell 模式明确选择解释器，支持脚本文本、多行与管道；不得把普通模式参数拼接成脚本。
- [ ] 环境标签页编辑本机环境变量及工具路径覆盖，验证错误就地可见，运行结果能证明确已应用。
- [ ] 执行契约补齐有界环境与显式脚本语义，沿公开解析和受控进程接口执行，不借终端私有配置改变含义。
- [ ] 配置不能提升权限、改变工作区信任或把宿主敏感环境隐式注入 WASM；本机敏感值不写入日志或共享草稿。
- [ ] 真实程序及显式解释器分别验证参数边界、目录、环境与解释器缺失错误；提供中英文和中文 IME 验收。
