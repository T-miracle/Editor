## 实现边界

`ui.tools 1.0` 发布包内图标、双语提示、显隐／选中／禁用状态及版本化文件／窗口目标。
宿主只绘制两组原生按钮并路由事件；插件处理功能。Explorer 与独立窗口在左组，
中心提供者和辅助贡献不自动产生窗口按钮，多个适用贡献的工具共同出现在短竖线右侧。
两组使用各自溢出菜单，复用同一贡献和捕获目标。绘制不按插件 ID 分支。

`storage.private 1.1` 提供插件＋工作区＋文件类型的 opaque 偏好、CAS 与可撤销 watch。
损坏记录保留，过期写入拒绝，整体配额及候选迁移事务与私有文件 IO 共用。
原生 EditorState、DocumentSession、选择、IME 和 Undo 不进入偏好或插件状态。

独立 `layout-example 0.2.0` 提供三种布局工具和共享偏好；`tools-example 0.1.0`
同时提供辅助文件工具和五个独立窗口，各功能计数由真实 WASM 完成。
两包均通过宿主 `--plugin-cargo` 构建，不依赖仓库 crate 路径或 SDK 源码副本。
实际 Markdown／Image／Terminal 的模式、图标和旧偏好由下一粗批次统一迁移。

## 当前验证证据

- JSON 接缝先暴露工具字段未保留及非法目标被接受；协议实现后工具测试 3 项通过，全协议 34 项通过。
- `cargo test -p plugin-runtime instance::preferences::tests --lib`：3 项通过，覆盖同范围并发写入、过期 CAS、幂等、目录／类型隔离、损坏保留及配额／事务回滚。
- `cargo test -p plugin-runtime --test plugin_tools -- --ignored`：实际 SDK 包 3 项通过，涵盖能力协商、存储授权、缺失／危险图标、同类型切换、不同工作区、重启、watch 收敛／损坏终止和停用清理。
- 原生工具用例通过真实鼠标和菜单键盘验证布局改变、辅助工具、禁用状态、窗口目标保持、两组单行溢出、旧文件事件拒绝及深浅主题；补充的菜单键盘跳过回归通过（18.66 秒）。
- 原有实际布局／Image／中文 IME／文本与 Undo 回归 1 项通过（59.45 秒）。
- `cargo fmt --check`、`cargo test --workspace --exclude editor-app`、`cargo check --workspace` 通过；ignored 不计为已执行。
- 构建宿主后 `./scripts/verify-plugin-sdk.ps1` 的完整导出、缓存修复、仓库外独立编译通过，包含新增契约与文档。
- 最终原生工具用例包含禁用项键盘跳过与 1.5 倍 DPI、深浅主题变化后的真实激活，1 项通过（19.30 秒）。
- 当前布局夹具的能力／辅助约束运行时回归 1 项通过（28.71 秒）；当前导出 SDK 包经公开 Manager 安装运行 1 项通过（19.91 秒）。

首次原生测试将包安装到了不同于既有测试宿主的资源目录，导致图标无法解析；修正测试环境。
匹配包目录后，启动可能打开目录中的其他文件；回归按实际文件身份定位 Tab，避免猜测索引。
随后回归发现实际延迟聚焦会夺走工具溢出菜单的键盘；测试先在旧菜单无法关闭处失败，
修复后旧操作被拒绝且 Enter 不再写入另一个文件。
