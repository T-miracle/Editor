## 行为与边界

终端 0.7.0 发布 `interactive.execute` 1.0.0；消费者声明版本与有界参数/结果 Schema，调用 `execute(program, args, cwd?, name?)`，返回当前实例内的展示会话编号及 `started`。返回仅确认进程创建，既不冒充程序退出，也不冒充异步面板已显示。普通面板请求通过既有编辑器队列完成。

执行命令原样使用程序与参数数组，不套用私有 Shell 配置或借用既有进程。通用服务机制检查调用链与授权交集；调用方需要 `services.call`、`process.exec`、`ui.panels`。降低方法权限会成为不兼容契约，缺失安装授权无法激活。原生程序仍具有操作系统用户权限。

请求开始前取消保证未执行；进入副作用阶段后只能停止等待，不承诺回滚。创建请求完成后取消不会终止已启动程序，用户可关闭会话。来源或提供者退出回收委托资源；热更新使旧引用失效并结清未执行请求。服务会话快照仅保存历史，不自动重新执行，避免恢复时扩大为提供者私有权限；普通 Shell 恢复策略保持原状。

主程序没有绑定具体终端的项目执行业务入口，本次使用独立 SDK 消费者验收。终端自身的用户命令仍通过普通命令接口调用。`capability-example` 0.15.0 仅在测试重新打包声明时充当同契约替代实现，以 stdio 启动程序并使用自己的普通面板。默认示例包没有服务执行声明或原生执行授权。没有新增主程序执行接口、契约名分支或插件 ID 白名单。
