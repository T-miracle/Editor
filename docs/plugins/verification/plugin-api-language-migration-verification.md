## 交付行为

Rust、TOML、HTML、JavaScript 包均升级为 0.2.0，采用协议 7 的动态语言识别、高亮与图标声明。后三者保持纯资源包；Rust 增加独立 WASM 策略组件，通过宿主导出的公共 SDK 构建。

Rust Analyzer 的工具候选、版本探测、初始化字段、配置节、就绪通知与 Cargo 项目发现均由 Rust 插件声明或计算。宿主移除固定语言枚举、内建扩展名回退和 Rust 专属 SDK 项目扫描。无有效识别提供者时，文档保持纯文本。

新增的公共接口不包含语言名称：`workspace.files` 1.1 接受有界相对 glob，遵守忽略规则、拒绝越界和链接遍历；`host.sdk` 返回 SDK 内容摘要、绝对根目录和 Cargo 配置位置，不授予文件权限。SDK 资源由后台宿主准备，随候选、作用域切换和失败恢复传递。语言准备钩子只能读取，临时句柄在回调后回收。

通用进程服务支持显式工具搜索路径和 argv 探测。目录扫描、候选数量、探测时长和现有请求截止时间共同约束开销；空匹配也计入扫描预算。用户指定的错误可执行路径不会回退。LSP 的额外客户端能力为受限 JSON；宿主不解释 Rust 私有字段。

语言识别变化立即使旧文档租约失效，并重新绑定相应提供者，即使语言服务计划本身未变化。延迟关闭只作用于原租约，不会误关快速切回后打开的新文档；无关服务实例保留。
