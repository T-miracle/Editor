# 底栏提醒与摘要验证（工单 03 / GitHub #25）

状态：已完成，2026-10-04，Windows。依据：[规格](../specs/plugin-management-logs.md)、[工单](../tickets/plugin-management-logs/03-status-popover.md)、[运行日志验证](plugin-runtime-logs-verification.md)。

## 交付行为

- 底栏只显示一个插件入口：错误优先于警告，再到正常加载。警告和错误使用项目主题的彩色图标，未查看提醒持续存在。
- 打开 A 方案弹窗时，在同一日志锁内捕获每插件 ID 边界和最新异常摘要，随后确认本轮底栏提醒。仍加载则恢复 loading，否则隐藏；新异常再次提醒。摘要保留原始级别和原因，不把已查看表示为已修复。
- 历史仍每插件最多 512 条。额外保留最多两条被淘汰但未查看异常的代表（警告、错误各最新一条），保证普通输出不会挤掉底栏提醒。确认或实际查看后释放代表；不恢复已淘汰历史及其 Tab 未读图标。快照克隆保护打开瞬间原因，不被后续同级代表替换。
- 按插件分组显示名称、最新一条警告 / 错误、接收时间、来源和正文，同时合并当前加载任务。标题固定、内容滚动，卡片适配窗口边界。正文使用主题前景色，级别保留彩色图标。
- 只有消息实际进入绘制视口，且仍属于当前打开快照时，才按精确 ID 标为已读；其他旧条目继续未读。弹窗确认与记录已读分别处理。
- 摘要整行使用本地 Base 按钮。点击正文或键盘激活可打开管理窗口，清除旧搜索 / 市场状态并定位对应插件日志 Tab。卸载历史保留可读内容，过期点击不能路由。
- Escape、关闭按钮和外部点击释放 Base 弹窗状态。原触发入口消失后，即使同级提醒重新创建，关闭仍回到编辑器有效焦点；连续 Tab 自动将聚焦摘要滚入视口。

原生观察：在独立插件目录与工作区通过真实受控服务产生插件归属的准备失败及 Info / Error / Warning 通知。底栏优先显示红色错误；最新摘要仍呈现原始黄色警告，与更早未读错误分别处理。打开摘要后本轮插件提醒隐藏，重启服务产生新异常后再次提醒。将受控服务通知改为只有警告后，底栏黄色警告保持到用户查看，旧已确认错误没有再次唤起红色入口。

A 方案分组的名称、UTC 时间、彩色级别、正文与来源可读；点击正文实际定位服务插件日志 Tab。真实 Tab 焦点依次经过关闭按钮和两条摘要，离屏第二条滚入视口，Return 定位对应工具插件完整日志。浅色 14 px 和深色 20 px 均实际查看；深色长中英文消息正常换行，滚轮只移动卡片正文、标题及关闭按钮保持固定，时间与来源没有被横向裁掉。Escape 关闭后旧提醒保持隐藏。

## 审查与边界

审查修正原入口被移除后的焦点恢复、离屏摘要的键盘滚动，以及普通输出淘汰未查看异常导致提醒消失的边界。首轮编译修正路由读借用生命周期；首轮 GPUI 验证发现测试 recording worker 不会自动发布真实包的安装条目，按既有管理夹具的公开管理器发布接缝修正，保留行为断言。

原生验证发现 Base 按钮内富文本的固有宽度让正文成为超宽单行，修正本地按钮可选内容宽度与摘要换行，并以长正文、时间边界及正文点击回归验证。连续 Tab 用例需显式激活测试窗口，使 GPUI focus-in 观察按真实窗口触发；1.5 倍缩放的 f32 边缘误差小于 0.0001 px，完整可见断言只允许 0.01 px 舍入容差，保留 13 次 Tab 与 12 行完整可见检查。旧加载用例补齐生产流程原已记录的所属插件错误日志，保留加载、阻断与定位断言。最终独立只读审查无阻塞项。

本工单不变更公开插件协议或 SDK，不发布插件包或编辑器 Release。真实 WASM / LSP 来源接入已在 #24 验证，本切片沿用同一来源与记录，补充底栏消费闭环。英语与 1.5 倍缩放通过 GPUI 验证；原生界面验收为中文，日志正文包含中英文。未执行 macOS / Linux 验收。既有 CollectionModel 可见性、未使用辅助函数和 Windows wasmtime / tree-sitter 链接警告仍存在。
