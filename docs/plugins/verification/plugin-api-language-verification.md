## 交付行为

协议 7 纯声明式资源包使用独立的 `language_definitions` 与 `highlighters` 数组，不要求附带空生命周期组件。一个包可声明多个语言，识别与高亮也可来自不同包。语言 ID、grammar 导出名及包 ID 相互独立；新注册路径没有固定语言枚举。

“设置 → 语言提供者”分别配置文件识别与语言高亮，支持用户全局及已确认的本机项目覆盖，并显示来源。唯一候选自动采用且记住已有有效选择；安装竞争包不改变选择。选中项移除后，唯一候选接替，多个候选要求选择，无候选明确显示纯文本降级。宿主本机文件持久化选择，不从项目文件获取授权或信任。

后台只准备 WASM grammar 与查询。UI 确认任务代际及当前选中的包版本后才注册解析器，并刷新已打开文档。启停、替换和卸载立即撤销旧高亮；查询或 grammar 校验失败保留语言识别、显示错误并保持无高亮。只有识别没有高亮时也不会回落到宿主内建 grammar。

图标和主题贡献沿用原路径。旧语言包暂时保留，但其后台加载同样改为准备后再由 UI 检查发布；不会覆盖动态选择。动态高亮可沿用旧识别，移除动态覆盖后重新验证并恢复可用的旧插件 grammar。本项没有迁移既有语言插件或修改 LSP 配置；相关工作仍属于后续工单。

公开 SDK 导出包含 [LANGUAGES.md](../../../website/src/content/docs/en/sdk/languages.md)，说明完整包清单、TOML 格式、预算、路径、选择和热加载语义。
