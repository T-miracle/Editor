## 交付

- `process` 1.0 能力：固定声明服务与任意执行分开授权，类型化管道/PTY 启动、输入、输出、退出、尺寸和释放。
- 服务调用只能传 ID，程序和参数来自已确认包；经过 toolchains 解析到实际可执行文件。
- Windows 管道进程先暂停、加入 Job 再恢复，PTY 创建时原子加入 Job；拥有者退役清理进程及后代。
- 输出按流区分并等待 EOF 后报告退出，显式释放后不投递当前批次剩余事件；总资源额度在原生启动前检查。
- 安装确认展示本机执行权限边界和服务程序/参数。新增权限未确认时，旧包和授权保持有效。
- 独立 SDK 示例升级为 0.5.0，仍通过宿主公开 SDK 构建；默认示例不申请原生执行，测试包才声明其夹具权限。

公开契约随 SDK 导出为 [PROCESSES.md](../../../documentation/en/sdk/processes.md)。没有安装脚本接口、插件名称判断或终端画面解析。

## 回归

沿既定 Package/Manager + 独立 WASM、现有 GPUI 界面接缝验证；原生夹具由 rustc 独立编译，所有数据使用临时目录。

- 包检查 RED→GREEN：支持固定服务；拒绝相对目录、Shell 开关和安装步骤字段。
- 真实 stdio：带空格输入、独立 stderr、退出前 128 KiB 尾部输出全部保留；服务权限拒绝任意执行。
- Windows PTY：带空格路径、引号/尾斜杠 argv、空格输入、resize、正常退出和退出后句柄拒绝。
- 立即创建后代的夹具：stdio 显式关闭及 PTY 停用后父子 PID 均退出；受限工作区拒绝安装/启用。
- 新增执行权限但拒绝授权：旧实例仍能启动原声明服务。
- 满 128 个资源槽：拒绝启动，不生成 marker、不留下进程。输出回调关闭资源后只接收首块，覆盖活跃进程和已自然退出进程。
- 现有终端完整 smoke、持续高度 resize、新建及恢复提示符间距回归通过。兼容旧 ConPTY 握手；规范路径转普通路径前核对实际文件相同，解决 PowerShell 的设备路径初始化问题；stdio 与 PTY 共用该路径规则。
