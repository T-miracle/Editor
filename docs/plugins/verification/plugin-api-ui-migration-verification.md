## 交付行为

示例升级为 0.3.0、SVG 升级为 0.2.0，均通过宿主 SDK 独立编译并采用协议 7。示例仅协商 `ui.native`，不申请原生权限；计数与中文笔记继续使用宿主管理的逻辑快照，输入值更新保持交互目标版本，模态与标签切换使旧事件失效。

SVG 仅申请 `editor.read`，通过宿主管理的 Preview 通知接收当前内存内容，不读取磁盘源文件。输出是普通 `Canvas` 节点，保留颜色、透明棋盘、四个图标、居中缩放、尺寸响应和主题字体。每份 UI 原样返回来源文档 ID、路径和 revision；同一路径重新打开按新身份处理。

通用 Manager 在进入 WASM 和修改预览来源之前拒绝同一文档的旧 revision，避免把正常插件停用。主程序对超出 1 MiB 的内存文档显示通用错误提示，保持当前来源版本、撤销旧画布及 guest 源；缩小内容、切换文件、隐藏和更换实例会清除错误。不增加 SVG ID 专属分支，不扩大传输限额。
