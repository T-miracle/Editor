# 插件安装进度弹窗尺寸调整

日期：2026-10-06。

## 行为与边界

- 安装进度窗口从 680 × 480 的内容尺寸调整为 520 × 200；加上 28 的标题栏，总尺寸为 520 × 228 个逻辑像素，实际显示随系统缩放变化。
- 通用原生弹窗的最小尺寸不再超过调用方指定的初始尺寸；原有较大弹窗仍保留 520 × 320 的最小尺寸。
- 长进度信息在内容区滚动，取消／关闭按钮固定在底部。限制内容容器的最小高度，避免长信息将按钮撑出窗口。

## 验证

- 现有 `second_market_install_shows_visible_consent` 从市场安装入口进入进度窗口，检查实际 GPUI 视口尺寸、按钮可见性及取消结果。旧实现因窗口过宽失败，修改后通过。
- 注入 80 行进度信息并发送滚轮事件，验证按钮位置保持不变。该检查发现并修复了内容容器撑出窗口的问题。
- `cargo test -p editor-app extensions::tests:: -- --test-threads=1`：7 项通过，无跳过。
- `cargo fmt --check`、`cargo test --workspace --exclude editor-app`、`cargo check --workspace`：通过；保留已有编译警告。

本次使用 GPUI 测试窗口验证布局与输入，没有替换或重启用户当前运行的程序，也没有进行实际插件下载与安装。macOS/Linux 未实测。现有运行程序须重新构建并启动后才能显示新尺寸。
