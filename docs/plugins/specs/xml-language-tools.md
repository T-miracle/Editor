# XML 插件与通用语言编辑能力方案

## Problem Statement

用户编辑 XML、SVG 及相关文档时，需要可靠的高亮、补全、错误提示和结构导航。只识别扩展名或给文本着色，不能满足根据文档约束补全元素、属性和取值的需求，也不能帮助用户定位不符合 Schema 的内容。

现有 Image 插件已经提供 SVG 源码与预览组合。新增 XML 语言能力应独立工作，与 Image 同时安装时自然组合，不能让两个插件互相依赖、调用或检查对方身份。

用户还需要跨语言一致的格式化、标签重命名和大纲体验。格式化不能永久绑定某个语言插件；未来其他插件应能提供替代格式化器。大纲应是宿主内置的统一窗口，消费插件数据与图标，跟随当前编辑文档，并支持与资源管理器同时显示和调整停靠布局。

## Solution

新增独立 XML 插件，首版识别 `.xml`、`.svg`、`.xsd`、`.xsl`、`.xslt`，并允许用户配置其他扩展名关联到 XML。通过插件提供的 Tree-sitter WASM grammar 与语言服务，实现高亮、基础补全、Schema 智能补全、诊断、悬浮说明、定义跳转、格式化、大纲数据和结构折叠。

宿主补齐面向全部插件的公开能力：独立可选的格式化提供者、显式重命名、标签关联编辑，以及结构化大纲与折叠数据的消费。XML 与 HTML 都接入标签重命名和自动同步。宿主维护唯一文本会话、revision、IME、选择与 Undo/Redo；插件负责语言语义和候选编辑范围。

宿主内置大纲窗口，按插件数据渲染带图标的目录树。大纲跟随当前编辑文档和光标，点击后跳转到对应源码。大纲与资源管理器同级、可同时显示，使用现有 DockArea 机制停靠和恢复布局。

## Implementation Decisions

### 1. 范围与职责

- XML 插件负责语言识别、grammar/query、语言服务配置、Schema 来源及语言领域数据；HTML 插件同时接入显式标签重命名与关联编辑。
- 首版文件关联为 XML、SVG、XSD、XSL、XSLT 所对应的五种扩展名，另提供用户自定义扩展名关联。支持作为 XML 编辑不代表承诺完整 XSLT 执行、调试或特定行业语言智能能力。
- DTD 可以作为补全和校验规则来源；独立 DTD 文件的语法高亮、编辑和导航不在本次已确认的文件格式范围。
- XML 与 Image 不建立强制或可选的插件间调用依赖，不探测对方 ID，不接管对方功能。XML 不创建 SVG 预览面板，Image 不负责 XML 语言服务。
- 语言能力与文件显示提供者独立选择。组合通过宿主文档、贡献注册和已有文件显示机制完成。
- 优先扩展现有语言集成、协议、运行时和本地 UI 模块，不为每项功能新建 crate，不复制上游控件或创建插件专属宿主 API。

### 2. 高亮、补全、Schema 与服务依赖

- 高亮仅由插件携带的 Tree-sitter WASM grammar 和查询提供，不引入宿主内建 XML grammar。
- 无 Schema 时保留基础补全，包括标签闭合、现有标签和属性提示。有 XSD/DTD 时提供合法子元素、属性、取值补全和约束诊断；SVG 提供常用元素和属性提示。
- 无 Schema 不产生“缺少 Schema”错误或警告。显式配置的 Schema 加载失败要给出配置/加载问题，不能冒充文档内容错误。
- 默认使用插件随附、本地配置和有效缓存中的 Schema。远程下载默认关闭，用户开启后按需获取并缓存；关闭或失败不影响基础补全和语法诊断。
- Schema 的发现、关联和领域配置留在插件；网络、文件、缓存和进程资源继续遵循宿主现有权限、信任、归属与清理契约。允许下载 Schema 不等于授予 XML 任意外部实体访问权限。
- 安装授权覆盖语言服务器及其必要运行时的私有依赖准备，不修改全局环境，不安装整个项目编译器或 SDK。允许显式指定本机已有服务；配置错误按既有契约报告，不偷偷换用其他程序。
- 服务准备或启动失败时保留高亮，明确区分安装、准备、启动、可用和失败状态。受限工作区仍遵循不启动插件或语言工具的既有规则。
- Tree-sitter XML 与 LemMinX 是已调研候选，不把具体版本、二进制来源、打包方式或全部服务器能力当作已完成的技术选型。实施前核对 WASM ABI、许可证、Windows 分发、运行时与所需能力；版本和下载来源锁定后验收。

### 3. 可替换的格式化提供者

- 将格式化作为独立、通用的插件贡献和提供者选择维度，不与文档主 LSP 或高亮提供者绑定。替代格式化器不得迫使用户切换主语言服务。
- 语言插件可提供默认格式化器；其他插件可为同一语言提供替代格式化器。JavaScript 默认语言格式化被未来 ESLint 类插件替换，是本能力必须支持的复用场景，不是本次实现完整 ESLint 插件的承诺。
- 单一候选自动使用；多个候选保留已有有效选择，用户可以在用户设置或项目设置中指定，项目设置优先。不存在已有有效选择时不得按安装顺序抢占。
- 每次操作只调用一个选中的提供者。选中提供者被移除后的候选处理继承既有平台规则：仅一候选可接替，多个候选要求选择，无候选明确降级。显式配置错误与正常移除分开处理。
- 支持手动格式化；保存时格式化可选、默认关闭。两种触发方式使用同一提供者选择与版本校验。
- XML 格式化整理缩进、属性换行及空元素样式，同时保留混合文本和 xml:space 的空白语义。
- 格式化请求与结果携带文档目标、revision 和提供者生命周期信息；宿主通过唯一文本会话事务应用有效结果并支持撤销。过期、取消、关闭或提供者失效的结果不得应用。
- 格式化与自动修复串联、多个格式化器流水线不在首版范围。

### 4. 显式重命名与标签关联编辑

- XML 与 HTML 首版同时支持两种操作：主动执行重命名后输入新名称；直接编辑任意一端标签名时自动同步配对端。
- 显式操作使用常规的新名称输入交互，一次性修改同一元素的开始和结束标签；不采用同时选中两端后直接输入的专用交互。不改变其他同名元素，也不承诺跨文件 Schema 重构。
- 自动同步默认开启，允许用户级关闭和按语言覆盖。只有插件能够明确识别配对时才同步；无法确定时只修改当前端，不猜测另一个标签。
- 宿主公开重命名与关联编辑能力；插件提供语义目标、配对范围和合法编辑结果，宿主负责校验、原生交互、应用和撤销。不得在宿主按 XML、HTML 或插件 ID 编码配对规则。
- 自闭合元素、HTML 空元素、同名嵌套、属性中的相似文本和注释中的标签文本必须根据真实语言语义处理，不能依赖全局字符串替换。
- 显式重命名作为一次可撤销编辑；一次直接输入及对应配对修改保持一致的 Undo/Redo 行为，不使用户撤销到仅一端改变的状态。
- 保留唯一 EditorState 与 DocumentSession；插件不得维护第二份可变文本真相或撤销栈。IME 组合输入、粘贴、删除和取消不得造成递归同步或错误范围应用。
- 先前针对“双端选区模式”讨论的 Enter/Esc 专用语义，以及名称暂时为空时持续绑定的提案，均不作为已确认需求。具体输入中间态处理须满足上述配对明确、无误改和撤销一致性，不擅自恢复已撤回方案。

### 5. 大纲数据、导航与折叠

- 大纲是宿主内置面板，不由 XML 插件创建或渲染专有 UI。所有插件使用同一公开结构化契约提交大纲数据。
- 节点至少表达定义名称、定义类型、插件图标引用、层级关系、覆盖范围和定义定位范围；响应须关联目标文档、revision 与提供者实例。确切序列化字段和能力版本在契约实现时确定。
- 定义类型与图标由插件贡献；宿主负责图标资源的归属校验与安全加载。图标缺失或加载失败时显示宿主默认“定义”图标，节点仍可正常导航。
- 树项顺序为展开/折叠按钮、定义类型图标、定义名称；只有有子节点的项显示折叠按钮。宿主统一管理缩进、焦点、选中、键盘导航与主题外观。
- XML 大纲以元素为节点，用 id 或 name 辅助区分同名元素；普通属性、文本和注释不单独占用节点。点击跳转到对应开始标签名，并使原生编辑区获得焦点。
- 大纲跟随当前活动编辑文档，面板本身取得焦点不得导致目标丢失。切换或关闭文件立即撤销旧目标数据；没有提供者时显示“此文件暂无大纲”，不能残留上一个文件的树。
- 光标移动时高亮所在的最内层元素。自动展开与滚动定位作为可关闭的“跟随光标”选项，保留手动浏览体验。
- 结构折叠覆盖完整元素、注释等语言结构。折叠数据也由语言提供者经通用机制供给，不把已有原生折叠开关视为完整 XML 结构折叠交付。
- 大纲与折叠可使用同一语言结构信息，但不强制相同节点集合；例如注释可折叠而不成为 XML 大纲节点。
- 大纲定义位置、元素覆盖范围和折叠范围分别服务于跳转、光标归属与折叠，不混为一个范围。非法或过期范围必须拒绝。

### 6. 大纲停靠与布局

- 大纲默认与资源管理器同级、位于同一侧栏，允许同时显示；不能仅提供互斥切换的页签。
- 左、右停靠区域内的面板上下排列；顶部、底部区域内左右排列。首次布局或新增面板按等比例分割，已有用户手动布局不因文档更新而重置。
- 允许使用 DockArea 将大纲拖至其他位置并调整分割比例。沿用上游状态和交互接口，在项目本地 UI 层组合外观。
- 停靠位置和分割比例按本机工作区保存并恢复，不写为团队共享项目设置。恢复有效的既有布局时优先使用保存值。
- 当前工作树已有分割插入及 DockArea 持久化基础，应优先复用。大纲面板登记、顶部停靠路径及全部方向的原生拖动效果仍须实际验证；已有代码不代表本方案已验收。
- 本次已确认的停靠要求替代历史“固定布局、不做自由停靠”中与其冲突的限制，仅覆盖本方案面板接入与布局行为，不扩展为多窗口或多编辑组。
- 可见 UI 遵循 gpui-base 行为基座、参考 gpui-component、本地外观与现有主题契约；保持中英文、深浅主题、键盘、滚动与缩放可用。

### 7. 生命周期、兼容与交付

- 新增通用能力须有版本、协商、权限、实例归属、取消与清理语义，并同步更新 SDK 和消费者文档。不得增加旧协议运行兼容分支或 XML 专用权限。
- 新插件安装、停用、卸载、服务退出和提供者切换均通过既有注册和资源生命周期机制；清理大纲、关联编辑状态和迟到请求，保持现有有效选择规则。
- 插件包独立构建沿用宿主内嵌 SDK 分发入口，不依赖仓库内部源码路径或复制 SDK。
- 修改并交付 HTML 包时同步提升包版本，核对清单、能力、grammar、资源和实际 ZIP 内容。XML 包作为新包验收；不因组合测试顺带修改 Image 的领域功能。
- 本方案本身不表示实现、测试或发布版本已经完成。

## Testing Decisions

### 已确认主测试入口

复用一个主要的产品验证入口：**将实际插件包安装到隔离的宿主测试工作区，通过公开插件管理与语言能力接口打开和编辑文件，验证实际文档、原生 UI、提供者选择和生命周期结果。**

XML、HTML、Image 组合及不同 ID 的独立测试提供者都从这个入口进入，不为 XML 或某个格式化器增加宿主测试专用 API。可控 LSP 只替代外部进程以制造超时、迟到和乱序响应；最终功能验收仍包含实际 XML 服务与实际 WASM 包。协议级范围、资源和权限测试作为该入口的必要补充，不另造一套业务实现。

### 可复用先例与分层

- 动态语言工单及其验收已有陌生语言包、多提供者、已打开文档与迟到加载先例。
- 通用 LSP 工单及其验收已有可控服务、文档同步、初始化、诊断、取消和旧结果拒绝先例。
- 现有语言迁移和 SDK 分发测试提供实际包、独立构建与宿主缓存分发先例。
- 现有编辑请求与文档导航测试提供 revision、事务和定位行为先例。
- Image 文件显示及 Markdown 原生集成测试提供未保存文本、选择、撤销与布局共存先例。
- 本地 DockArea 控件测试与会话恢复测试提供拖动、分割方向、面板缺失及恢复比例先例。
- 只验证可观察行为与公开契约；不以私有函数被调用、某个字段被赋值或假服务返回了方法名作为功能完成依据。

| T05 | 显式 Schema 路径失效、远程下载关闭/失败/缓存命中 | 区分配置/加载错误和文档错误，基础功能持续可用，关闭下载不发起自动获取 |
| T06 | 悬浮与定义跳转 | 有定义时展示说明并准确定位，无定义时不伪造目标 |

| T09 | 格式化提供者移除、配置错误或运行失败 | 按既有候选规则接替或提示，无静默随机覆盖；错误不能导致原文部分修改 |
| T10 | XML 和 HTML 显式重命名 | 输入名称后仅对应开始/结束标签改变，一次撤销恢复，不使用双端选区专用模式 |
| T11 | XML 和 HTML 直接编辑任意一端 | 明确配对时另一端同步；用户级关闭和按语言覆盖生效 |
| T12 | 同名嵌套、自闭合/空元素、属性、注释及损坏结构 | 不误改其他元素或类似文本；配对不明只编辑当前端 |
| T13 | 中文 IME、粘贴、删除、Undo/Redo | 输入和同步保持一致，无递归编辑、错误定位或仅撤销一端 |
| T14 | 格式化/重命名/关联编辑响应迟到或文档重开 | 旧 revision、旧目标和旧实例结果均不得写入当前会话 |
| T15 | XML 大纲内容与插件图标 | 元素树、id/name 辅助名称和节点顺序正确；缺图标安全兜底 |
| T16 | 大纲跳转、文件切换及空状态 | 点击定位开始标签名并聚焦编辑区；切换后不残留旧树，无提供者显示明确状态 |
| T17 | 大纲跟随光标与手动浏览 | 高亮最内层元素，自动展开/滚动可关闭，点击大纲不会丢失目标文件 |
| T18 | 元素/注释折叠及编辑后刷新 | 折叠范围准确，过期和非法范围不应用，注释无需出现在大纲里 |
| T19 | 四个停靠方向和新增面板 | 左右区域上下分割、顶底区域左右分割，初始等比例，资源管理器与大纲可同时见到 |
| T20 | DockArea 拖动、调整比例与工作区重开 | 实际可拖动并恢复本机工作区位置和比例，不在文件切换时重新均分 |
| T21 | XML 与 Image 的安装/停用组合 | 仅 XML 可编辑 SVG；仅 Image 保留自身预览；同时启用共享同一未保存文档且互不调用 |
| T22 | 语言依赖准备、本机服务和故障 | 授权私有安装，不修改全局环境；失败保留高亮并说明智能能力状态 |
| T23 | 陌生语言、不同 ID 的结构/格式化测试提供者 | 复用同一公开宿主能力，无 XML/HTML/ESLint 白名单或测试专用 API |
| T24 | 插件停用、卸载、崩溃、配置变更及受限工作区 | 状态、进程和请求按现有契约撤销，不保留旧大纲或旧配对编辑，不越过信任边界 |
| T25 | 深浅主题、中英文、键盘、滚动与缩放 | 原生控件视觉与交互可用，插件图标在相关主题下可辨认 |
| T26 | 独立构建、实际包与公开 SDK | XML 和升级后的 HTML 可通过正式入口构建和安装，能力声明与包内容匹配 |

实施时先运行受影响模块的针对性测试，再执行仓库要求的 Rust 格式、非 UI workspace 测试和 workspace 编译检查；修改宿主应用必须追加相关 GPUI 测试及 Windows 原生交互验收。实际 WASM 包与 ignored 测试必须先构建所需夹具再显式运行。SDK 变更按既有分发验证流程执行。macOS/Linux 未实际验证时明确记录限制。

方案整理阶段仅检查文档；用户现已授权执行全部三张工单。上述计划测试必须按真实执行结果记录，不提前标为通过。

## Out of Scope

- 快速修复/code actions，已明确留到后续。
- 本次未确认的 XPath 查询、XML/JSON 转换、SVG 颜色编辑或引用专项增强。
- 独立 DTD 编辑器、完整 XSLT 执行与调试，以及 HTML/Vue 文件识别迁入 XML 插件。
- 实现完整 ESLint 插件、串联多个格式化器或格式化与自动修复流水线。
- 跨文件 Schema 语义重构，或一次替换全部同名元素。
- 双端自动选区后直接输入的专用重命名交互。
- XML 与 Image 相互依赖或插件 ID 特判。
- 原生宿主内建 XML grammar、复制 SDK、修改全局运行时环境、自动安装项目工具链。
- 超出本方案停靠需求的多窗口、多编辑组或其他新增编辑器产品能力。
- 发行发布，以及修改或关闭父设计议题；代码实现、普通提交/推送和验收后关闭实施工单已获用户授权。

## Further Notes

### 决策优先级与现状

本方案以本次对话最终决定为准：显式重命名和直接编辑自动同步都纳入首版；双端选区方案已撤回；大纲属于宿主且支持真实同时分割显示，不是插件私有面板或互斥视图切换。

代码调查基于当前工作树，其中有大量此前及其他任务的改动。宿主已有补全、诊断、悬浮和定义跳转接入；不能将 LSP 上游声称支持的方法直接视为本产品能力已经接通。当前补全初始化未宣告 snippet 支持，因此基础标签辅助若涉及模板占位符，需要通过通用能力验证，不能凭服务器支持推断已可用。

现有 DockArea 插入和恢复代码是可复用基础，不能计作新大纲已经完成。实施时重新核对当时状态，保留用户已有改动。

本次对历史固定布局约定的替代仅来自用户明确要求的大纲停靠与分割。其他现行文档、权限、插件边界、唯一文本会话和交付约定继续有效。

### 技术核验项

实现前核验 XML grammar 的具体版本及 ABI、语言服务器 Windows 分发及许可证、SVG 提示的规则来源和覆盖、HTML 标签语义提供方式、格式化独立服务生命周期、完整 DockArea 方向能力。它们是实现前的事实核验项，不代表要重新访谈已经确定的产品范围。
