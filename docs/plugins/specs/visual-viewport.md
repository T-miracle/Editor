# 通用可视视口能力

2026-10-06，按用户要求修正 Image 缩放职责：所有宿主能力面向全部插件公开，
不由单个插件持有，不为每种图片或绘图插件新增缩放专用接口。

## 职责决定

- 公开 `ui.viewport ^1`，适用于文件图片、文档资源图片和非字符网格画布；沿用协议 7 的独立能力协商。
- 插件决定比例、滚轮步长与方向、锚点、平移、自动适配和切换文件后的重置；宿主不保存图片缩放状态。
- 宿主报告原始逻辑像素输入和受控解码的内在尺寸，每帧在实际视口上投影及裁剪。
- 输入保留节点、实例及 revision 校验。连续绝对尺寸事件可合并；滚轮增量和其他输入边界不能丢弃。
- 几何变化保留同一输入身份，文件或结构变化撤销旧身份；不能因每次缩放都更新 revision 而丢失已排队的合法增量。
- 不增加资源访问授权。图片仍必须绑定精确文件或文档版本，按现有权限和解码配额处理。

首个消费者为 Image 0.6.0。普通图片通过视口能力维护自己的手动比例；SVG 继续使用公开画布绘图，
保留透明棋盘、工具栏、居中缩放及初次最长边至少 240px（可见区域不足时等比缩小）。

公开契约正文维护在 [英文 SDK UI](../../../website/src/content/docs/en/sdk/ui.md) 与
[中文 SDK UI](../../../website/src/content/docs/zh-cn/sdk/ui.md)，不在此复制读者文档。
接口类型见 [visual_viewport.rs](../../../crates/plugin-protocol/src/ui/visual_viewport.rs)。
