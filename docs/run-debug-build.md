# 运行、调试与构建

本说明面向使用者，介绍如何在 Me Editor 里配置并运行程序、单独构建、观察并行会话，以及启动调试。
执行与调试都由**插件提供者**承担：宿主不内建语言或工具链知识，也不区分调试器种类，因此下面描述的
行为对任何实现了对应契约的插件都一致。

## 运行配置

标题栏运行组的下拉是唯一入口，包含**运行配置**与**活动会话**两部分。

一个配置包含：

- **名称**：显示用标签，出现在下拉与确认提示中。
- **可执行程序与参数**：程序是一个**可执行路径**，参数是**逐项的参数数组**。带空格、引号、中文与
  Shell 元字符的参数都作为**单个参数原样传递**——编辑器不拼接命令行，除非你显式选择 Shell 模式。
- **工作目录**：程序启动时的工作目录；留空则使用当前工作区。
- **环境变量**：逐项的名称与值，应用在继承的环境之上。值不会被写入日志。
- **构建与启动前步骤**：见下节。
- **断点**：`源文件:行号`，每行一个；属于**运行程序的这个配置**，随共享条目跨机器往返。
- **执行提供者**：默认「跟随默认」。选择某个插件即固定使用它；选择缺失或不兼容时，编辑器会**列出
  原因并让你选择修复**，**不会静默换用**别的提供者。

### 手动创建与从项目发现

「手动创建」从空白配置开始。若已安装的插件能识别当前项目，编辑器还会**发现**候选目标并列出来；
**确认之前不写入任何存储**。确认后该配置记录它来自哪个目标，之后重新发现只更正程序与参数，
**保留你的改动**；目标消失时在选择处标记为失效，由你确认后修复。

### 保存去向

配置可存为**本机**（只在此机器生效）或**项目共享**（写入项目文件，供团队共用）。共享条目只包含
可移植的部分——个人路径、环境与工具目录留在本机。

## 运行与构建

- **运行**启动配置。若该配置的会话已经在运行，再次点击只会**定位已有会话**，不会启动第二个程序。
- **构建**只执行构建步骤：不执行启动前步骤，也不启动程序。未配置构建时该入口**带原因禁用**。
- 构建和启动前步骤**严格按顺序**执行；**任何一步失败或被停止，后续步骤与程序都不会执行**。
- 一步的完成条件是**观察到程序结束**，不是等待固定时长，也不是凭输出内容猜测。
- 运行与构建使用**同一份已保存的配置**：点击前若有未保存的编辑，会先按既有流程确认保存；
  保存失败或取消**不启动任何步骤**。

## 会话与输出

- 程序的输出留在**提供者自己的面板**中（例如终端插件），不会串到其他会话或编辑区。
- 运行组下拉列出**全部会话**：可定位展示，也可停止。大项目里可以同时运行多个独立配置。
- **停止**只作用于所选会话。停止请求被受理**不等于程序已结束**：状态来自提供者的观察。
- 关闭展示页签**不会停止程序**；重新打开下拉即可恢复展示。
- 关闭窗口或切换项目时会**先确认**，可以取消；确认后编辑器会先请求停止仍拥有程序的会话，再拆除
  插件实例，因此不会留下无人管理的后台程序。

## 调试

调试由实现了调试契约的插件提供；编辑器**不内建调试器**，也不假设适配协议或传输方式。

- 配置的「调试」页选择该配置的**执行提供者**——调试会话通过同一个提供者启动目标程序。
- 断点属于配置。**提供者无法在目标中绑定的位置会显示为未验证**，未验证的断点不算已设置。
- 连接中或已暂停时，「停止调试」始终可用——那正是你需要出口的时刻。**继续**、**暂停**与三个
  **单步方向**按会话状态启用；每个不可用控件都给出原因。
- **断点命中会自动定位**：目标在没人要求的情况下停下时，编辑器打开对应源文件并把光标放到该行。
  **你自己驱动到的停不会移动光标**（继续或单步之后），因为那时你正在读文件。
- 暂停后可查看**调用栈**与**局部变量**；变量按所选栈帧显示。
- **断点自动定位与防打断**：开始调试时，若另一个配置的会话已经暂停，编辑器会提示是哪一个，而不是
  悄悄抢走焦点。
- **缺少调试能力不会退化成普通运行**：无法调试时会说明原因。这是刻意的——静默地不带调试器运行，
  看起来像成功，实际给的不是你要的东西。

## 插件变更与进行中的会话

停用、卸载或更新插件前，编辑器会**列出受影响的会话**（正在运行的程序与调试会话）。取消则一切保持
原样。确认后，相关会话明确失败，其目标进程、调试器、订阅与展示由清理路径回收，**不影响无关会话**；
旧提供者的引用不会复活会话，也不会作用到替换它的新实例。

## 作为插件作者接入

实现执行或调试提供者只需公开 SDK，不需要仓库内部 crate 或 SDK 源码副本：

```powershell
editor-app.exe --export-plugin-sdk <目录>
editor-app.exe --plugin-cargo <插件>/Cargo.toml build --target wasm32-wasip2 --release
```

契约与方法的声明形状、错误码、取消与资源释放语义见
[`crates/plugin-protocol/SESSIONS.md`](../crates/plugin-protocol/SESSIONS.md)，服务机制与授权模型见
[`crates/plugin-protocol/SERVICES.md`](../crates/plugin-protocol/SERVICES.md)。
