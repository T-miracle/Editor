# 文档结构

[English](../../en/sdk/structure.md)

`language.structure: ^1` 提供独立的文档结构贡献。它要求 WASM `component`、
`editor.read` 授权及可信工作区，但不要求语言服务器、进程声明或服务权限。
语言识别决定文档的语言；宿主单独选择 `structure:<language>`，与高亮、LSP、
格式化无绑定关系。安装其他包时保留已有有效选择。用户/项目提供者设置及候选
移除沿用通用提供者规则。

```json
{
  "protocol": 7,
  "component": "plugin.wasm",
  "api": {"required": {"language.structure": "^1"}},
  "permissions": ["editor.read"],
  "structure_providers": [{"id": "structure", "language": "novel"}]
}
```

## 纯快照回调

处理 `api::Notification::LanguageStructure(structure::Request)` 并返回
`api::Output.language_structure: Some(structure::Proposal)`。请求包含非零请求标识、
提供者 ID、解析后的设置及 `language::SourceSnapshot`。源快照包含打开文档的 ID、
工作区相对路径、revision 及最多 1 MiB 的 UTF-8 文本。回复必须复制请求标识和文档
版本。文档版本标识具体一次编辑器打开实例，不只是文件名。

宿主在独立、受 fuel/deadline 限制的纯实例中执行回调，不恢复私有快照，不继承环境或
文件系统 preopen，并拒绝所有宿主操作，包括读取资源、编辑、文件访问和创建进程/UI。
设置是只读输入，不能授予权限。初始化及其他回调不得发布结构结果。
只能返回该类型的结构字段；混合回调输出会被拒绝。

## 节点与折叠

`Proposal.nodes` 是完整的 `structure::Node` 树。节点包含显示 `name`、插件自行定义的
不透明 `kind`、可选主题图标、覆盖定义及其后代的 `range`、精确的 `definition` 定位范围
和有序 `children`。范围都是当前快照文本中的 UTF-8 字节左闭右开区间。
定义范围必须非空且位于覆盖范围内；子节点必须位于父节点内，同级节点不得重叠。
宿主没有固定的定义类型白名单。

`Proposal.folds` 单独表示完整的结构范围。注释可以折叠而不成为大纲节点。
折叠范围允许嵌套，不允许交叉；宿主把多行范围转换为原生编辑器的行折叠机制。
不要把覆盖范围作为定位或折叠的替代品。回复最多包含 4,096 个节点、128 层树、
4,096 个折叠范围及 512 KiB 序列化结构数据。名称上限为 512 字节，类型为 100 字节，
都必须非空且不能包含控制字符。非法数据会使整个回复被拒绝。

## 包内图标

`Node.icon` 格式为 `{ "light": "icons/definition.svg", "dark": "icons/definition-dark.svg" }`，
`dark` 可省略。引用是当前安装包确切版本内的有界相对路径，绝对路径、URL、路径穿越和
跨包访问都会被拒绝。运行时规范化所属包和资源路径，每次读取限制为 64 KiB，只接受
不含 DTD、脚本、文本、外部链接或 URL 绘制源的纯几何 SVG。每个回复最多加载 64 个
不同图标路径。文件缺失或 SVG 内容被拒绝时显示宿主默认定义图标，有效节点仍可导航。
不安全的路径声明会使回复被拒绝。

## 原生大纲与生命周期

宿主以原生树呈现折叠按钮、类型图标和名称，管理选择、键盘导航、主题、焦点和滚动。
大纲跟随活动编辑文档，即使面板自身拥有焦点也不改变目标。导航校验当前快照，展开
目标所在折叠范围，跳转到定义并聚焦编辑区。光标归属使用最内层覆盖范围。
可选跟随设置控制自动展开和滚动。

文档变动、关闭/重开、提供者更换及信任/工作区撤销都会使旧结果失效。丢弃宿主任务会
取消结果递交；有界纯计算可以结束，但没有副作用。退役先把 lease 标记为失效，再释放
工作器内存。宿主应用数据前同时检查提供者实例和当前文档版本。没有提供者时显示
原生空状态，不保留其他文档的树。

回调 trap 或调用失败只撤销其纯执行句柄；非法 proposal 范围仅拒绝本次回复，不影响后续有效调用。
发布刷新不会静默重启失效 worker。显式恢复/重新启用插件或替换配置可以产生新句柄，
该插件的其他语言能力仍保持独立。

大纲是宿主停靠面板，不是插件 UI。DockArea 管理唯一的实时分割树、拖动、尺寸调整及
工作区本机恢复。插件不得创建大纲面板，或保存另一套布局、可变文档副本。
