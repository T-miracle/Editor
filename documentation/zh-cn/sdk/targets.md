# 运行目标提供者 — run.targets 1.0

[English](../../en/sdk/targets.md)

发现由用户显式触发，不启动发现的程序。语言和工具包通过标准 `targets::declaration()` 服务契约贡献候选。宿主消费可移植绑定，不解释语言的项目格式、包名称、构建输出或适配器协议。

## 发现与身份

`discover { workspace }` 返回 `{ targets }`，要求 workspace.read 与 process.exec。提供者可在认证的受信任工作区运行受控项目发现工具，但不能执行候选程序。候选包含 identity、label、source、target_type、type_version、binding。

identity 和 label 最多 256 字节，source 和 binding 4096 字节，target_type 128 字节，type_version 为 1–2147483647。单次回复及合并后的宿主目录各最多 128 个目标，最多查询 16 个动态提供者。宿主用认证的提供者命名身份；原始候选不能冒充其他提供者。

binding 是提供者拥有的版本化可移植 JSON，仅含项目相对身份字段，不含凭据、授权、机器可执行路径或进程句柄。发现候选是临时信息；只有显式确认才保存配置，相同已保存绑定重复确认复用该配置。发现不覆盖编辑过的名称、参数、环境或准备步骤。

一个来源失败不丢弃健康来源。失败来源的旧候选保留展示，但阻止运行／构建，直到健康重发现或显式修复。消失或不兼容的目标不会静默替换为另一个可执行程序。

## 准备与产物选择

`prepare { workspace, binding, env }` 返回 `{ program }`，要求 workspace.read、process.exec、ui.panels。env 最多 64 项，名称 128 字节、值 32768 字节；program 最多 4096 字节。提供者验证绑定并产出该目标的确切可执行文件。仅构建不运行它。

宿主按顺序执行构建和运行前步骤，再通过[运行会话](sessions.md)或[调试会话](debug.md)启动产物一次。本次配置快照固定目标、参数、环境、工作目录及有效提供者；修改不改变正在执行的一轮。准备失败阻止启动，显示失败步骤与输出。

每次准备拥有认证的资源根；输出跨原生片段保留 UTF-8，宿主最多保留 64 KiB 准备输出。停止只作用于该准备及其委派原生进程树；升级强制结束等待真实进程和输出结束。取消、退役、超时和提供者替换撤销根，不发布过期可用产物。清理不重放准备或最终程序。

## 独立提供者与可移植性

无需动态构建行为时，声明式目标规则可贡献普通程序。动态提供者协商 plugin.services，通过自己的 WASM 组件发布精确的 run.targets 方法结构。两条路径使用相同的确认、配置、准备与校验规则。

可移植共享配置保留绑定及项目相对数据；机器解释器／工具路径、凭据、权限及运行会话身份保留本机。导入其他工作区建立新的本地配置身份，并要求重新发现有效绑定或显式修复。进程、权限及会话不跨工作区迁移。

独立包使用编辑器的公开 SDK 构建入口，不依赖编辑器实现 crate，也不分发私有 SDK 源码副本。
