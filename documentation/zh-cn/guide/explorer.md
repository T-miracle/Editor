# 文件树

[English](../../en/guide/explorer.md)

文件树列出你打开的工作区。它是树而不是平铺列表：目录就地展开，也可以用工具栏整体展开或
收起。

## 排序

条目按三条规则依次排序：

1. 目录排在文件之前。
2. 忽略大小写的字母顺序，因此 `README.md` 与 `Cargo.toml` 出现在读者预期的位置，不会因
   大小写被拆开。
3. 中文名按读音而不是码位排序，因此 `北京` 会排在其他 `b` 开头的条目之间。

## 哪些内容会被隐藏

文件树遵循工作区内的 `.gitignore` 与 `.ignore`，包括嵌套规则与否定规则，其中 `.ignore`
优先。被这些规则排除的文件不会列出。

目录列举限定在工作区根目录内：不读取上级目录与全局忽略文件，也不跟随符号链接。
你主动提供的导入文件可以从项目之外读取。

## 工具栏

| 按钮 | 作用 |
| --- | --- |
| 定位当前文件 | 展开到正在编辑的文件并选中它 |
| 全部折叠 | 收起所有已展开的目录 |
| 全部展开 | 展开树中的全部目录 |

按 `Ctrl+Shift+R` 可从磁盘刷新文件树，这在构建、切换分支或其他编辑器之外的变化之后很有用。

## 打开文件

单击选中条目，双击文件才在标签中打开它。双击目录或单击其箭头可展开、折叠目录。
再次打开同一文件会聚焦已有标签而不是新建第二个，因此同一文件
的未保存改动不会被拆到两个视图里。

有未保存改动的标签会被标记，关闭时会先询问再丢弃。

## 导入与移动文件

在系统文件管理器中复制或剪切文件、目录后，可通过资源管理器右键菜单粘贴，或在目录树
获得焦点时按 `Ctrl+V`。复制保留源文件，剪切执行移动。外部文件拖入默认复制；拖动一个
目录树条目默认移动，Windows/Linux 按住 `Ctrl`、macOS 按住 `Option` 可改为复制。
目录行写入该目录，文件行写入父目录，空白处写入项目根目录。实际目标目录会高亮。

悬停折叠目录约 600ms 后自动展开；靠近树的上下边缘可自动滚动。取消拖动会恢复本次临时
展开的目录。

同名冲突可选择**跳过**、**保留两份**或**替换**，也可应用于本批后续冲突。替换同名目录
会合并内容、保留目标独有文件，内部同名项继续进入冲突选择。普通转移禁止替换存在未保存
修改的目标。移动已打开文件会保留编辑内容和文本撤销记录。

长操作显示进度并允许取消。失败或取消后保留已完成项，清理当前未完成结果，停止后续项。
符号链接和 Windows 目录联接会跳过。报错和跳过路径的消息保留到手动关闭。

## 撤销与重做文件操作

右键菜单会显示已记录的文件操作对象。目录树获得焦点时，`Ctrl+Z` 撤销文件操作，
`Ctrl+Shift+Z` 重做；编辑区内这些快捷键继续撤销、重做文本。复制、移动、替换和目录
合并可在当前会话内恢复，备份位于项目之外，关闭会话后清理。

恢复前会检查当前磁盘内容。后续修改或路径被占用时需确认；强制恢复涉及未保存编辑内容时，
还需单独确认丢弃这些修改。重做也会检查新冲突。新建与删除命令不属于这套文件转移历史。

Windows 系统文件剪贴板及拖入有专门支持。macOS 复用原生文件路径和文件 URI 剪贴板输入，
尚未实现 Finder 原生剪切意图。Linux 支持文件 URI 输入，原生文件剪贴板支持取决于平台
后端。macOS 和 Linux 尚未进行与 Windows 相同的原生交互验收。
