# 快速开始

[English](../../en/guide/getting-started.md)

Nanobug 是原生桌面程序，不需要账号。

## 安装与更新

Windows 用户运行 Nanobug x64 Setup 安装器，按英文或简体中文向导安装。程序按当前用户安装，
创建开始菜单入口，并提供可选桌面快捷方式。使用已安装的程序与插件文件无需 Rust/Cargo。

更新或卸载前关闭所有 Nanobug 窗口。运行新版本安装器即可更新同一安装；通过 Windows 的
“已安装的应用”卸载。既有 `MeEditor` 用户数据目录中的设置、历史与已安装插件数据会保留。

macOS 使用 DMG 中的应用包（将 Nanobug 拖入 Applications），或通过 PKG 安装。Linux 使用
发行版的包管理器安装 DEB/RPM。当前阶段只提供这两端的兼容打包入口，未构建或验收安装行为。
macOS 签名、公证与平台专属插件依赖需要另行准备。

## 打开文件

启动时传入文件路径，或在文件树中点开一个文件。文件按 UTF-8 读取，编辑器随后询问已安装
的插件它是哪种语言，这决定了语法高亮，以及是否有可用的语言服务。

窗口标题与编辑器状态栏会显示文件名和编辑器解析出的语言。标签上的圆点表示缓冲区有未保存
改动；按 `Ctrl+S` 保存。

## 打开项目文件夹

传入一个目录而不是文件。编辑器把它当作工作区根目录，并据此构建文件树，因此该目录内的
`.gitignore` 与 `.ignore` 规则决定哪些文件会出现。

工作区同时也是插件与语言服务的作用域单位。因此打开文件夹才会让定义跳转、诊断这类语言
功能对该项目生效；单独打开的文件不属于任何工作区。

## 编辑器对你的项目的预期

- 文件按 UTF-8 读写，不对其他编码做转换。
- 文件树遵循 `.gitignore` 与 `.ignore`，不读取工作区之外的内容。
- 语言功能需要对应插件，插件可能还需要你另行安装的语言服务。编辑器不会自行下载工具。
- 保存会在项目目录之外写入历史快照，因此你的仓库不会多出编辑器产生的文件。
