# 安装与管理插件

[English](../../en/guide/plugins.md)

插件为编辑器带来语言、语法高亮、面板与工具。本页讲的是宿主行为：如何安装包、批准它做什么、
以及控制它在哪些项目运行。每个插件自己的功能记录在随包分发的 README 里，插件管理器会在
概览标签中显示它。

## 安装包

打开**插件管理**，用**从本机安装 ZIP…**选择本机的插件包。插件包是插件的分发形式：一份清单
加上资源，当插件需要无法声明的行为时再附带一个 WebAssembly 组件。

在你批准之前不会安装任何东西。确认对话框会显示包的来源、安装后允许它做什么，以及它声明的
具体程序与参数。

## 权限提示意味着什么

包声明它需要的能力，你一次性批准这一组。声明式资源包会说明它不需要任何运行权限。对可执行
插件，对话框会列出每项声明权限授予的内容：

| 权限 | 批准后允许 |
| --- | --- |
| 读取包内资源 | 读取该插件自己安装包内的资源文件 |
| 读取工作区文件 | 读取当前工作区中的文件 |
| 剪贴板 | 读写系统剪贴板 |
| 私有存储 | 保存插件自己的配置与会话数据 |
| 启动声明的服务 | 启动该包声明的固定本机服务，该程序随后以你的用户账号运行，可访问本机文件与网络 |
| 执行任意程序 | 以你的用户账号执行任意本机程序（含交互式终端） |
| 准备依赖 | 把包声明的服务依赖下载、校验并解包到编辑器私有目录。不运行安装脚本，也不修改全局 `PATH` |
| 原生安装步骤 | 另行展示程序、参数、目标与用途，只有你确认该具体方案后才会执行 |

原生程序以你的账号权限运行；约束插件自身 WebAssembly 的沙箱并不约束它们。批准一项权限是在
对一个程序作决定，不是走形式。

## 启用、禁用与作用范围

每个插件有全局开关与项目开关：

- **全局启动 / 全局禁用**决定该插件是否允许运行。
- **本项目启用**决定它是否在你当前打开的工作区中运行。

被你全局禁用的插件会一直保持禁用，直到你重新打开；安装更新不会把它静默重新启用。项目开关
是你把重型插件（语言服务、终端）挡在不需要它的项目之外的方式。

## 受限工作区

编辑器不信任的工作区处于受限状态。在受限工作区里你仍然可以编辑文件，但插件与语言工具不会
启动，也不会采用项目提供的工具路径。这是为了防止某个仓库自带配置影响你。信任是工作区的属性，
项目配置无法授予它。

## 更新

更新会用新版本替换正在运行的版本。如果新版本声明了旧版本没有的权限，你会被再次询问；拒绝则
旧版本继续可用。

编辑器会先准备新版本。准备失败会保留旧实例继续运行。只有新版本就绪后才停止旧实例；激活失败
则恢复旧版本及其私有数据。更新不会重新执行旧实例已经收到的命令。

## 卸载插件

卸载会移除插件的面板、停止它启动的进程，并释放它占用的资源。卸载会先请求确认，因为移除一个
插件也可能移除你正在依赖的语言或面板。

属于该插件的设置与私有数据会随之移除。插件写进你文档里的数据不会被改动。

## 出问题时

详情页有**运行日志**标签，显示本次会话的消息；顶部有**重启插件**按钮。

- 重启会替换该插件的实例并重新连接。它保留插件的私有文件与最近一次安全检查点，因此失败后
  首先应该尝试重启。
- 日志标签显示插件及其服务上报的内容，包含级别、来源与时间。标签上的彩色图标表示有未读的
  警告或错误。
- 超出执行预算或崩溃的插件会被退役并上报。编辑器与你的其他插件继续运行。
- 反复失败的语言服务会停止重试：三次失败后需要显式重启插件，日志中会有说明。

重启或移除插件不会修改你的文档，也不会回滚插件在编辑器之外已经做过的事情。
