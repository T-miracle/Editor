# Editor guide

[简体中文](../../zh-cn/guide/index.md)

This section covers using Nanobug as an installed product. It assumes you already have
the editor; building it from source is a repository README topic, not a user topic.

The pages here grow with the editor. Each one is written from the reader's point of view
and states what the editor actually does today, including the limits.

## What is covered

- Getting started: opening a file or a project folder, and what the editor does with each.
- Editing and shortcuts: typing, selecting, moving text, folding, soft wrap and saving.
- Explorer and search: how files are listed, which ones are hidden, and how search is scoped.
- Panels and layout: the explorer, the editor area and docked plugin panels.
- Settings and themes: which settings apply to you and which belong to a project.
- Installing plugins: permissions, enabling, updating and removing them.

## Plugin usage lives elsewhere

Each plugin documents its own features in its package README, and the editor shows that
README inside the plugin manager. This guide only covers the host behaviour: how a package
is installed, what the permission prompt means, and what happens on update or removal.
[Run, debug and build](run-debug-build.md) explains configurations, portable targets, ordered preparation, independent sessions and real debug inspection.
