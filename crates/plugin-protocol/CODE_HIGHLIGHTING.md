# 只读原生代码块高亮

`ui.code_highlighting ^1` 是独立的声明式能力，宿主提供版本为 1.0.0。基础传输仍为 `protocol = 7`，UI 文档仍为 `Document.version = 1`；插件包版本单独提升。它补充已有 `ui.richtext ^1` 的 `Kind::CodeBlock { text, language }`，不替代该能力，不授予编辑、文件读取、外部进程或语言服务器启动权限。

## 声明与授权

`Document.code_highlighting` 默认 `false`。未开启时 CodeBlock 保持原生只读等宽呈现，不请求高亮。开启时，插件清单必须协商 `ui.code_highlighting` 与 `ui.richtext`、声明并获准 `editor.read`，且输出来自该实例自己声明的工作区编辑区面板。Application 实例和其他面板不能借用当前工作区权限。

开启的文档必须带 `Document.source: DocumentVersion`，精确回显该面板最近一次获准 Preview 的文档 ID、工作区相对路径与 revision。源文本来自宿主的版本化内存通知；插件声明派生的代码文本与语言，不通过本能力读取文件。宿主在发布和异步结果采用前分别检查归属及版本，不能凭文件路径或节点名猜测源身份。

```json
{
  "version": 1,
  "revision": 12,
  "source": { "id": "open-document-1", "path": "notes.sample", "revision": 4 },
  "code_highlighting": true,
  "root": {
    "id": "example-code",
    "kind": { "type": "code_block", "text": "let value = 1;\n", "language": "rust" }
  }
}
```

这个例子请求已经选中的 `rust` 语言高亮提供者，不授权安装或启动工具。普通节点、代码文字与空白仍采用既有 UI 配额。缺少新能力或 `ui.richtext` 返回 `CapabilityUnavailable`；缺少读取或面板作用域权限返回 `PermissionDenied`；开启但未带 source 的结构返回 `InvalidRequest`；过期或错误的 source 返回 `StaleRevision`。非法发布不会成为当前视图。

## 提供者与原生呈现

高亮只复用已安装、已启用且有效选择的动态 Tree-sitter WASM grammar、查询和 parser factory。识别与高亮提供者独立，选择及替换遵循 [LANGUAGES.md](LANGUAGES.md)；不重新引入宿主内建 grammar。`language` 优先匹配公开语言 ID，也允许当前语言声明中的显示名或扩展名，存在歧义时按既有识别选择解析或降级；不包含特定语言的硬编码别名表。插件自行归一化其领域额外别名，宿主不按 Markdown、插件 ID 或特定语言执行分支。

未声明语言、未知语言、缺失或停用的提供者、加载或解析失败以及预算耗尽都使对应代码块保留等宽文字及代码块外观，不拒绝整份其他方面合法的视图，不丢失代码、空白或换行。本能力不启动额外 LSP，也不从 HTML、URL 或代码内容隐式读取资源。

提供者声明的静态注入沿同一公开语言契约执行：每个允许的目标语言使用独立选中的 WASM 提供者。缺少或停用目标只使相应注入范围保留普通样式，不借用内建 parser；目标替换、选择变化及停用同样撤销旧批次。注入与主语法共用每块捕获、文字、名称、取消及期限预算，循环或过深注入降级。

后台任务只产出有界的只读捕获范围与语义名称，原生绘制按当前主题解析颜色和文字样式。主题变化不能让缓存沿用旧颜色；没有对应主题样式的捕获保留普通代码样式。WASM 访客不接收 GPUI 对象、Parser 句柄或另一份可编辑文档，预览不拥有源文档的选择、IME 或 Undo/Redo。

## 生命周期与资源上限

后台结果同时绑定预览实例、面板、源文档 ID／路径／revision、UI 场景 revision、节点身份、确切代码与语言，以及当前选中的提供者版本和有效代次。文档切换、编辑、关闭、预览撤销、插件禁用或卸载、工作区信任撤销，以及提供者变更或退役，都使旧任务和缓存不再具备绘制资格。任务取消后释放批次与资源配额，迟到结果只能被丢弃。

同一路径重新打开、同一提供者身份停用后再启用、或恢复到相同文本均不能恢复旧任务的权限：源文档实体和实例／提供者代次必须仍匹配，避免 ABA。主题变化可以重新绘制仍有效的语义捕获，不能把已经退休的解析结果重新激活。

宿主上限如下；超限采用对应代码块的等宽降级，不改变源码或原生视图授权：

| 资源 | 上限 |
| --- | --- |
| 全局活动高亮批次 | 4 |
| 每个原生预览同时在途批次 | 1 |
| 每个场景参与选中提供者解析的代码块 | 64 |
| 每个场景保留的捕获 token 总数 | 16,384 |
| 每块代码输入 | 64 KiB UTF-8 字节 |
| 每块捕获 token | 4,096 |
| 每个捕获名称 | 128 UTF-8 字节，复制前检查 |
| 每块原始／最终捕获名称累计 | 各 64 KiB，复制前检查 |
| 注入深度／解析层数 | 4 层／每块 32 层 |
| 每块注入 content 事件 | 4,096 |
| 每块注入物理 included ranges | 4,096 |
| 每块注入 included ranges 累计 | 64 KiB |
| 每批截止时间 | 30 秒，包含等待执行的排队时间 |

这些限额补充整份 UI 的 2 MiB 编码、1 MiB 文字和 2,048 节点限额，不扩大原有权限。无有效提供者的块不借此触发安装，也不能占用无限重试队列。实际包、提供者热切换、原生绘制和门禁的验证结果记录在对应实施工单中；本文说明契约，不作为测试通过证明。
