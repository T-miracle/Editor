# XML grammar

The unmodified `tree-sitter-xml.wasm` is from the official
[tree-sitter-xml v0.7.0 release](https://github.com/tree-sitter-grammars/tree-sitter-xml/releases/tag/v0.7.0).
The module exports the XML grammar with ABI 14. SHA-256 is
`9950327f8542a3d563fe4192aa05986a53e6fd6adca518cbb1a1699cbc8970ad`.
The upstream MIT license is included as `LICENSE`. The host verifies the ABI and compiles
the plugin's local highlight query before publishing this grammar.
