# 10 — 按内容块双向同步滚动并记住开关

**Status:** ready-for-agent — 用户已要求执行，按阻塞关系实施。

**GitHub:** [#36](https://github.com/T-miracle/Editor/issues/36)；父方案 [#26](https://github.com/T-miracle/Editor/issues/26)。

**规格：** [Markdown 插件总方案](../spec.md)。验收覆盖：M07、M05（同步偏好）、M06、M14、M15、M16。

## What to build

滚动源码或预览时另一侧跟随对应段落，底栏链条开关允许独立阅读并按工作区记忆。

## Acceptance criteria

- [ ] 通过通用源编辑器视口通知和定位能力关联源码块与渲染块，默认双向同步，不以整篇百分比作为主要映射。
- [ ] 程序性定位标识来源或抑制回授，不产生来回滚动循环；手动操作两侧均有效。
- [ ] 长图片加载、表格、软换行、编辑和分割线宽度变化后刷新映射，旧 revision 映射不得应用。
- [ ] 三个模式图标右侧显示链条开关，有提示、选中态、键盘操作；仅分栏可操作，关闭后独立滚动。
- [ ] 同工作区切换文档和重开保持开关，另一工作区独立；禁用插件后撤销视口订阅。
- [ ] 真实包原生测试验证两侧可见段落、布局变化与反馈抑制，不只断言内部滚动数值。
