# 04 — 使用顶部格式工具栏完成可撤销编辑

**Status:** ready-for-agent — 用户已要求执行，按阻塞关系实施。

**GitHub:** [#30](https://github.com/T-miracle/Editor/issues/30)；父方案 [#26](https://github.com/T-miracle/Editor/issues/26)。

**规格：** [Markdown 插件总方案](../spec.md)。验收覆盖：M03、M06、M15、M16。

## What to build

在源码编辑区顶部用按钮对选区加格式或插入模板，预览立即反映结果，每次操作可一次撤销。

## Acceptance criteria

- [ ] 按用途分组提供标题、粗体、斜体、删除线、行内代码、代码块、引用、无序列表、有序列表、任务列表、链接、图片和表格。
- [ ] 有选区时操作选中文字，无选区时插入模板并选中待填写内容；块级与多行选区有一致、可记录的行为。
- [ ] 通用文档编辑请求携带目标与 revision，经 DocumentSession 写入，不因工具栏取得焦点而丢失原选区。
- [ ] 每次操作是一个撤销步骤，重做可恢复；中文、跨行及 UTF-8 边界通过可观察回归。
- [ ] 缺失的顶部贡献或选区编辑能力随本单扩展公开契约、SDK 和独立夹具，禁止 Markdown 专属宿主调用。

## Blocked by

- 02 — 编辑未保存 Markdown 并实时查看原生分栏预览

## Implementation guardrails

图片按钮本单生成 Markdown 引用模板；剪贴板和拖入图片保存归工单 06。先完成必要的文档事务接缝预重构并验证原编辑行为，再实现格式命令。

遵守插件根部 AI 执行约定。所需接口、权限、宿主接入、插件行为、SDK 与可观察回归在本单闭环；必要预重构先保持行为并验证，不能以占位 UI 或仅协议声明完成工单。保留其他任务改动，新增代码同步补注释。

## Verification

沿真实插件包、公开管理器、原生编辑器交互主接缝验证以上验收项。先运行针对性回归，再执行仓库要求的格式、非 UI workspace 测试与 workspace 编译；涉及 editor-app 追加相关测试和原生验收，实际 WASM 测试先构建再显式运行。记录失败归因与未验证内容，不以 mocked 内部结果替代完整行为。
