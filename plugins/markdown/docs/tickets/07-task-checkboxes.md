# 07 — 在预览中勾选任务并同步源码

**Status:** ready-for-agent — 用户已要求执行，按阻塞关系实施。

**GitHub:** [#33](https://github.com/T-miracle/Editor/issues/33)；父方案 [#26](https://github.com/T-miracle/Editor/issues/26)。

**规格：** [Markdown 插件总方案](../spec.md)。验收覆盖：M11、M06、M03（任务撤销）、M16。

## What to build

点击预览任务框更新对应源码标记，支持撤销与重做，其他预览内容保持只读。

## Acceptance criteria

- [ ] 复用源码块映射定位任务标记，未选中与选中双向切换，支持嵌套列表和中文内容。
- [ ] 点击请求绑定文档身份与 revision，旧预览或已关闭文档的事件被拒绝，不修改相邻任务。
- [ ] 通过工单 04 的通用编辑事务写入，单次点击一个撤销步骤，预览与源码同步。
- [ ] 真实包交互测试覆盖快速编辑后点击、撤销重做、切换文档与插件停用。

## Blocked by

- 02 — 编辑未保存 Markdown 并实时查看原生分栏预览
- 04 — 使用顶部格式工具栏完成可撤销编辑

## Implementation guardrails

不引入预览富文本编辑或第二份任务状态真相。

遵守插件根部 AI 执行约定。所需接口、权限、宿主接入、插件行为、SDK 与可观察回归在本单闭环；必要预重构先保持行为并验证，不能以占位 UI 或仅协议声明完成工单。保留其他任务改动，新增代码同步补注释。

## Verification

沿真实插件包、公开管理器、原生编辑器交互主接缝验证以上验收项。先运行针对性回归，再执行仓库要求的格式、非 UI workspace 测试与 workspace 编译；涉及 editor-app 追加相关测试和原生验收，实际 WASM 测试先构建再显式运行。记录失败归因与未验证内容，不以 mocked 内部结果替代完整行为。
