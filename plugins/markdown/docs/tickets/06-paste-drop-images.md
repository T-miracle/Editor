# 06 — 粘贴或拖入图片并保存同级引用

**Status:** ready-for-agent — 用户已要求执行，按阻塞关系实施。

**GitHub:** [#32](https://github.com/T-miracle/Editor/issues/32)；父方案 [#26](https://github.com/T-miracle/Editor/issues/26)。

**规格：** [Markdown 插件总方案](../spec.md)。验收覆盖：M09、M10（写入）、M03（插图撤销）、M06、M16。

## What to build

把剪贴板或拖入图片保存到 Markdown 文件同级目录并插入相对路径，随即在预览中显示。

## Acceptance criteria

- [ ] 支持粘贴及拖入图片，尚未保存文档先提示保存；取消保存或无可写目录时不落盘且不插入悬空引用。
- [ ] 依次寻找 img.后缀、img1.后缀、img2.后缀，后缀符合实际格式；不建立 assets 子目录。
- [ ] 通过不会覆盖现有文件的创建方式处理名称竞争，并测试连续及多图输入、已有同名文件、保存失败和权限拒绝。
- [ ] 文件写入与文档编辑结果分别可确认，失败不冒充成功；文档已关闭或 revision 过期时不得把链接写进其他文档。
- [ ] 引用插入经既有编辑事务支持撤销；明确落盘图片的生命周期，不把文本撤销自动扩展为删除外部文件。
- [ ] 通过真实包的剪贴板／拖入入口与隔离目录验证图片、引用和预览一致。
