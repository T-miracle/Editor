# 03 — 通过底栏图标切换并记住三种视图

**Status:** ready-for-agent — 用户已要求执行，按阻塞关系实施。

**GitHub:** [#29](https://github.com/T-miracle/Editor/issues/29)；父方案 [#26](https://github.com/T-miracle/Editor/issues/26)。

**规格：** [Markdown 插件总方案](../spec.md)。验收覆盖：M04、M05（模式）、M14、M15、M16。

## What to build

底栏工具组右侧显示三个项目风格图标，让用户切换仅编辑、分栏、仅预览并按工作区记忆。

## Acceptance criteria

- [ ] 生成文本编辑、左右分栏、预览三个 SVG 图标，按主题着色，带中英文提示、选中态与键盘焦点。
- [ ] 按钮位于底部栏左侧现有工具按钮组右边，用短竖线分隔，不覆盖插件管理与日志入口。
- [ ] 默认分栏；模式切换不丢文档、选区或撤销历史；隐藏一侧不留空白，源码工具栏随源码区显隐。
- [ ] 同工作区切换 Markdown 文档及重开保持最近模式，另一工作区独立。
- [ ] 布局与底栏贡献经通用接口接入、撤销；通过真实点击、模式恢复及禁用测试。
