# Markdown 插件

本包通过公开语言贡献为 `.md`、`.markdown` 提供 Tree-sitter WASM 源码高亮，并通过文件预览贡献显示左源码、右原生预览。输入、粘贴、撤销、重做和重新加载后，预览采用当前未保存内容。停用、卸载与替换后撤销对应预览和语言贡献。

当前 Markdown 0.17.0 通过 `editor.layout`、`ui.tools`、`ui.content_colors` 与 `storage.private >=1.1` 提供自己的布局、底栏功能、内容配色和按工作区共享的显示设置。原生输入与撤销历史由宿主保留；分栏拖动需要 `ui.native >=1.1`。将 `editor-app.exe` 与同目录的 `plugins` 文件夹一起保留；受信任工作区首次使用时，安装确认窗口显示来源及权限。`storage` 用于插件私有显示设置，从未授予该权限的旧版本更新时需确认新增授权。受限工作区继续允许普通文本编辑。

右侧插件工具按钮组提供编辑、分栏、预览、同步滚动和格式工具栏显隐；`.md` 与 `.markdown` 在同工作区共享选择。旧 session 显示设置一次导入，已有插件设置优先。首次解析及持续输入期间保留原生文本；派生预览超出节点、事件、深度或单个文本限制时显示原因，保留可编辑源文件。这个有限退回不保证任意大文档都能完整预览。

0.17.0 去掉普通单段列表条目的冗余布局容器，降低实际节点消耗；多段落、嵌套列表和独立表格单元格保持原有结构。仓库的 `docs/plugins/specs/plugin-api-platform.md` 已作为完整预览回归输入，不修改原文或放宽通用安全配额。

`ui.incremental` 保留同一文件上一棵只读预览树并复用未改变的块；旧树只用于绘制，不能授权文本编辑或旧事件。宿主按首次编辑后的 150 ms 节奏合并发布，在途回答后继续提交最新版本。插件自行决定源码模式下是否解析，并在重新显示预览时刷新最新文本。同一文件的新 revision 保留最后手动滚动的一侧，换文件才重置滚动；工具栏图标通过通用 `ui.icons` 提供。

取消首次安装、禁用或卸载都是持久选择：重启、更换工作区和新版随包 ZIP 不会重新启用，也不会覆盖已有 Markdown 预览或语言提供者。卸载时是否删除插件数据不影响该选择。之后需要安装或重新启用，可在插件管理页主动安装随包 ZIP 或启用已安装的插件；正常编辑不重复询问权限。首次确认之前不启动插件、不读取图片、不写入文件或打开网页。

预览支持 CommonMark 基础语法及 GFM 表格、任务列表和删除线。列表保留有序起始编号，支持嵌套引用、列表和代码块；任务框可更新对应源码，其他内容保持只读，图片通过原生图片节点呈现，代码块使用等宽文本。原始 HTML 显示为文字，不渲染嵌入 HTML；首版不提供数学公式和 Mermaid。

Markdown 解析在独立 WASM 组件中完成。宿主提供通用原生富文本、代码块和源码范围能力；插件不读取文档文件，仅通过版本化公开请求提交格式编辑，不维护另一份可变文档或撤销历史。预览树回显源文档身份与 revision，以供宿主拒绝过期结果。

围栏代码通过公开 `ui.code_highlighting` 声明式能力请求当前选中的语言提供者：标记可匹配已安装声明的语言 ID、显示名或扩展名，不通过宿主内建 grammar 回退，也不为示例代码启动 LSP。未知、无标记、停用、失败或超出工作预算时仍显示原代码的等宽样式。提供者竞争使用现有用户／工作区选择；安装、替换、停用及重新启用会更新颜色，迟到结果核对源文档、场景和提供者不可复用代次。查询返回只读 UTF-8 范围与 capture 名称，当前深浅主题在绘制时决定颜色，代码和撤销历史保持不变。

任务框复用原生 Checkbox 的点击与键盘切换，提供中英文操作提示。点击仅接受当前 UI revision 中真实解析的任务节点，并核对其原始三字节标记范围；未勾选标记接受解析器支持的空格、TAB、VT、FF，已勾选标记接受 `[x]` 和 `[X]`，换行或 Unicode 空格不作为任务标记。嵌套任务按自己的标记独立定位，不从客户端节点字符串猜测偏移。任务与格式操作共用一个异步文本意图 owner：先通过 `editor.edit` 读取实际源文档选区、核对文档版本及所选文字，再原子替换任务标记中间一个 ASCII 字节；核对时保留原始空白字节，勾选使用小写 x，取消 `[X]` 也只改成空格。单字节长度不变，原选区和光标保持不变，一次切换对应一次 Undo／Redo，源码仍为未保存编辑。

任务状态只从新 Preview 快照重建，不乐观修改派生勾选状态。源文档改变、关闭或新的任务、格式及图片输入会取消旧文本意图；原选区竞态由事务再次检查，旧节点、旧 revision 不更新相邻任务。任务开始可停止图片引用插入，但已受理保存继续观察文件收据。任务失败在源码工具栏显示对应的中英文原因；其他预览文字、代码、HTML 与非任务列表没有写入行为。

预览链接使用公开 `ui.links` 与 `editor.navigation` 能力，在用户点击或键盘激活当前原生链接时导航。访客核对当前 UI revision、源文档版本、真实 CommonMark 链接及渲染节点范围；事件地址必须精确匹配同一公开 HTML writer 生成并经原生控件单次 HTML 属性解码的 href，再以对应原始解析 URI 分类与请求，不对整个事件 URI 做百分号解码或替换目的地。原始 HTML、代码块、图片 alt 内部链接和普通文字本身不产生业务导航。导航不修改源码、选区或 Undo；失败说明与格式错误、已保存图片收据在源码工具栏共同显示，不相互覆盖。导航失败也在预览正文滚动区外显示当前文档的只读中英文原因，仅预览模式和长文滚动时仍可见，预览超限回退也保留说明；新的有效导航、源码变化或关闭会清除旧说明，无源文档时不显示。

真实链接同步声明到最终原生 RichText、Image 或图片错误替代文字叶节点，容器不重复声明。仅图片的外层链接保留图片 alt 作为访问名称，图片加载失败后仍可导航；图片 alt 内部的链接不能借用外图激活权限。混合文字／图片按各叶节点的真实可见内容提供名称，重复文字链接沿源码顺序分别声明。名称最多 256 字节并在完整 UTF-8 字符处截断，空名称由宿主本地化；href 至多 4096 字节，超过此限制不声明原生焦点目标。文字链接可逐个 Tab 聚焦与键盘激活，聚焦提示由通用宿主提供；图片和替代文字使用原生按钮交互。链接目标计入整篇 2048 个原生控件、1 MiB 文本与 2 MiB 编码预算，超限沿用可见预览限制提示。

标题锚点按实际解析标题文字生成：Unicode 字母与数字、小写、下划线及连字符保留，空白组转成连字符，标点移除，空名使用 `section`。按源码顺序全篇去重，重复名使用 `-1`、`-2` 等后缀并跳过已占用名字；自然带后缀的标题也不会与已生成锚点碰撞。锚点严格单次百分号 UTF-8 解码后精确匹配，区分大小写；空锚点、不存在的标题及无效编码显示中英文原因。中文、引用中的标题、Setext 标题及含图片的标题均定位到已有原生渲染节点。

相对 `.md`、`.markdown` 链接经宿主相对源文档目录打开，路径先由访客单次解码判断扩展名，请求仍保留原始编码路径，宿主只解码一次并校验授权工作区。支持相对文档后的 `#标题锚点`：仅以实际 `Opened` 回执的文档 ID、路径、revision 与目标 Preview 一致时继续定位，兼容两个消息的到达顺序；再切文档、修改或关闭会停止旧定位，不猜测目标身份。相对路径的 query、非 Markdown 文件、绝对路径及其他协议不扩展。邮件自动链接按解析器的 Email 类型保留隐含 `mailto:` 并拒绝导航，包括以 `.md`、`.markdown` 结尾的邮箱；明确写出的 `[文件](user@example.md)` 仍可作为相对文件链接，不按 `@` 字符一律拒绝。

HTTP(S) 网页链接在点击后通过受控系统浏览器入口打开，需要 `navigation.external` 权限；解析与布局不调用外部程序。每个原生导航请求期限 30 秒；新的链接点击取消旧请求，完成、取消、失败或源变化清理请求关联。打开回执先于目标预览时只保留小量元数据，直到精确目标预览或新的意图／源变化，不保留活动宿主任务。

图片使用公开 `ui.images` 能力，只向宿主声明 URI、作者替代文字及原文 UTF-8 范围。相对路径由宿主相对当前 Markdown 文件目录解析，需 `workspace.read`；HTTP(S) 图片需 `network.images`。宿主异步读取并核对文档版本和实例归属，加载、路径越界、无权限、网络及解码失败只显示该图的替代文字与中英文原因，不阻塞整篇预览。空地址或超过 4096 字节的地址由插件显示局部说明；富文本和原始 HTML 中的图片标签不能隐式读取资源。

支持 PNG、JPEG、GIF、WebP 的首帧以及 UTF-8 SVG；动画暂以首帧显示。单图读取至多 8 MiB、请求期限 30 秒，单个预览最多声明 64 张图片。原生像素单轴至多 4096，当前图片缓存共用 64 MiB；SVG 另受 512 KiB XML、10,000 节点／展开引用、128 层与临时画布配额限制，不支持 SVGZ、DTD 实体及嵌入图片读取，文字使用系统字体。行内图片按源码顺序拆为富文本、图片、富文本，保留前后文字、强调及代码；引用和列表中的图片保留嵌套结构，含图片的表格采用原生行与单元格，保留表头和各列内容。图片加载后的尺寸变化由原生布局处理，迟到的旧文档、旧目录或旧 revision 结果不得更新当前预览。

源码顶部工具栏分为标题；粗体、斜体、删除线；行内代码、代码块；引用、无序列表、有序列表、任务列表；链接、图片、表格五组。全部采用 24 × 24 画布、2 px 圆角描边的 SVG 图标，24 px 高的原生按钮保留中英文提示，普通单行工具栏含边框高 29 px。窄分栏按内容换行并自动调整高度，仅预览模式隐藏源码及工具栏。图片按钮生成相对图片引用模板；图片文件通过原生粘贴或文件拖入导入。长导入收据使用 56 px 原生滚动区域，保留源码编辑空间。

图片导入使用公开 `editor.images` 能力及 `clipboard`、`workspace.write` 权限。未保存文档由宿主先提示保存，取消或无法确定可写目录时不落盘。宿主识别实际 PNG、JPEG、GIF、WebP 或 SVG 内容，仅向插件传递格式、长度和不透明输入句柄；插件不读取剪贴板字节、文件或网络。图片保存到 Markdown 同级目录，不建 assets 子目录，不覆盖用户文件。同一批共用递增编号，按 `img.实际后缀`、`img1.实际后缀`、`img2.实际后缀` 寻找名称；例如混合 PNG／JPEG 为 `img.png`、`img1.jpg`。新批次从 img 开始，由宿主原子创建处理已占用名称及并发竞争，编号上限为 4096。

原生宿主正在准备图片或等待保存确认时，后续粘贴／拖入明确提示稍后重试，不改变第一批的选区。拖入位置必须命中源码正文；工具栏、行号区及宿主阻塞浮层不能作为插图位置。

每批最多 8 张、每张 8 MiB、合计 32 MiB；宿主所有待处理输入共用 64 MiB 配额，输入句柄期限 30 秒。插件逐张确认保存，全部成功后一次性替换原输入选区，生成相对图片引用，多图沿原文 CRLF 或 LF 换行，选区外的字节保持不变，光标移到引用末尾。拒绝拆开 UTF-8 或 CRLF；替换后的完整源文必须实际解析出每张图片的准确范围和目的地，现有代码围栏、转义等隐藏图片的上下文不插入引用，并显示已保存文件及原因。现有图片替代文字里的嵌套图片只会成为外图替代文字，因此也拒绝插入；普通链接内容中的可见图片仍允许。文档身份、revision 与原选区由宿主事务再次校验；整批引用只占一次 Undo，撤销或重做引用不删除已落盘图片。

文件保存和引用插入分别确认：中途失败、文档改变或关闭、新的图片输入及工具栏格式操作会停止后续插入，完整保存的图片保留，并在对应文档工具栏显示名称与原因；重新打开同一路径仍可查看该实例保留的收据。后来的失败不能清除此前未确认引用的完整文件说明；当前批次全部名称显示，较早收据最多显示最近 32 个名称及剩余数量。已受理的保存请求继续观察完成收据，不用取消等待冒充文件回滚。若请求超时或取消时宿主已进入副作用阶段，说明未确认的文件名或引用结果，不冒称成功，也不声称文件已被删除。

行内格式保留非空选区的原文和正文选中。粗体、斜体和删除线把每行边缘空白留在标记外，跨行时分别包裹各行有效正文，空白行及 CRLF 原样保留；纯空白选区不提交格式编辑。插件解析替换后的完整文档，要求每段生成的标记恰好对应原生预览采用的强调事件范围；标点与未选正文相邻等无法表达的范围拒绝编辑，不改动相邻正文、不插入隐藏字符。正常中文单词相邻仍可格式化。结果选区覆盖首行至末行的有效正文，中间保留生成的标记与换行。标题固定为一级标题；标题、引用和列表将选区扩展到完整行并对每行加前缀，有序列表从 1 递增，结果选中生成的整行。选区恰在下一行开头结束时不包含该行，最终行终止符留在替换外，已有 CRLF 保持不变；块级命令拒绝位于 CR 与 LF 之间的选区端点，避免拆开换行符。代码块同样扩展整行，保留正文并选中正文；行内代码与围栏长度超过原文最长连续反引号，避免标记提前闭合。表格把选中行放入第一列，转义管道字符，生成两列 GFM 表格。

链接和图片引用转义标签中的反斜杠和方括号，渲染后的标签保留原字符，结果选区覆盖转义后的标签字节。插件与强调格式共用完整文档解析和范围校验；跨空白段、现有代码环境等无法形成完整引用的选区拒绝编辑，不吞字符、不扩展选区。强调和引用模板也检查其在完整源文中的实际解析范围。

无选区时插入本地化模板并选中待填写文字；链接、图片选中文字占位，表格选中第一列表头。块模板在当前光标插入，必要时按原文换行约定添加分隔，不替换光标两侧文字。每次操作通过 `editor.edit` 读取指定文档选区、核对源版本和选区文字后提交一次范围替换，并携带原选区防止选区竞态；新点击或源文档改变取消旧异步意图。宿主通过 DocumentSession 写入并维护唯一撤销历史，插件等待新预览快照，不自行修改源副本。权限不足、过期文档、选区改变和超时等失败在工具栏显示本地化原因。

底栏右侧插件工具按钮组显示编辑、分栏、预览及显示开关。首次使用默认左源码、右预览，分栏中间可拖动；插件按工作区与 Markdown 类型保存选择，同工作区切换 `.md`、`.markdown` 文件及重新打开沿用最近模式。切换模式保留文档、选区及撤销历史，隐藏的一侧不留空白。

图标通过公开 `ui.tools` 能力和 `Document.tools` 提供，模式在插件内部改变 `editor.layout` 内容。三个 SVG 分别以文本行、左右分栏和预览图案表达模式，采用 16 × 16 的设计网格和 `currentColor` 随主题着色，按项目底栏按钮的 14 px 尺寸显示；按钮提示、选中态和键盘焦点由通用宿主控件提供。

先构建匹配宿主，通过 `editor-app.exe --plugin-cargo plugins/markdown/Cargo.toml build --target wasm32-wasip2 --release` 独立编译，再将清单、README、markdown.wasm、grammar、查询、图标与许可归档为标准 ZIP。步骤见[直接打包说明](../../installer/README.md)。访客项目使用版本化 SDK，无需引用宿主源码路径，打包不调用旧辅助脚本。

分栏默认开启双向同步滚动，模式组右侧的链条按钮可关闭，选择按工作区保存；仅编辑、仅预览时开关不可操作。源码与预览按当前内容块对应，程序性定位回执不反向触发；图片加载、表格、换行、宽度及窗口变化后重新测量。滚轮、键盘及滚动条拖动继续由原生 Base 控件处理，手动拖动到释放期间拒绝迟到定位。源文档、场景或实例变化立即撤销旧定位，不修改文本、选区、焦点与 Undo。实际交付状态以[工单目录](docs/tickets/README.md)与验证记录为准。
