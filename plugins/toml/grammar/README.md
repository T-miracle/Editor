# Bundled TOML grammar

`toml.wasm` is the prebuilt Tree-sitter TOML grammar from `tree-sitter-wasm@1.1.1`, built against `@tree-sitter-grammars/tree-sitter-toml` 0.7.x. The npm tarball was pinned to version 1.1.1 and its SHA-512 integrity value was checked against the npm registry before extraction.

The grammar exports Tree-sitter ABI 15. Its SHA-256 is `4b70362b6d2e6efabffc3068b9d216989700085e9e69c8d9da8005ea44bb0e7a`.
